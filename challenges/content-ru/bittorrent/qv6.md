На этом этапе вы скачаете один фрагмент по magnet-ссылке и сохраните его на диск.

### Команда `magnet_download_piece`

Для проверки программы на этом этапе вводится новая команда `magnet_download_piece`. Она работает так:

```bash
$ ./your_program.sh magnet_download_piece -o /tmp/test-piece-0 <magnet-link> 0
```

Она похожа на ранее реализованную команду `download_piece`, но принимает magnet-ссылку вместо пути к файлу .torrent.

Для этой команды нужно реализовать следующую последовательность:

- Разобрать magnet-ссылку и получить URL трекера.
- Выполнить GET-запрос трекеру и получить список пиров.
- Установить TCP-соединение с пиром и выполнить базовое рукопожатие.
- Выполнить рукопожатие расширений.
- Получить словарь info через расширение метаданных (отправить сообщение `request`, получить `data`).
- Скачать блоки фрагмента (как в команде `download_piece` из предыдущих этапов).
- Сохранить фрагмент на диск.

### Тесты

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh magnet_download_piece -o /tmp/test-piece-0 <magnet_link> 0
```

Она проверит, что фрагмент скачан правильно.
