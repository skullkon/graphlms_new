На этом этапе вы реализуете поддержку команды `evaluate` и вычисление литералов `true`, `false` и `nil`.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 7.2.1: Вычисление литералов](https://craftinginterpreters.com/evaluating-expressions.html#evaluating-literals).

### Команда `evaluate`

На предыдущих этапах тестирующая система использовала команду `parse` для проверки вашей реализации синтаксического анализатора. В этом расширении ей потребуется проверить
реализацию вычислителя, поэтому она будет использовать другую команду: `evaluate`.

Команда `evaluate` принимает путь к файлу (например, `test.lox`) и печатает результат вычисления его содержимого в stdout.

Например, если `test.lox` содержит следующее:

```
2 + 3
```

Команда `evaluate` вернёт следующее:

```
$ ./your_program.sh evaluate test.lox
5
```

Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/expressions/evaluate.lox).

Для того же файла вывод команды `parse` выглядел бы так:

```
$ ./your_program.sh parse test.lox
(+ 2.0 3.0)
```

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими логические значения `true` и `false`, а также литерал `nil`.

Например, если `test.lox` содержит следующее:

```
true
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh evaluate test.lox
true
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

| Входные данные | Ожидаемый вывод |
| :---: | :-------------: |
| `true` | `true` |
| `false` | `false` |
| `nil` | `nil` |

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/expressions/evaluate.lox)
- Для литерала `nil` тестирующая система проверит, что программа выводит `nil`.
