На этом этапе вы добавите поддержку инструкции `for` в свой интерпретатор. Инструкция `for` многократно выполняет блок кода, используя части «инициализация», «условие» и «приращение».

### Ссылка на книгу

Код для этого этапа реализован в [разделе 9.5: Циклы for](https://craftinginterpreters.com/control-flow.html#for-loops).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими программы с инструкциями `if`.

Например, если `test.lox` содержит следующее

```
for (var baz = 0; baz < 3;) print baz = baz + 1;
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
1
2
3
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
for (var baz = 0; baz < 3;) print baz = baz + 1;
```

Ожидаемый вывод:

```
1
2
3
```

Тестовый случай 2:

Входные данные:

```
for (var world = 0; world < 3; world = world + 1) {
  print world;
}
```

Ожидаемый вывод:

```
0
1
2
```

Тестовый случай 3:

Входные данные:

```
var world = 0;
for (; world < 2; world = world + 1) print world;

for (var foo = 0; foo < 2;) {
  print foo;
  foo = foo + 1;
}
```

Ожидаемый вывод:

```
0
1
0
1
```

Тестовый случай 4:

Входные данные:

```
var quz = "after";
{
  var quz = "before";

  for (var quz = 0; quz < 1; quz = quz + 1) {
    print quz;
    var quz = -1;
    print quz;
  }
}

{
  for (var quz = 0; quz > 0; quz = quz + 1) {}

  var quz = "after";
  print quz;

  for (quz = 0; quz < 1; quz = quz + 1) {
    print quz;
  }
}
```

Ожидаемый вывод:

```
0
-1
after
0
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0.
