На этом этапе вы реализуете выполнение исполняемого файла, имя которого заключено в кавычки.

### Имена исполняемых файлов в кавычках

До этого имя исполняемого файла (первое слово команды) было простой строкой. Но имена исполняемых файлов можно заключать в кавычки, как и аргументы. Это полезно, если имя содержит пробелы, кавычки или специальные символы. 

Кавычки вокруг имени позволяют запускать программы, на которые иначе было бы трудно сослаться.

Например:

```bash
$ 'my program' argument1
# Runs an executable named "my program"

$ "exe with spaces" file.txt
# Runs an executable named "exe with spaces"
```

Когда оболочка получает команду с именем исполняемого файла в кавычках:

- Анализатор должен правильно интерпретировать кавычки, чтобы получить имя файла (например, из `"my 'program'"` получить `my 'program'`).
- Оболочка должна искать имя программы без окружающих кавычек в каталогах `PATH`.
- Найдя исполняемый файл, оболочка должна запустить процесс и передать остальные токены как аргументы.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке последовательность команд, запускающих переименованный исполняемый файл `cat`:

```bash
$ 'exe with "quotes"' file
content1
$ "exe with 'single quotes'" file
content2
```

Тестирующая система проверит, что:
- Имена исполняемых файлов в кавычках обрабатываются корректно (кавычки удаляются).
- Полученное имя исполняемого файла найдено и выполнено.
- Вывод соответствует выводу исполняемого файла.
