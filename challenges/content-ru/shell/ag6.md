На этом этапе вы добавите поддержку ограничения количества записей истории.

### Команда `history <n>`

Команда `history` может принимать необязательный числовой аргумент, ограничивающий количество отображаемых записей. Когда пользователь запускает `history <n>`, оболочка должна показать последние `n` команд из истории.

Например, `history 2` показывает две последние команды:

```bash
$ echo first
first
$ echo second
second
$ history 2
    2  echo second
    3  history 2
$
```

Здесь команда `history 2` отображает две последние команды (включая саму команду `history`).

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке несколько команд, а после них — команду `history <n>`:

```bash
$ echo hello
hello
$ echo world
world
$ invalid_command
invalid_command: command not found
$ history 2
    3  invalid_command
    4  history 2
$
```

Тестирующая система проверит, что:
- Вывод содержит последние `n` команд.
- Каждая запись пронумерована правильно.
- Сама команда `history` присутствует в истории.

### Примечания

- Команда `history` должна включать себя в список истории.
- В Bash `history <n>` означает «показать последние n команд». Некоторые оболочки, например _zsh_, трактуют это иначе («показать записи начиная со строки n»), но в этом задании используйте трактовку Bash.
