На этом этапе вы зарегистрируете `complete` как встроенную команду оболочки.

### Встроенная команда `complete`

Встроенная команда [`complete`](https://www.gnu.org/software/bash/manual/html_node/Programmable-Completion-Builtins.html#index-complete) позволяет пользователям регистрировать программируемое дополнение для команд.

Например, можно зарегистрировать скрипт дополнения для `git`:

```bash
$ complete -C /path/to/completer_script git
```

После регистрации оболочка будет вызывать скрипт при нажатии TAB после `git`, чтобы получить варианты:

```bash
$ git clo<TAB>
$ git clone 
```

На этом этапе достаточно зарегистрировать `complete` как встроенную команду, чтобы её распознавала команда `type`. Само поведение мы реализуем на следующих этапах.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем система проверит, что `complete` распознаётся как встроенная команда:

```bash
$ type complete
complete is a shell builtin
```

### Примечания

- На этом этапе не нужно реализовывать логику дополнения. Просто зарегистрируйте `complete`, чтобы она определялась как встроенная команда.
- Если оболочка уже использует список или словарь встроенных команд (например, `echo`, `cd`, `pwd`), добавьте `complete` в ту же структуру.
