На этом этапе вы будете читать историю из файла с помощью команды `history -r <path_to_history_file>`.

### Проверки

Тестирующая система запишет следующие команды в файл истории:

```txt
echo hello
echo world
<|EMPTY LINE|>
```

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке следующие команды:

```bash
$ history -r <path_to_history_file>
$ history
    1  history -r <path_to_history_file>
    2  echo hello
    3  echo world
    4  history
$
```

### Примечания
- Тестирующая система ожидает, что команды работы с историей также присутствуют в списке истории.
- `history -r` должна добавлять содержимое файла истории к списку истории в памяти.
