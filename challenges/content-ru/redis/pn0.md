### Команда MULTI

Команда [MULTI](https://redis.io/docs/latest/commands/multi/) начинает транзакцию.

После выполнения `MULTI` следующие команды из того же соединения помещаются в очередь, но не выполняются.

Пример использования:

```bash
$ redis-cli
> MULTI
OK
> SET foo 41
QUEUED
> INCR foo
QUEUED
```

Команды из очереди можно выполнить через [EXEC](https://redis.io/docs/latest/commands/exec/), которую мы рассмотрим позже.

Пока достаточно обработать `MULTI` и вернуть `+OK\r\n`. Постановка команд в очередь появится позже.

### Тесты

Тестирующая программа запустит вашу программу так:

```
./your_program.sh
```

Затем подключится к серверу как клиент Redis и выполнит команду:

```bash
$ redis-cli MULTI
```

Ожидается ответ `+OK\r\n`.

### Примечания

- Постановка команд в очередь и выполнение транзакций будут проверяться на следующих этапах.
