На этом этапе вы добавите создание каталога AOF при включённом сохранении в AOF.

### Создание каталога AOF

Сервер уже принимает конфигурацию AOF через флаги командной строки. Теперь пора применить её. При запуске с `--appendonly yes` серверу нужен каталог для хранения файлов AOF. Он находится внутри пути `dir`, а его имя задаётся параметром `appenddirname`.

Например, при таком запуске:

```bash
$ ./your_program.sh --dir /tmp/redis-data --appendonly yes --appenddirname appendonlydir
```

Сервер должен создать каталог `/tmp/redis-data/appendonlydir/`, если его ещё нет.

Если `--appendonly` не равен `yes`, создавать каталог не нужно.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh --dir <dir> --appendonly yes --appenddirname <append_dir_name> --appendfilename <append_file_name>
```

Она проверит, что:

- Каталог `<dir>/<append_dir_name>` создан.
- Каталог существует до отправки любых клиентских команд: он должен создаваться при запуске.

### Примечания

- Пока не нужно создавать файлы внутри каталога. Это появится на следующих этапах.
- Если каталог уже существует, сервер не должен возвращать ошибку.
