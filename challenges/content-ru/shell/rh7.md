На этом этапе вы добавите выбор команд из истории клавишей со стрелкой вверх.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке несколько команд, а после них нажмёт стрелку вверх для обращения к истории:

```bash
$ echo hello
hello
$ echo world
world
<UP ARROW>
$ echo world
<UP ARROW>
$ echo hello
```

Тестирующая система ожидает, что при нажатии стрелки вверх будут отображаться предыдущие команды.

### Примечания






- Для реализации рекомендуем библиотеку наподобие [readline](https://pkg.go.dev/github.com/chzyer/readline). Большинство современных оболочек и REPL (например, Python REPL) используют [GNU readline](https://www.wikiwand.com/en/articles/GNU_Readline) внутри. Хотя некоторые стандартные поведения, возможно, придётся переопределить, обычно это требует меньше работы, чем реализация с нуля.
