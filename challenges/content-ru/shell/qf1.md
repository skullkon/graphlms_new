На этом этапе вы обработаете случай, когда скрипт дополнения не возвращает вариантов.

### Обработка пустого вывода скрипта дополнения

Если скрипт дополнения ничего не выводит в stdout, у оболочки нет вариантов для дополнения. В этом случае она должна:

- Оставить ввод без изменений.
- Вызвать звуковой сигнал терминала, напечатав `\x07` в stdout.

Это сообщает пользователю, что нажатие TAB получено, но доступного дополнения нет.

Например, скрипт дополнения, который всегда завершается без вывода:

```python
#!/usr/bin/env python3
exit(0)
```

После регистрации и вызова по TAB оболочка должна лишь подать звуковой сигнал и оставить ввод без изменений:

```bash
$ complete -C /path/to/completer_script docker
$ docker xyz<TAB>
# bell rings, input line stays as "docker xyz"
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Система предоставит скрипт дополнения без вывода, зарегистрирует его для команды и нажмёт TAB:

```bash
$ complete -C /path/to/completer_script docker
$ docker xyz<TAB>
# bell rings, input unchanged
```

Тестирующая система проверит, что:

- После нажатия TAB строка ввода не меняется.
- Символ звукового сигнала (`\x07`) выводится в stdout.
