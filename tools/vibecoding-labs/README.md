# Практика курса «Вайбкодинг: от первого запроса до своего харнесса»

Курс: /vibecoding. Чтение и локальные проверки бесплатны; для общения с живым агентом нужен доступ к выбранному сервису на его условиях.

- starter — собственная работа. Реализованы загрузка данных и list; add и done намеренно оставлены заготовкой.
- reference — открытый эталон. Все 12 поведенческих тестов должны пройти.
- templates — примеры спецификации, инструкций, статуса и скилла. Адаптируйте их к фактам проекта.

Нужны Python 3.10+ и Git. Откройте терминал внутри starter либо reference и прочитайте её README.
На macOS/Linux используйте python3, на Windows при необходимости py -3.
Проверка: python3 check.py. Она работает без внешних пакетов, сети и API-ключей.
Тесты используют временные папки и вызывают CLI отдельными процессами.

В заготовке общий запуск намеренно завершается ошибкой до реализации. Не удаляйте падающие тесты.
Отдельные классы TestAdd и TestDone позволяют проверять шаги независимо.

Чтобы подключить процедуру проверки, скопируйте templates/review-change/SKILL.md:
для Codex — в starter/.agents/skills/review-change/SKILL.md;
для Claude Code — в starter/.claude/skills/review-change/SKILL.md.
В корень starter скопируйте WORKFLOW.md, STATUS.md и файл инструкций выбранного клиента.
Не копируйте всё в глобальные настройки; это учебный проект.

Ограничения: один пользователь и последовательная запись в JSON. Нет защиты от конкурентной записи и прерывания сохранения.
Скрипт check.py запускает код, не предоставляет песочницу и не управляет моделью.
Для упражнений используйте искусственные задачи. Не помещайте токены или личные данные в проект.
