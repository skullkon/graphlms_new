### Ответ API Produce для неверного топика или раздела

Получив запрос `Produce`, брокер Kafka должен проверить существование топика и раздела. Если хотя бы один из них не существует, брокер возвращает соответствующий ответ с кодом ошибки.

На этом этапе ответ с ошибкой можно жёстко задать: считайте все запросы `Produce` запросами к неверным топикам или разделам и возвращайте код `3` (`UNKNOWN_TOPIC_OR_PARTITION`). На следующем этапе вы реализуете успешные ответы.

Мы создали интерактивный обозреватель структуры запросов и ответов `Produce`:

- 🔎 [Запрос Produce (v11)](https://binspec.org/kafka-produce-request-v11)
- 🔎 [Ответ Produce (v11) — неверный топик или раздел](https://binspec.org/kafka-produce-unknown-topic-or-partition-response-v11)

### Тесты

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh /tmp/server.properties
```

Затем подключится к серверу на порту 9092 и отправит два запроса `Produce` (v11): первый — для существующего топика с неверным разделом, второй — для неверного топика.

Для ответов на оба запроса она проверит, что:

- Первые 4 байта ответа («длина сообщения») корректны.
- Идентификатор корреляции в заголовке ответа совпадает с идентификатором в заголовке запроса.
- Поле `throttle_time_ms` ответа равно `0`.
- Поле `topics` содержит 1 элемент, в котором:
  - Поле `name` совпадает с именем топика в запросе.
  - Поле `partitions` содержит 1 элемент, в котором:
    - Поле `error_code` равно `3` (`UNKNOWN_TOPIC_OR_PARTITION`).
    - Поле `index` совпадает с разделом в запросе.
    - Поле `base_offset` равно `-1`.
    - Поле `log_append_time_ms` равно `-1`.
    - Поле `log_start_offset` равно `-1`.

### Примечания

- На этом этапе нужно разобрать запрос `Produce`, чтобы получить имя топика и раздел для ответа.
- Пока ответ с ошибкой можно жёстко задать. Реальной проверкой существования топиков и разделов мы займёмся позже.
- Официальная документация API `Produce` находится [здесь](https://kafka.apache.org/42/design/protocol/#The_Messages_Produce). Прокрутите до раздела «(Version: 11)».
