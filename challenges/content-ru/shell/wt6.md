На этом этапе вы расширите автодополнение для частичного дополнения с помощью наибольшего общего префикса (LCP).

### Дополнение до наибольшего общего префикса

Если пользовательскому вводу соответствуют несколько исполняемых файлов и некоторые имена являются префиксами других, оболочка должна дополнить ввод до наибольшего общего префикса всех совпадений.

Например, если в PATH есть такие исполняемые файлы:

- `xyz_foo`
- `xyz_foo_bar`
- `xyz_foo_bar_baz`

Когда пользователь вводит `xyz_` и нажимает Tab, оболочка дополняет ввод до `xyz_foo`, потому что это самый длинный префикс, общий для всех трёх исполняемых файлов.

После ввода следующего символа-разделителя нажатие Tab дополняет ввод до следующего общего префикса оставшихся совпадений:

```bash
# Note: The prompt lines below are displayed on the same line
$ xyz_<TAB>
$ xyz_foo_<TAB>
$ xyz_foo_bar_<TAB>
$ xyz_foo_bar_baz 
```

Если после дополнения остаётся только одно совпадение, оболочка должна дополнить имя команды, как на предыдущих этапах (с пробелом в конце).

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система проверит последовательное дополнение по Tab:

```bash
# Note: The prompt lines below are displayed on the same line
$ xyz_<TAB>
$ xyz_foo_<TAB>
$ xyz_foo_bar_<TAB>
$ xyz_foo_bar_baz 
```

Тестирующая система проверит, что:
1. После `xyz_`<TAB> дополнение показывает `xyz_foo`.
2. После ввода `_` и нажатия Tab дополнение показывает `xyz_foo_bar`.
3. После ввода `_` и повторного нажатия Tab дополнение показывает `xyz_foo_bar_baz ` с пробелом в конце.
4. Завершающий пробел появляется только при единственном оставшемся совпадении.
