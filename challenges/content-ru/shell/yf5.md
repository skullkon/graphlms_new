На этом этапе вы реализуете встроенную команду `history`.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке несколько команд, а после них — команду `history`:

```bash
$ echo hello
hello
$ echo world
world
$ invalid_command
invalid_command: command not found
$ history
    1  echo hello
    2  echo world
    3  invalid_command
    4  history
$
```

Тестирующая система ожидает список истории выполненных команд с форматированием и нумерацией, как в примере выше.

### Примечания

- Некоторые оболочки, например _zsh_, не добавляют команду `history` в историю, но тестирующая система ожидает её присутствия.
- Для этого расширения достаточно хранить историю в памяти. Сохранение истории между сеансами будет реализовано в отдельном расширении.
