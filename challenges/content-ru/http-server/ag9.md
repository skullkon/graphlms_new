На этом этапе вы добавите поддержку постоянных HTTP-соединений. По умолчанию соединения HTTP/1.1 постоянные: одно TCP-соединение можно использовать повторно для нескольких запросов.

### Тесты

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Затем она отправит два последовательных запроса по одному соединению:
```bash
$ curl --http1.1 -v http://localhost:4221/echo/banana --next http://localhost:4221/user-agent -H "User-Agent: blueberry/apple-blueberry"
```

Ваш сервер должен:
1. Оставить TCP-соединение открытым после первого запроса.
2. Обрабатывать последующие запросы по тому же соединению.
3. Вернуть соответствующие ответы на оба запроса.

### Примечания
- В HTTP/1.1 соединения по умолчанию постоянные, если клиент не отправляет заголовок `Connection: close`.
- Каждый запрос нужно обрабатывать независимо, даже если запросы поступают по одному соединению.
- Сервер не должен закрывать соединение после каждого запроса.
