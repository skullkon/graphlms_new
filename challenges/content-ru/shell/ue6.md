На этом этапе вы добавите поддержку дополнения имён файлов во вложенных путях.

### Дополнение во вложенных путях

Пока оболочка дополняет имена файлов только в текущем каталоге. Теперь вы расширите её для дополнения файлов в подкаталогах, когда пользователь указывает путь.

Например, если есть файл `path/to/file.txt`, пользователь может ввести:

```bash
$ cat path/to/f<TAB>
$ cat path/to/file.txt 
#                      ^ note the trailing space
```

### Реализация дополнения путей

Когда пользователь нажимает Tab и неполное имя файла содержит `/`:

1. Разделите текст по последнему символу `/`:
   - Всё до последней `/` включительно — путь каталога.
   - Всё после неё — префикс для поиска совпадений.
     
   Например, в `path/to/f` путь каталога — `path/to/`, а префикс — `f`.
2. Найдите в этом каталоге элементы, начинающиеся с префикса.
3. Если совпал один элемент, замените всё неполное имя файла полным путём и добавьте пробел в конце (например, `path/to/f` превращается в `path/to/file.txt `).

### Проверки

Тестирующая система создаст файл во вложенном каталоге (например, `path/to/file.txt`) и запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем система имитирует пользовательский ввод и нажатия Tab:

```bash
$ cat path/to/f<TAB>
$ cat path/to/file.txt 
```

Тестирующая система проверит, что:
- Нажатие Tab дополняет неполный путь до полного.
- После дополненного пути добавляется пробел.

### Примечания

- Путь каталога задаётся относительно текущего рабочего каталога. Например, если текущий рабочий каталог — `/home/user`, а токен — `path/to/f`, просматривайте элементы внутри `/home/user/path/to/`.
- Пока достаточно обработать случай, когда префиксу соответствует ровно один элемент. Несколько совпадений мы обработаем на следующих этапах.
