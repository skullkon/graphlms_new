На этом этапе вы добавите вывод одной входной строки, если она соответствует шаблону.

### Вывод совпавших строк

Когда grep находит совпадение, он выводит всю входную строку в стандартный вывод.

Например:

```bash
$ echo -n "apple" | ./your_program.sh -E "[^abc]"
apple
$ echo -n "cab" | ./your_program.sh -E "[^abc]"
$
```

Здесь grep выводит строку `"apple"`, поскольку она соответствует шаблону `[^abc]` (содержит символы, отличные от a, b и c). Строка `"cab"` не соответствует шаблону, поэтому ничего не выводится.

Код завершения grep также указывает, найдены ли совпадения:

- Если входная строка соответствует шаблону, программа завершается с кодом `0` (успех).
- Если входная строка не соответствует шаблону, программа завершается с кодом `1` (совпадений нет).

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -n "dog" | ./your_program.sh -E "dog$"
```

Она проверит, что программа:
- Выводит входную строку в stdout при совпадении.
- Ничего не выводит в stdout при отсутствии совпадения.
- Завершается с кодом `0`, если шаблон совпадает.
- Завершается с кодом `1`, если шаблон не совпадает.

### Примечания

- Тестирующая система передаёт только одну входную строку. На этом этапе обрабатывать несколько строк не нужно — это появится позже.
