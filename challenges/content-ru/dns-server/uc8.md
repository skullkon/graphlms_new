До сих пор мы игнорировали содержимое полученного DNS-пакета и жёстко задавали идентификатор ответа равным `1234`. На этом этапе вам нужно разобрать полученный DNS-пакет и вернуть ответ с тем же идентификатором. Кроме того, потребуется установить некоторые другие поля заголовка.

Как и на предыдущем этапе, тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем она отправит на порт 2053 UDP-пакет с DNS-запросом.

Ваша программа должна отправить ответный DNS-пакет с заголовком, содержащим следующие значения:

| Поле | Размер | Ожидаемое значение |
| ---------------------------------- | ------- | --------------------------------------------------------------------------- |
| Идентификатор пакета (ID) | 16 бит | Повторить 16-битный идентификатор из пакета запроса, отправленного тестирующей системой |
| Признак запроса/ответа (QR) | 1 бит | 1 |
| Код операции (OPCODE) | 4 бита | Повторить значение OPCODE, отправленное тестирующей системой |
| Авторитетный ответ (AA) | 1 бит | 0 |
| Усечение (TC) | 1 бит | 0 |
| Запрошена рекурсия (RD) | 1 бит | Повторить значение RD, отправленное тестирующей системой |
| Рекурсия доступна (RA) | 1 бит | 0 |
| Зарезервировано (Z) | 3 бита | 0 |
| Код ответа (RCODE) | 4 бита | 0 (нет ошибки), если OPCODE равен 0 (стандартный запрос), иначе 4 (не реализовано) |
| Количество вопросов (QDCOUNT) | 16 бит | Любое допустимое значение |
| Количество записей ответов (ANCOUNT) | 16 бит | Любое допустимое значение |
| Количество записей полномочий (NSCOUNT) | 16 бит | Любое допустимое значение |
| Количество дополнительных записей (ARCOUNT) | 16 бит | Любое допустимое значение |

Тестирующая система не проверяет содержимое после заголовка, если пакет в целом является корректным DNS-пакетом.

**Примечание**: ваш код по-прежнему должен проходить тесты предыдущих этапов. Больше не нужно жёстко задавать идентификатор запроса равным `1234`, поскольку на предыдущих этапах тестирующая система отправляет идентификатор `1234`. Если этот этап реализован правильно, тесты предыдущих этапов также должны проходить автоматически.
