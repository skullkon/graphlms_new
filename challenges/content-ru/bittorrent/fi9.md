Трекеры — центральные серверы, хранящие сведения о пирах, участвующих в раздаче и скачивании торрента.

На этом этапе вы отправите GET-запрос HTTP-трекеру, чтобы найти пиров для скачивания файла.

### GET-запрос трекеру

Нужно отправить запрос по URL трекера, извлечённому на предыдущем этапе, включив следующие параметры запроса:

- `info_hash`: информационный хеш торрента.
    - Длина 20 байт; необходимо URL-кодирование.
    - **Примечание**: это **не** шестнадцатеричное представление длиной 40 байт.
- `peer_id`: уникальный идентификатор вашего клиента.
    - Строка длиной 20 символов, которую вы выбираете сами.
- `port`: порт, который прослушивает ваш клиент.
    - Можно задать `6881`; реализовывать эту функциональность в задании не потребуется.
- `uploaded`: общий объём уже отправленных данных.
    - Поскольку клиент ещё ничего не отправлял, можно указать `0`.
- `downloaded`: общий объём уже скачанных данных.
    - Поскольку клиент ещё ничего не скачивал, можно указать `0`.
- `left`: количество байт, которое осталось скачать.
    - Поскольку клиент ещё ничего не скачивал, это полная длина файла (вы извлекли её из торрент-файла на предыдущих этапах).
- `compact`: следует ли использовать [компактное представление](https://www.bittorrent.org/beps/bep_0023.html) списка пиров.
    - В рамках задания задайте `1`.
    - Компактное представление встречается чаще, а некомпактное поддерживается преимущественно для обратной совместимости.

Подробнее об этих параметрах — в [спецификации протокола BitTorrent](https://www.bittorrent.org/beps/bep_0003.html#trackers).

### Ответ трекера

Трекер вернёт словарь bencode с двумя ключами:

- `interval`:
    - Целое число, указывающее, как часто клиент должен обращаться к трекеру.
    - В рамках задания это значение можно игнорировать.
- `peers`.
    - Строка со списком пиров, к которым может подключиться клиент.
    - Каждый пир представлен 6 байтами: первые 4 байта — IP-адрес, последние 2 — номер порта.

---

Тестирующая система запустит вашу программу следующим образом:
```
$ ./your_program.sh peers sample.torrent
```
Ожидаемый вывод:
```
165.232.41.73:51556
165.232.38.164:51493
165.232.35.114:51476
```
