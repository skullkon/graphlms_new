На этом этапе вы обработаете случаи, когда аргументу не соответствует ни один элемент.

### Отсутствие элементов для дополнения

Когда пользователь вводит аргумент, не совпадающий ни с одним элементом, и нажимает `<TAB>`, оболочка должна:
1. Оставить ввод без изменений (не менять введённый пользователем текст).
2. Напечатать символ звукового сигнала `\x07` в стандартный вывод.

[Символ звукового сигнала](https://en.wikipedia.org/wiki/Bell_character) обычно вызывает звук или визуальную вспышку в зависимости от настроек терминала.

Например:
```bash
$ cat absent_filenam<TAB>
# No completion occurs, input unchanged
# Bell character (\x07) printed to stdout
$ cat absent_filenam
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем система имитирует пользовательский ввод с несуществующим путём:

```bash
$ cat absent_filenam<TAB>
$ cat absent_filenam
```

Тестирующая система проверит, что:
- Если дополнение невозможно, ввод остаётся без изменений.
- Символ звукового сигнала печатается в стандартный вывод.
