На этом этапе вы добавите отрицательные индексы в `LRANGE`.

### `LRANGE` с отрицательными индексами

Команда `LRANGE` также поддерживает отрицательные индексы.

Отрицательный индекс задаёт смещение от конца списка: `-1` — последний элемент, `-2` — предпоследний и так далее.

Например:

```bash
# Create a list with 5 items
> RPUSH list_key "a" "b" "c" "d" "e"
(integer) 5

# List the last 2 items 
> LRANGE list_key -2 -1
1) "d"
2) "e"

# List all items except the last 2
> LRANGE list_key 0 -3
1) "a"
2) "b"
3) "c"
```

Если отрицательный индекс выходит за границы, например `-6` для списка длиной `5`, он трактуется как `0`, то есть начало списка.

### Тесты

Тестирующая программа запустит вашу программу так:

```
./your_program.sh
```

Затем создаст список с несколькими элементами.

```bash
$ redis-cli RPUSH list_key "a" "b" "c" "d" "e"
```

После этого отправит серию `LRANGE` с одним или несколькими отрицательными индексами.

Например:

```bash
$ redis-cli LRANGE list_key 2 -1
```

В этом случае ожидается массив `["c", "d", "e"]`, закодированный в RESP так:

```
*3\r\n
$1\r\n
c\r\n
$1\r\n
d\r\n
$1\r\n
e\r\n
```
