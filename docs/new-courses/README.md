# Четыре практических курса

Работа по запросу владельца проекта: бесплатные законченные курсы Git, базового Linux, баз данных, алгоритмов и структур данных. Автору разрешены самостоятельная организация и параллельные агенты; после проверки требуется commit и push. Новые курсы используют существующий читатель и каталог GraphLMS.

## Результат и последовательность

| Курс | Главы | Предварительные знания | Финальная работа |
|---|---:|---|---|
| Git | 14 | Работа с файлами; shell вводится в примерах | Совместное изменение, конфликт, проверка и восстановление в локальных репозиториях |
| Linux | 14 | Новичок, локальная Ubuntu VM/WSL | Диагностика локального сервиса и восстановление отчёта из копии |
| Базы данных | 13 | SQL с нуля; Go нужен для приложения | Сервис выдачи книг с конкурентным инвариантом и проверкой restore |
| Алгоритмы | 16 | Функции, циклы, срезы, map и тесты Go | Планировщик зависимостей, маршруты и отбор по приоритету |

Практический старт: Linux и Git можно проходить параллельно с основами Go. После функций и тестов Go доступны алгоритмы. SQL-часть баз данных не требует Go; клиент и финальный сервис требуют базового Go. Эти курсы подготавливают к backend-проекту и углублённому System Design.

## Методика

Сначала изучены открытые программы и первичные материалы: Pro Git/MIT Missing Semester, Linux Foundation/Ubuntu/GNU, CMU/Berkeley/PostgreSQL, MIT/Princeton/Berkeley и документация Go. Источники, конкретные адаптации и ограничения доступа записаны в `*-research.md`.

Каждая глава строится вокруг ситуации, объяснения механизма, команд или кода с ожидаемым результатом, самостоятельной задачи, критериев и открытого разбора. Термины вводятся до применения. Minutes означает время чтения; практику оцениваем отдельно. Коммерческие рейтинги не использованы как доказательство качества; закрытые платные материалы не объявлены прочитанными целиком.

Обязательная практика выполняется локально без платных API. Linux использует отдельную учебную среду; Git — временные репозитории и bare remote; PostgreSQL — новые базы и rollback; алгоритмы — стандартную библиотеку Go. Открытые эталоны не подменяют самостоятельное задание. Тесты заготовок алгоритмов ожидаемо падают до реализации — это явно обозначено.

## Интеграция

Четыре записи реестра и версия 0.10.0, каталог, sitemap, граф последовательности и общие маршруты `/<course>` и `/<course>/book/<slug>`. Shared reader разрешает только git/linux/databases/algorithms, неизвестные пути дают 404. Старые маршруты и идентификаторы сохранены. Исправлена маркировка навыков новых курсов: они больше не получают тег go автоматически.

Архивы собираются командой `python3 tools/package-course-labs.py`; System Design — `node tools/system-design-labs/package.mjs`. Источник архива — соответствующая папка tools. Файлы упакованы в собственный корневой каталог, временные базы и кэши не включаются. Программа упаковки сохраняет вложенные папки и права shell-скриптов.

## Проверка качества

Проверяем технические договоры и последовательность перекрёстно другими агентами, исполняем лаборатории и проверяем рендер всех глав. Сводный итог с версиями инструментов и конкретными ограничениями находится в verification.md. Наблюдение за реальными новичками — отдельный последующий пилот; агент не считается заменой студенту.
