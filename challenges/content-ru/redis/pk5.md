На этом этапе вы добавите поддержку `GET` для ключа, созданного командой `SETBIT`.

### Строки и битовые карты

Поскольку битовые карты являются строками, строковые команды работают с ключами, созданными через `SETBIT`.

Это два представления одних байтов: `SETBIT` записывает биты в строку, а `GET` возвращает эту строку.

Смещение `0` соответствует старшему биту первого байта. Установка бита `1` даёт байт `01000000`, то есть ASCII-символ `@`:

```bash
> SETBIT mykey 1 1
(integer) 0
> GET mykey
"@"
```

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем создаст битовую карту командой `SETBIT`.

```bash
$ redis-cli SETBIT mykey 1 1
```

Далее отправит команду `GET` для этого ключа.

```bash
$ redis-cli GET mykey
```

Ожидаемый ответ — `$1\r\n@\r\n`, то есть `@` в формате [bulk string RESP](https://redis.io/docs/latest/develop/reference/protocol-spec/#bulk-strings).

### Примечания

- Здесь достаточно обработать `GET` для ключа, созданного одним вызовом `SETBIT`. Увеличение строки при большем смещении рассмотрим позже.
- `GET` возвращает строковое значение ключа, а `SETBIT` записывает это значение как байты. Ключи, созданные через `SETBIT` и `SET`, имеют общее представление.
