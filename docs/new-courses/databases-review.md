# Проверка интегратором курса баз данных

30 сентября 2026 года. Проверены программа и последовательность 13 глав, setup.sql/tests.sql/indexes.sql/migration.sql/transactions.sql, README и выбранные объяснения из глав01,05,06,08,09,10,11,13. Это отдельная проверка интегратора; не заявляется вторым полным прочтением всех текстов.

Модель книги и физического экземпляра согласована с частичным уникальным индексом активной выдачи. Примеры COUNT после LEFT JOIN различают отсутствующее значение и количество строк. Отчёты исходного набора2/0/0 и свободных экземпляров0/1/1 согласованы с dataset. Параметризация, пул/Rows и транзакции Go не подменяют авторизацию. EXPLAIN ANALYZE назван исполнением; фиксированное ускорение не обещано. Migration — dry run с rollback, а restore идёт в новую пустую базу, без --clean.

Найдено и исправлено одно расхождение формата: в первой главе команда psql `\r` была записана настоящим символом carriage return. Автор заменил его буквальными символами и проверил главы на управляющие байты. Дополнительно добавлен полный необязательный читающий Go-клиент с pgx, чтобы ученик мог сверить полный жизненный цикл соединения и Rows с собственным решением.

Из распакованного database-labs.zip интегратор повторно выполнил на отдельном PostgreSQL 18.6: setup/tests/indexes/migration; отказ повторного setup и tests после отказа; pg_dump→новая пустая база→pg_restore→tests; Go-клиент для участников 1/2/3 и отказ localhost:1. Все проверки прошли. Двухсессионные lost update/write skew/guard/Serializable и две ветви частичного unique index исполнил автор лаборатории в том же временном кластере; описание результатов в databases-research.md и README. Файл transactions.sql сам по себе эти истории не автоматизирует.

Проверка подтверждает определённые договоры учебного набора и клиентского примера. Она не является нагрузочным испытанием произвольного приложения и не оценивает будущий самостоятельный финальный проект автоматически.
