На этом этапе вы добавите проверку имён переменных оболочки.

### Проверка идентификаторов

Имя переменной оболочки должно быть корректным идентификатором: начинаться с буквы или подчёркивания, а в остальной части содержать буквы, цифры и подчёркивания.

Цифра не может быть первым символом. Если имя недопустимо, оболочка сообщает об ошибке и не создаёт переменную.

Например:

```bash
# Valid variable declaration
$ declare foo=bar
$ 

# Valid variable declaration
$ declare _FOO=BAR
$ 

# Invalid variable
$ declare 67=x
declare: `67=x': not a valid identifier
$ 
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Система отправит `declare` с допустимыми именами (начинающимися с буквы или `_`) и с недопустимыми (например, начинающимися с цифры). Для недопустимого имени тестирующая система проверит вывод следующего вида:

```bash
$ declare 23=x
declare: `23=x': not a valid identifier
$ declare _FOO=bar
$ declare -p _FOO
declare -- _FOO="bar"
```
