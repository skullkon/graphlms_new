На этом этапе вы добавите проверку наследования классов, обеспечивающую корректность иерархий классов. Для этого потребуется обнаруживать недопустимые схемы наследования и сообщать об ошибках.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 13.1: Суперклассы и подклассы](https://craftinginterpreters.com/inheritance.html#superclasses-and-subclasses), а именно в частях об обработке ошибок.

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими недопустимые схемы наследования.

Например, если `test.lox` содержит следующее:

```
// A class can't inherit from itself.
class Foo < Foo {} // expect compile error
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
[line 2] Error at 'Foo': A class can't inherit from itself.
```

Тестирующая система выполнит несколько проверок с недопустимыми схемами наследования, например:

Тестовый случай 1:

Входные данные:
```
fun A() {}

// A class can only inherit from a class.
class B < A {} // expect runtime error

print A();
print B();
```

Ожидаемый вывод:
```
Superclass must be a class.
[line 4]
```

Тестовый случай 2:

Входные данные:
```
var A = "class";

// A class can only inherit from a class
class B < A {} // expect runtime error

print B();
```

Ожидаемый вывод:
```
Superclass must be a class.
[line 4]
```

Тестирующая система проверит, что для корректных иерархий классов код завершения равен 0. При некорректной иерархии, которую можно обнаружить во время компиляции, программа должна завершиться с кодом 65 (ошибка компиляции). При некорректном создании экземпляра класса, которое можно обнаружить только во время выполнения, программа должна завершиться с кодом 70 (ошибка времени выполнения) и вывести соответствующее сообщение об ошибке.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/class/local_inherit_self.lox)
- Сообщения об ошибках следует выводить в stderr, но их точный текст не проверяется.
