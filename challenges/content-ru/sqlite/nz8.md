На этом этапе мы реализуем сканирование индекса. Вместо чтения _всех_ строк таблицы с последующей фильтрацией в памяти мы используем индекс для более эффективного поиска.

Чтобы проверить, что реализация действительно использует индекс, тестирующая система возьмёт базу размером около 1 ГБ и потребует вернуть результаты запроса менее чем за 3 секунды.

Тестовая база содержит таблицу `companies` с индексом `idx_companies_country` по столбцу `country`.

Для локального тестирования можно скачать уменьшенную версию этой базы. Подробности — в разделе **Sample Databases** файла **README** вашего репозитория.

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh companies.db "SELECT id, name FROM companies WHERE country = 'eritrea'"
```

Ожидаемый вывод:

```
121311|unilink s.c.
2102438|orange asmara it solutions
5729848|zara mining share company
6634629|asmara rental
```

Можно считать, что все запросы тестирующей системы будут содержать `country` в условии `WHERE`, поэтому их можно выполнить с помощью индекса. Тестирующая система выполнит несколько случайных запросов и будет ожидать, что каждый вернёт результат менее чем за 3 секунды.
