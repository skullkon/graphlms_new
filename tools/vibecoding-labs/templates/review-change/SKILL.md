---
name: review-change
description: Проверяй небольшое изменение менеджера задач перед сохранением. Не используй для публикации.
---

Прочитай SPEC.md и посмотри изменённые файлы.
Свяжи изменение с одним требованием.
Проверь обычный сценарий, ошибочный ввод и сохранение данных.
Запусти python3 check.py и сообщи код возврата.
Посмотри git diff и git status --short.
Назови ограничения. Не меняй требования или тесты ради успеха.
Не делай commit и не отправляй изменения без запроса человека.
