На этом этапе вы добавите чтение нескольких потоков командой `XREAD`.

### Команда `XREAD` для нескольких потоков

При чтении нескольких потоков команда `XREAD` после ключевого слова `STREAMS` передаётся список ключей потоков, а затем соответствующий список идентификаторов записей для каждого потока.

Формат команды:

```bash
XREAD STREAMS <key1> <key2> ... <id1> <id2> ...
```

Ответ сервера по-прежнему представляет собой массив RESP с потоками, где:

- Каждый поток — массив из двух элементов: ключ потока и прочитанные записи.
- Порядок потоков в ответе должен совпадать с порядком в команде.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем отправит несколько `XADD`, добавляя записи в разные потоки.

```bash
$ redis-cli XADD stream_key 0-1 temperature 95
$ redis-cli XADD other_stream_key 0-2 humidity 97
```

После этого отправит серверу `XREAD` для нескольких потоков.

```bash
$ redis-cli XREAD streams stream_key other_stream_key 0-0 0-1
```

Сервер должен ответить массивом RESP с результатами для всех указанных потоков.

Для примера выше ответ будет таким, в формате массива RESP:

```json
[
  [
    "stream_key",
    [
      [
        "0-1",
        [
          "temperature",
          "95"
        ]
      ]
    ]
  ],
  [
    "other_stream_key",
    [
      [
        "0-2",
        [
          "humidity",
          "97"
        ]
      ]
    ]
  ]
]
```
