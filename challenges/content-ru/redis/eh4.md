На этом этапе вы реализуете второй шаг рукопожатия репликации.

### Напоминание о рукопожатии

Рукопожатие состоит из трёх шагов:

1. Реплика отправляет ведущему `PING` (реализовано ранее).
2. Реплика дважды отправляет ведущему `REPLCONF`.
3. Реплика отправляет ведущему `PSYNC`.

На этом этапе вы реализуете второй шаг.

### Команда `REPLCONF`

Команда `REPLCONF` настраивает подключённую реплику. Получив ответ на `PING`, реплика отправляет две команды `REPLCONF` по очереди, ожидая ответ после каждой.

1. `REPLCONF listening-port <PORT>`: сообщает ведущему порт, который слушает реплика. Он используется для [мониторинга и журналирования](https://github.com/redis/redis/blob/90178712f6eccf1e5b61daa677c5c103114bda3a/src/replication.c#L107-L130), а не для самой репликации.
2. `REPLCONF capa psync2`: сообщает ведущему о возможностях реплики.
   - `capa` — сокращение от capabilities («возможности»). Следующий аргумент обозначает поддерживаемую функцию.
   - `psync2` означает поддержку протокола PSYNC2 — улучшенной версии [частичной синхронизации](https://redis.io/docs/latest/operate/oss_and_stack/management/replication/), используемой для повторной синхронизации реплики с ведущим.
   - Пока можно жёстко задать `capa psync2`.

Обе команды отправляются как массивы RESP, поэтому байты будут выглядеть примерно так:

```
# REPLCONF listening-port <PORT>
*3\r\n$8\r\nREPLCONF\r\n$14\r\nlistening-port\r\n$4\r\n6380\r\n

# REPLCONF capa psync2
*3\r\n$8\r\nREPLCONF\r\n$4\r\ncapa\r\n$6\r\npsync2\r\n
```

На обе команды ведущий отвечает `+OK\r\n`: строкой `OK`, закодированной как [простая строка](https://redis.io/docs/latest/develop/reference/protocol-spec/#simple-strings). Реплика должна дождаться ответа, прежде чем отправлять следующую команду.

### Тесты

Тестирующая программа запустит вашу программу так:

```
./your_program.sh --port <PORT> --replicaof "<MASTER_HOST> <MASTER_PORT>"
```

Затем проверит, что реплика подключилась к ведущему и отправила:

1. Команду `PING`.
2. Команду `REPLCONF` с аргументами `listening-port` и `<PORT>`.
3. Команду `REPLCONF` с аргументами `capa psync2`.

**Примечания**

- Ответ на `REPLCONF` всегда будет `+OK\r\n`.
