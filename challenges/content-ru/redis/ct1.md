На этом этапе вы добавите создание [упорядоченного множества](https://redis.io/docs/latest/develop/data-types/sorted-sets/) командой `ZADD`.

### Упорядоченные множества Redis

Упорядоченное множество — один из типов данных Redis. Это коллекция уникальных элементов, каждому из которых соответствует оценка — число с плавающей точкой. В отличие от обычных множеств, упорядоченные множества сохраняют элементы в порядке их оценок.

Они удобны для таблиц лидеров, очередей с приоритетом и других задач, где нужен быстрый доступ к элементам, отсортированным по числовому значению.

Например, упорядоченное множество для рейтинга игроков могло бы содержать:

```yaml
racer_scores:
    - member: "Ford"
      score: 6.1
    - member: "Royce"
      score: 8.2
    - member: "Sam-Bodden"
      score: 8.2
    - member: "Prickett"
      score: 14.5
```

Элементы располагаются по возрастанию оценок.

### Команда `ZADD`

Команда [ZADD](https://redis.io/docs/latest/commands/zadd/) добавляет элемент в упорядоченное множество.

Если множества нет, оно создаётся, и в него добавляется элемент.

Пример использования:

```bash
> ZADD racer_scores 8.0 "Sam"
(integer) 1
```

`ZADD` принимает ключ, оценку и имя элемента. Она возвращает целое число — количество новых элементов, добавленных в множество.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем отправит `ZADD` с ключом, значением и оценкой.

```bash
$ redis-cli ZADD zset_key 10.0 zset_member
```

Тест проверит ответ `:1\r\n`: число 1, количество добавленных элементов, в формате целого числа RESP.

### Примечания

- Пока достаточно создавать новое упорядоченное множество с одним элементом. Добавление элементов в существующее множество появится позже.
- Для максимальной точности рекомендуется хранить оценку как 64-битное число с плавающей точкой: официальная реализация Redis использует [`double`](https://github.com/redis/redis/blob/bec644aab198049eaa5583631c419b4574b137e1/tests/modules/zset.c#L34).
- Рекомендуем выбрать структуру данных, хранящую элементы в порядке оценок. Это пригодится позже.
    - Redis реализует упорядоченные множества сочетанием [хеш-таблицы и списка с пропусками](https://github.com/redis/redis/blob/674b829981c0b8ad15a670a32df503e0e4514e96/src/server.h#L1560).
