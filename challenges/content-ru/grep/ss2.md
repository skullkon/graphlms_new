На этом этапе вы добавите вывод нескольких совпавших фрагментов из одной строки.

### Вывод нескольких совпадений

Если строка содержит несколько совпадений с шаблоном, флаг `-o` выводит каждое на отдельной строке.

Например:

```bash
# The '\d' pattern matches 1 and 0 separately
$ echo -n "The king had 10 children" | grep -o -P '\d'
1
0

# The `\d\d` matches a pair of digits, so each pair (if found) is printed in its own line
$ echo -n "The king had 10 children" | grep -o -P '\d\d'
10
```

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -e "jekyll and hyde" | ./your_program.sh -o -E "(jekyll|hyde)"
jekyll
hyde
```

Она проверит, что:
- Выведены все совпадения из строки, каждое на отдельной строке.
- Программа завершается с кодом `0`, когда найдено хотя бы одно совпадение.
- Программа ничего не выводит и завершается с кодом `1`, когда совпадений нет.

### Примечания

- Достаточно обработать одну входную строку. К обработке нескольких строк перейдём на следующих этапах.
