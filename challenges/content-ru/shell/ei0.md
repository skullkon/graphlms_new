### Встроенная команда `pwd`

Встроенная команда [`pwd`](https://en.wikipedia.org/wiki/Pwd) (print working directory — вывести рабочий каталог) печатает полный абсолютный путь текущего рабочего каталога в stdout.

При запуске оболочки её текущим рабочим каталогом обычно является каталог, из которого она запущена. Ваша реализация `pwd` должна получить эту информацию у операционной системы и вывести её.

Например:
```bash
$ pwd
/home/user/projects
$ pwd
/usr/local/bin
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке команду `pwd`:

```bash
$ pwd
/path/to/current/directory
$
```

Тестирующая система проверит, что команда `pwd` корректно отображает текущий рабочий каталог.

### Примечания

- Команда `pwd` должна выводить полный абсолютный путь текущего рабочего каталога.
