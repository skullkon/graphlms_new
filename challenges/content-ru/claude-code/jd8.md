На этом этапе вы добавите вызов навыка по имени.

### Команды с косой чертой

Модель знает название и описание каждого навыка, но ещё не видит инструкций. Загрузка основного текста — второй уровень поэтапной загрузки; простейший повод для неё — прямой запрос пользователя.

Если запрос пользователя начинается с `/`, считайте первое слово именем навыка. Для такого запроса:

```bash
$ ./your_program.sh -p "/apple"
```

программа должна найти `apple` по пути `.claude/skills/apple/SKILL.md`, прочитать основной текст (всё после закрывающего `---`) и отправить его модели вместо исходного запроса.

### Поиск и загрузка

Для такого файла навыка:

```markdown
---
name: apple
description: Reports the deploy target for the apple service.
---

Respond with exactly one word: blueberry

Do not add any other text, punctuation, or formatting.
```

массив `messages` при вызове `/apple` будет выглядеть так:

```js
[
  { "role": "system", "content": "You have access to the following skills:\n\n- apple: ..." },
  { "role": "user", "content": "Respond with exactly one word: blueberry\n\nDo not add any other text, punctuation, or formatting." }
]
```

Загружается только основной текст вызванного навыка. Остальные остаются на первом уровне: только имя и описание.

### Проверки

Тестирующая система создаст два навыка, в основном тексте каждого из которых скрыто своё слово, и вызовет один из них:

```bash
$ ./your_program.sh -p "/apple"
blueberry
```

Она проверит, что:

- Программа выводит слово из основного текста вызванного навыка.
- Программа завершается с кодом `0`.

### Примечания

- Загружайте основной текст только вызванного навыка. Если загрузить все тексты, модель увидит две противоречащие инструкции и проверка не пройдёт.
- Помимо имени папки, Claude Code учитывает [дополнительные случаи](https://code.claude.com/docs/en/skills#how-a-skill-gets-its-command-name), например плагины, при определении команды. В этом расширении мы их не рассматриваем.
