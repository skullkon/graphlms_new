На этом этапе вы добавите поддержку присваивания значений переменным с помощью оператора `=`. Слева от присваивания нужно поддержать только уже объявленные переменные.
Обратите внимание: присваивание правоассоциативно, поэтому `a = b = 1` эквивалентно `a = (b = 1)`.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 8.4: Присваивание](https://craftinginterpreters.com/statements-and-state.html#assignment).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими операцию присваивания.

Например, если `test.lox` содержит следующее

```
var a;
var b = 2;
var a = b = 1;
print a;
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
1
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
var quz;
quz = 1;
print quz;
print quz = 2;
print quz;
```

Ожидаемый вывод:

```
1
2
2
```

Тестовый случай 2:

Входные данные:

```
var hello = 93;
var bar = 93;
bar = hello;
hello = bar;
print hello + bar;
```

Ожидаемый вывод:

```
186
```

Тестовый случай 3:

Входные данные:

```
var quz;
var hello;

quz = hello = 16 + 34 * 92;
print quz;
print hello;
```

Ожидаемый вывод:

```
3144
3144
```

Тестовый случай 4:

Входные данные:

```
var hello = 65;
var baz;
var quz;

hello = baz = quz = hello * 2;
print hello;
print baz;
print baz;
```

Ожидаемый вывод:

```
130
130
130
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0.
