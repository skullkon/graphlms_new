На этом этапе вы реализуете [REPL (Read-Eval-Print Loop — цикл чтения, вычисления и вывода)](https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop).

### Цикл REPL

[REPL (Read-Eval-Print Loop)](https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop) — интерактивный цикл, составляющий основу оболочки. Он повторяет следующие шаги:

1. **Чтение**: показать приглашение и дождаться ввода пользователя.
2. **Вычисление**: разобрать и выполнить команду.
3. **Вывод**: показать результат или сообщение об ошибке.
4. **Повторение**: вернуться к шагу `1` и ждать следующую команду.

Этот цикл продолжается неограниченно, пока процесс оболочки не завершится.

Ваша оболочка должна следовать тому же циклу:
1. Показать приглашение `$ `, затем дождаться строки ввода.
2. Вывести `<command_name>: command not found` для любой введённой пользователем команды, как на предыдущих этапах.
3. Вернуться к шагу `1`.

Например, если пользователь вводит `hello`, оболочка должна вывести `hello: command not found`, а затем снова показать приглашение (`$ `).

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке последовательность команд:

```bash
$ invalid_command_1
invalid_command_1: command not found
$ invalid_command_2
invalid_command_2: command not found
$ invalid_command_3
invalid_command_3: command not found
$
```

После каждой команды тестирующая система проверит, что оболочка:
- Выводит сообщение `<command_name>: command not found`.
- Показывает новое приглашение (`$ `), прежде чем система отправит следующую команду.

### Примечания

- Точное количество отправленных команд и их имена будут случайными.
- Цикл должен работать неограниченно. Тестирующая система завершит вашу программу после окончания проверки.
