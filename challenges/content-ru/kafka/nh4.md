На этом этапе вы добавите обработку нескольких последовательных запросов одного клиента.

### Тесты

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем подключится к серверу на порту 9092, отправит запрос `ApiVersions` (v4), прочитает и проверит ответ.

Получив ответ, она повторно использует то же соединение для отправки нескольких других запросов `ApiVersions` (v4).

Для каждого ответа она проверит, что:

- Первые 4 байта ответа («длина сообщения») корректны.
- Идентификатор корреляции в заголовке ответа совпадает с идентификатором в заголовке запроса.
- Код ошибки в теле ответа равен `0` (нет ошибки).
- Тело ответа содержит хотя бы одну запись с ключом API `18` (ApiVersions).
- Значение `MaxVersion` для `ApiKey` `18` не меньше `4`.

### Примечания

- На этом этапе отправляются только запросы ApiVersions (v4).
- Если после декодирования всех полей тела ответа остаются лишние байты, это считается ошибкой.
