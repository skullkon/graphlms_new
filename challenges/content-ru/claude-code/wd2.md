На этом этапе вы добавите передачу аргументов навыку.

### Подстановки

Навык, всегда выполняющий одно и то же, не очень полезен. Настоящие навыки принимают входные данные: *развернуть* <сервис>, *проверить* <файл>.

Навыки [принимают входные данные](https://code.claude.com/docs/en/skills#pass-arguments-to-skills) через подстановки в основном тексте. Программа заменяет их перед отправкой модели. Есть два вида:

| Подстановка | Чем заменяется |
| ----------------------------------- | ---------------------------------------------- |
| `$ARGUMENTS` | Всё после имени навыка одной строкой |
| `$ARGUMENTS[0]`, `$ARGUMENTS[1]`, … | Один аргумент по позиции, начиная с нуля |
| `$0`, `$1`, `$2`, … | Краткая запись для отдельных аргументов |

Оба вида могут встречаться в одном тексте, а одна подстановка — повторяться несколько раз.

### Выполнение подстановок

Для такого вызова:

```bash
$ ./your_program.sh -p "/apple staging eu-west"
```

`$ARGUMENTS` заменяется на `staging eu-west`, `$0` — на `staging`, а `$1` — на `eu-west`.

Поэтому основной текст:

```markdown
Deploy to $0 in region $1. Full request was: $ARGUMENTS
```

отправляется модели в таком виде:

```
Deploy to staging in region eu-west. Full request was: staging eu-west
```

Аргументы разделяются пробельными символами. Обрабатывать кавычки не требуется.

### Проверки

Тестирующая система создаст два навыка и дважды запустит программу.

Основной текст первого навыка просит повторить `$ARGUMENTS`; он вызывается со случайным числом:

```bash
$ ./your_program.sh -p "/apple 4127"
4127
```

Основной текст второго просит вывести `$1`, затем `$0`, поэтому два случайных слова из аргументов возвращаются в обратном порядке:

```bash
$ ./your_program.sh -p "/grape mango pear"
pear mango
```

Она проверит, что:

- Подстановка `$ARGUMENTS` воспроизводит всю строку аргументов.
- Позиционные подстановки дают нужные слова в порядке, указанном в основном тексте.

### Примечания

- Вызов навыка без аргументов тоже должен работать. Заменяйте подстановки пустыми строками.
- Claude Code поддерживает [другие подстановки](https://code.claude.com/docs/en/skills#available-string-substitutions), включая именованные аргументы и переменные сессии. В этом расширении мы их не рассматриваем.
