На этом этапе вы обеспечите загрузку истории из файла в память при запуске оболочки.

### Переменная окружения `HISTFILE`

[Переменная окружения `HISTFILE`](https://www.gnu.org/software///bash/manual/bash.html#index-HISTFILE) задаёт путь к файлу истории.
Этот путь используется для загрузки истории из файла в память при запуске и для сохранения истории из памяти в файл при выходе.


### Проверки

Тестирующая система запишет следующие команды в файл истории:

```txt
echo hello
echo world
<|EMPTY LINE|>
```

Тестирующая система запустит вашу программу следующим образом:

```bash
HISTFILE=<path_to_history_file> ./your_program.sh
```

Затем система отправит оболочке следующие команды:

```bash
$ history
    1  echo hello
    2  echo world
    3 history
$
```
