На этом этапе вы добавите поддержку удаления правил дополнения с помощью `complete -r`.

### Параметр `-r`

Встроенная команда `complete` принимает флаг `-r`, за которым следует имя команды. Он удаляет сохранённое правило дополнения этой команды. После удаления нажатие TAB для неё должно работать так, как если бы дополнение никогда не регистрировалось.

```bash
$ complete -C /path/to/completer_script git
$ git ch<TAB>
$ git checkout             # completion works

$ complete -r git
$ git ch<TAB>              # bell rings, no completion
```

При успешном выполнении команда не должна ничего выводить.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Система зарегистрирует дополнение, удалит его с помощью `-r`, подтвердит через `-p`, что правило исчезло, а затем снова попытается вызвать дополнение.

```bash
$ complete -C /path/to/completer_script git
$ complete -r git
$ complete -p git
complete: git: no completion specification
# Expect: Bell to ring
$ git <TAB>
```

Тестирующая система проверит, что:
- После удаления регистрации `complete -p git` выводит `complete: git: no completion specification`.
- Дополнение по Tab для `git` больше не работает и вызывает звуковой сигнал.

### Примечания

- Если `complete -r` вызывается для команды без зарегистрированного дополнения, оболочка всё равно не должна ничего выводить или считать это ошибкой.
