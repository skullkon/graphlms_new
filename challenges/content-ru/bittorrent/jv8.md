На этом этапе вы скачаете весь файл и сохраните его на диск.

Для начала можно скачать все фрагменты у одного пира. Нужно скачать каждый фрагмент, проверить его целостность по хешу и объединить фрагменты в файл.

### Тесты

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh download -o /tmp/test.txt sample.torrent
```

Она проверит, что файл скачан правильно.

**Необязательно:** для ускорения можно скачивать данные у нескольких пиров одновременно. Например, заведите очередь задач из фрагментов, которые нужно скачать. Обработчик (соединение с пиром) может брать фрагмент из очереди, пытаться скачать его, проверять целостность и записывать скачанный фрагмент в буфер. При любой ошибке — проблеме с сетью, несовпадении хешей, отсутствии фрагмента у пира и т. п. — возвращайте фрагмент в очередь для повторной попытки.
