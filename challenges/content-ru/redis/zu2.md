На этом этапе вы добавите поддержку нескольких клиентов, работающих одновременно.

### Обработка нескольких клиентов

Помимо нескольких команд от одного клиента, серверы Redis могут одновременно обслуживать несколько клиентов.

Для этого понадобятся потоки или, если хочется более сложной задачи, [цикл событий](https://en.wikipedia.org/wiki/Event_loop), как в официальной реализации Redis.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем она одновременно отправит две команды `PING` через два разных соединения:

```bash
# These two will be sent concurrently so that we can test your server's ability to handle concurrent clients.
$ redis-cli PING
$ redis-cli PING
```

Ожидаются два отдельных ответа `+PONG\r\n`.

### Примечания

- Пока тестовый клиент отправляет _только_ команду `PING`, можно игнорировать содержимое запроса и возвращать фиксированный ответ. Разбор клиентского ввода появится на следующих этапах.
