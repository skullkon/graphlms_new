На этом этапе вы установите TCP-соединение с пиром и выполните рукопожатие.

Согласно [протоколу взаимодействия пиров](https://www.bittorrent.org/beps/bep_0003.html#peer-protocol), сообщение рукопожатия состоит из следующих частей:

1. Длина строки протокола (BitTorrent protocol), равная `19` (1 байт).
2. Строка `BitTorrent protocol` (19 байт).
3. Восемь зарезервированных байтов, все равны нулю (8 байт).
4. Хеш SHA-1 infohash (20 байт), **не** его шестнадцатеричное представление длиной 40 байт.
5. Идентификатор пира (20 байт): сгенерируйте 20 случайных байтов.

После отправки рукопожатия пиру мы должны получить ответное рукопожатие в том же формате.

Программа должна вывести шестнадцатеричное представление идентификатора пира, полученного при рукопожатии.

Тестирующая система запустит вашу программу следующим образом:
```
$ ./your_program.sh handshake sample.torrent <peer_ip>:<peer_port>
```
Ожидаемый вывод:
```
Peer ID: 0102030405060708090a0b0c0d0e0f1011121314
```
(Точное значение будет отличаться, поскольку оно генерируется случайно.)

**Примечание**: чтобы получить IP-адрес и порт пира для локальной проверки, выполните `./your_program.sh peers sample.torrent` и выберите любого пира из списка.
