# Бесплатный backend-путь: проверка реализации

Дата: 2026-09-30. Стартовая страница: `/learn/backend`.

Путь включает восемь глав, локальный проект на стандартной библиотеке Go, общие тесты этапов, нагрузочный клиент и открытый эталон. Основы Go и конкурентность подключены как чтение по конкретным этапам. Последний этап требует объяснения архитектуры и самостоятельного изменения правил обработки клиентов.

Главы и ZIP доступны без регистрации. Отметки хранятся в браузере, экспортируются в JSON и явно обозначены как самопроверка. Открытие главы не завершает этап. При повреждённой записи приложение сохраняет исходные данные и блокирует перезапись. Дополнительные услуги не ограничивают самостоятельное обучение; публичная граница описана в `docs/free-core.md`.

## Проверки

- `site/web`: `npm test` — 39 файлов, 174 теста прошли. Проверяются порядок и отрисовка глав, критерии завершения, сохранение повреждённых данных и свободный доступ к учебным возможностям.
- `npm run build` — сборка, TypeScript и генерация всех восьми страниц прошли. Существующие предупреждения относятся к Analytics и twitter-image.
- `npm run content:manifest`, `npm run content:check` — пять курсов, внутренние ссылки и версии контента проверены.
- `npm run qa` — 32 прежних задания прошли проверку комплектности.
- HTTP production preview: маршрут, первая и последняя главы и оба ZIP отвечают 200; неизвестный этап отвечает 404. Архивы имеют корректную ZIP-сигнатуру.
- В браузере проверены стартовая страница, переход к первой главе, доступность критериев и читаемость кнопки скачивания.
- Эталон: общий набор из 17 тестовых функций проходит с `-race`; `go vet` проходит. Подробности в `backend-path-reference-check.md` и `backend-path-student-check.md`.
- Живой нагрузочный запуск: 200 попыток с параллелизмом 8, 69 приняты, 131 отклонена с 429, без сетевых ошибок. После обработки метрики показывают 69 завершённых заданий и пустую очередь. Числа относятся к одному локальному эксперименту.

Упаковка: `node tools/backend-path/package.mjs`. Скрипт синхронизирует тесты и нагрузочный клиент из shared, создаёт архивы с фиксированными порядком, датами и правами. Каждый ZIP содержит README и STAGES. Заготовка компилируется, но тест Analyze сначала должен падать; это исходная точка упражнения.

Проверка агента-ученика — симуляция чтения и запуска. Понятность для реального начинающего ещё предстоит подтвердить наблюдением за его самостоятельным прохождением.
