На этом этапе вы добавите увеличение битовой карты через `SETBIT` и проверку её длины через `STRLEN`.

### Увеличение битовой карты

Если `SETBIT` обращается к смещению за концом строки, Redis увеличивает строку, чтобы вместить его. Строка дополняется нулями, затем устанавливается нужный бит.

[STRLEN](https://redis.io/docs/latest/commands/strlen/) возвращает длину строки в байтах, не в битах. Смещения от `0` до `7` помещаются в одном байте. Смещение `8` — первый бит второго байта. После увеличения ключа через `SETBIT` значение `STRLEN` равно `floor(offset / 8) + 1`. Для смещения `10` это `2`.

```bash
> SETBIT bitmap_key 1 1
(integer) 0
```

После этой команды `SETBIT` Redis создаёт однобайтовую строку `01000000`.

```bash
> SETBIT bitmap_key 10 1
(integer) 0
```

После второго вызова `SETBIT` Redis добавляет второй байт и устанавливает бит со смещением `10` в `1`. Итоговая строка — `01000000 00100000`.

```bash
> STRLEN bitmap_key
(integer) 2
```

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем создаст однобайтовую битовую карту командой `SETBIT`.

```bash
$ redis-cli SETBIT bitmap_key 1 1
```

Она отправит команду `STRLEN` для этого ключа.

```bash
$ redis-cli STRLEN bitmap_key
```

Ожидаемый ответ — `:1\r\n`, то есть 1 в формате [целого числа RESP](https://redis.io/docs/latest/develop/reference/protocol-spec/#integers).

Затем будет отправлена команда `SETBIT` со смещением во втором байте.

```bash
$ redis-cli SETBIT bitmap_key 10 1
```

Ожидаемый ответ — `:0\r\n`.

Далее тестирующая система отправит команды `GETBIT` для нового бита.

```bash
$ redis-cli GETBIT bitmap_key 10
```

Ожидаемый ответ — `:1\r\n`.

```bash
$ redis-cli STRLEN bitmap_key
```

Ожидаемый ответ — `:2\r\n`.

### Примечания

- Достаточно создавать или увеличивать ключ при небольшом смещении; отсутствующий ключ нужно создать. Обрабатывать смещения вне допустимого диапазона не требуется.
- `STRLEN` возвращает длину строки в байтах. Для несуществующего ключа `STRLEN` возвращает `0`.
