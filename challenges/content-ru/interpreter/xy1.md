Код для этого этапа реализован в [разделе 8.1: Инструкции](https://craftinginterpreters.com/statements-and-state.html#statements).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими инструкцию `print`.

Например, если `test.lox` содержит следующее

```
print "Hello, World!";
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
Hello, World!
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

| Входные данные | Ожидаемый вывод |
| :---: | :-------------: |
| `print "Hello, World!";` | `Hello, World!` |
| `print 42;` | `42` |
| `print true;` | `true` |
| `print 12 + 24;` | `36` |

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0.

Тестирующая система также проверит, что ваша программа корректно обрабатывает недопустимые инструкции вывода. Например:

```
print;
```

Тестирующая система проверит, что код завершения равен 65, что означает синтаксическую ошибку.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/string/literals.lox)
- Команда `run` ожидает, что каждая инструкция заканчивается точкой с запятой. Команда `evaluate`, в свою очередь, предназначена для отдельных выражений и не требует точки с запятой. Ваша реализация должна поддерживать оба режима выполнения.
