На этом этапе вы реализуете поддержку обратных косых черт вне кавычек.

### Экранирование обратной косой чертой

Вне кавычек обратная косая черта `\` служит символом экранирования. Она убирает специальное значение следующего символа и делает его буквальным. После экранирования сама обратная косая черта удаляется.

Это работает для любого символа, включая:
- Символы со специальным значением (например, пробел, `'`, `"`, `$`, `*`, `?` и другие разделители).
- Символы без специального значения (обычные буквы, например `n`, `t` и т. д.).

Несколько примеров поведения обратных косых черт вне кавычек:

| Команда | Ожидаемый вывод | Объяснение |
|---------|----------------|-------------|
| `echo three\ \ \ spaces` | <code style="white-space: pre;">three   spaces</code> | Каждое <code style="white-space: pre;">\ </code> создаёт буквальный пробел внутри одного аргумента. |
| <code style="white-space: pre;">echo before\     after</code> | <code style="white-space: pre;">before  after</code> | Обратная косая черта сохраняет первый пробел буквально, но оболочка объединяет последующие неэкранированные пробелы. |
| `echo test\nexample` | `testnexample` | `\n` превращается просто в `n`. |
| `echo hello\\world` | `hello\world` | Первая обратная косая черта экранирует вторую, в результате в аргументе остаётся одна буквальная обратная косая черта. |
| `echo \'hello\'` | `'hello'` | `\'` делает одинарные кавычки буквальными символами. |

### Проверки

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Затем система отправит оболочке последовательность команд `echo`:
```bash
$ echo multiple\ \ \ \ spaces
multiple    spaces
$ echo \'\"literal quotes\"\'
'"literal quotes"'
$ echo ignore\_backslash
ignore_backslash
```

Тестирующая система проверит, правильно ли команда `echo` обрабатывает экранированные символы.

Далее система отправит команду `cat`, где обратные косые черты экранируют символы в аргументах имён файлов:

```bash
$ cat /tmp/\_ignored_1 /tmp/ignore_\2 /tmp/just_one_\\_3
content1 content2 content3
```

Тестирующая система проверит, что команда `cat` правильно обращается к этим файлам.
