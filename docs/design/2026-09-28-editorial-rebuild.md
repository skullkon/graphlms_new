# GraphLMS — новая редакция интерфейса

Заменяет предыдущую концепцию light learning studio по прямой обратной связи пользователя. Референс: https://21st.dev/community/components?paywallSource=pricing — изучены сам сайт, сетка, боковая навигация, плотность и интервалы. Светлая тема сохранена из согласованного направления; вместо мягких карточек используется строгий каталог.

## Решения
- Новая главная: каталог материалов, переключение типов, поиск с пустым состоянием, строка продолжения, табличные темы практики.
- Сетка с общими границами, прямые углы, отступы 12/16/20/24/28px, минимальные радиусы 0–2px.
- Нейтральная палитра: белый, чёрный, серый; спокойные технические обложки курсов. Убраны синие промо-панели, тени и анимация появления.
- Компактная навигация, служебные заголовки, лаконичные подписи. Убраны мотивационные заголовки главной и каталога практики.
- Учебник, рабочее место, авторизация и вспомогательные разделы используют общую нейтральную систему.
- Сохранены реальные маршруты, прогресс, диагностика, редактор и проверка решений.
