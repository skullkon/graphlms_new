На этом этапе вы расширите `XADD`, добавив автоматическую генерацию идентификаторов записей.

### Напоминание о форматах идентификатора в `XADD`

Команда `XADD` принимает идентификаторы в трёх форматах:

- Явный (`1526919030473-0`) — реализовано ранее.
- Автоматический порядковый номер (`1526919030474-*`) — реализовано ранее.
- Автоматические время и порядковый номер (`*`).

На этом этапе вы реализуете третий вариант: идентификатор генерируется целиком.

### Автоматическая генерация идентификаторов

Когда в `XADD` используется `*`, сервер автоматически создаёт уникальный идентификатор новой записи:

- Временная часть — текущее время Unix в миллисекундах, порядковый номер — `0`.
- Если запись с такой временной меткой уже есть, сервер увеличивает порядковый номер на `1`.

Например:

```bash
> XADD stream_key * foo bar
"1526919030474-0"
```

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем создаст запись с идентификатором `*`.

```bash
$ redis-cli XADD stream_key * foo bar
```

Сервер должен ответить строкой вида `$15\r\n1526919030474-0\r\n`: идентификатором `1526919030474-0` в формате [объёмной строки](https://redis.io/docs/latest/develop/reference/protocol-spec/#bulk-strings).

### Примечания

- Временная часть должна быть текущим временем Unix в **миллисекундах**, а не секундах.
- Тест не проверяет случай совпадения временной части и увеличения порядкового номера. Надёжно проверить его сложно: пришлось бы отправлять две команды в одну миллисекунду.
