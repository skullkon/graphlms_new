На этом этапе вы добавите в ответ `ACL GETUSER` установленный флаг `nopass`.

### Флаг `nopass`

Флаг `nopass` — один из пользовательских флагов Redis. Он управляет поведением парольной аутентификации:

- Если для пользователя установлен `nopass`, аутентификация проходит с любым паролем или без пароля.
- Установка `nopass` удаляет все пароли пользователя.

У пользователя `default` флаг `nopass` установлен изначально, поэтому новые соединения аутентифицируются автоматически.

Например:

```bash
> ACL GETUSER default
1) "flags"
2) 1) "nopass"
...
```

Флаги кодируются массивом RESP из bulk strings.

На этом этапе достаточно вернуть установленный `nopass` в ответе `ACL GETUSER`. Реальное поведение флага `nopass` реализуем позже.

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем отправит `ACL GETUSER` для пользователя `default`.

```bash
# Expect RESP array: ["flags", ["nopass"]]
$ redis-cli
> ACL GETUSER default
1) "flags"
2) 1) "nopass"
```

Она проверит, что ответ — массив RESP из двух элементов:
1. Первый элемент — bulk string `flags`.
2. Второй элемент — массив RESP с одним элементом: bulk string `nopass`.
