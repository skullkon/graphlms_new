На этом этапе вы добавите поддержку вычисления операторов равенства `==` и `!=`.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 7.2.5: Вычисление бинарных операторов](https://craftinginterpreters.com/evaluating-expressions.html#evaluating-binary-operators).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими выражения с операторами равенства `==` и `!=`.

Например, если `test.lox` содержит следующее:

```
156 == (89 + 67)
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh evaluate test.lox
true
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

| Входные данные | Ожидаемый вывод |
| :---: | :-------------: |
| `"hello" == "world"` | `false` |
| `"foo" != "bar"` | `true` |
| `"foo" == "foo"` | `true` |
| `61 == "61"` | `false` |

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/expressions/evaluate.lox)
- На этом этапе можно считать, что случаи ошибок не проверяются. Ошибки времени выполнения появятся на следующих этапах. Пока все операции равенства будут выполняться только над числами или строками.
