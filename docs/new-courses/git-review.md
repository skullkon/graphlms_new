# Независимое ревью Git — 2026-09-30

Область: 14 глав site/content/git/book и tools/git-labs. Чужие материалы не редактировались. Проверены модель HEAD/индекс/worktree, подготовка снимков, ветки, merge/conflict, remote-tracking, fetch/pull/push, restore/reset/revert и private rebase, cherry-pick/stash, bisect и публикация файлов.

Обязательных исправлений не обнаружено. Fetch корректно отделён от интеграции, pull --ff-only явно отказывает при расхождении. Rebase ограничен неопубликованной личной линией; soft/mixed сохраняют рабочий текст, revert продолжает общую историю, restore рабочей правки явно допускает потерю только учебного содержимого. Снятие отслеживания не объявляется удалением старых секретов. Примеры ограничены новыми временными репозиториями и локальными bare remotes.

`bash tools/git-labs/smoke.sh` реально выполнен: все 10 групп сценариев PASS, Git2.50.1 (Apple Git-155). Скрипт отключает системную/пользовательскую конфигурацию, внешние шаблоны и Git environment redirects; записи ограничены mktemp, удаление только этой папки. Проверены сохранение индекса вместо рабочего текста, два родителя merge, abort, divergence/non-fast-forward, review/correction, undo режимы, rebase backup/content, cherry-pick/stash, bisect и исторический синтетический config.

Ограничение: smoke проверяет заданные содержательные сценарии, но не буквальное исполнение каждого интерактивного шага каждой главы. GitHub PR, SSH/tokens и LFS-хостинг не выполнялись; они являются необязательным продолжением, а не частью заявления PASS. Скрипт не проверяет конкретный будущий проект пользователя и не подтверждает безопасность произвольного force push.
