На этом этапе вы добавите поддержку навыков, выполняемых субагентом.

### Субагенты

Навык может потребовать выполнения [субагентом](https://code.claude.com/docs/en/skills#run-skills-in-a-subagent) вместо основного агента, которого вы создаёте. Для этого в метаданных задаётся `context: fork`.

Субагент — второй запуск вашего цикла агента с отдельной историей разговора. Он получает основной текст навыка как запрос, выполняет инструкции и возвращает один ответ.

```markdown
---
name: apple
description: Use this skill when the user asks about the on-call rotation.
context: fork
---

Respond with exactly one word: blueberry
```

С добавлением `context:fork` основной текст apple передаётся субагенту. У него новая история разговора, и в основной разговор возвращается только ответ.

### Действия программы

Для `./your_program.sh -p "Who is on the on-call rotation right now?"`:

1. Найдите навыки и сформируйте каталог для системного запроса, как раньше.
2. Модель сопоставляет вопрос с `apple` и вызывает инструмент Skill, как на предыдущих этапах.
3. Перед возвратом основного текста проверьте `context`. Навык `apple` запрашивает субагента, поэтому его инструкции не должны попадать в основной разговор. Создайте **отдельный** список сообщений, содержащий только основной текст навыка, и запустите с ним цикл агента.
4. Верните ответ субагента как результат инструмента. Для приведённого навыка результат может выглядеть так:
  ```
   Skill apple ran in a separate context and returned: blueberry
  ```
5. Продолжите цикл агента в основном разговоре и выведите его ответ.

Шаги 3 и 4 выполняются внутри обработчика инструмента Skill, написанного ранее. До сих пор он возвращал основной текст для любого известного имени; навык с отдельным контекстом — случай, когда возвращается другой результат.

Шаги 3 и 5 используют один и тот же цикл. Субагент — повторный вызов этого цикла с другим списком сообщений, поэтому основная работа здесь — выделить цикл в отдельную функцию.

### Сообщения субагента

История субагента изначально пуста. Он получает только основной текст навыка; вопрос, запустивший навык, ему не передаётся:

```js
[
  { "role": "user", "content": "Respond with exactly one word: blueberry" }
]
```

Допустим, субагент отвечает `blueberry`. Только это слово выходит из субагента. Любое оформление, которым программа окружает его при возврате, как на шаге 4, добавлено вашей программой, а не получено от субагента.

### Проверки

Тестирующая система создаст два навыка со случайными именами. Один из них требует субагента. Она задаст подходящий ему вопрос, а основной текст навыка попросит вывести случайное слово:

```bash
$ ./your_program.sh -p "Who is on the on-call rotation right now?"
The on-call engineer is blueberry.
```

Второй навык тоже создан, но не выбирается: каталог содержит больше одного проверяемого навыка.

Тестирующая система проследит за запросами программы и проверит, что:

- Один запрос содержит инструкции навыка **без** вопроса, который привёл к их запуску.
- Ответ субагента присутствует в выводе программы.

### Примечания

- Навык, требующий субагента, завершает последовательность раскрытия навыков и никогда не раскрывается вместе с другим.
- Claude Code также поддерживает [поле agent](https://code.claude.com/docs/en/skills#run-skills-in-a-subagent), выбирающее тип субагента для выполнения навыка. Разные типы субагентов в этом расширении не рассматриваются.
