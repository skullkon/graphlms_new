### Команда `WATCH`

Redis использует [`WATCH`](https://redis.io/docs/latest/commands/watch/) для [оптимистической блокировки](https://redis.io/docs/latest/develop/using-commands/transactions/#optimistic-locking-using-check-and-set). Команда просит сервер следить за изменениями ключа. Позже, когда клиент выполняет группу команд как [транзакцию](https://redis.io/docs/latest/develop/using-commands/transactions/), сервер проверяет, изменились ли отслеживаемые ключи за это время. Если да, вся транзакция отменяется.

Пример на практике:

```bash
Client A: WATCH counter          # "Tell me if this changes"
Client A: GET counter → 10       # Read current value
Client B: SET counter 20         # Another client sneaks in an update
Client A: MULTI                  # Start a transaction
Client A: SET counter 11         # Queue an update based on stale data
Client A: EXEC                   # Try to execute...
→ (nil)                          # Transaction aborted, counter changed
```

Полную последовательность вы реализуете позже. Пока достаточно разобрать `WATCH` и ответить `+OK\r\n`.

```bash
$ redis-cli WATCH key
OK
```

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем отправит `WATCH`:

```bash
$ redis-cli WATCH key
```

Будет проверено, что:
- Ответ равен `+OK\r\n` (простая строка RESP).
- Программа не падает и не выдаёт ошибок.

### Примечания

- `WATCH` принимает несколько ключей за раз, например `WATCH key1 key2 key3`, но пока достаточно одного ключа. Несколько ключей появятся позже.
- Само отслеживание изменений и отмена транзакции появятся на следующих этапах.
