На этом этапе вы добавите поддержку вычисления числовых и строковых литералов.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 7.2.1: Вычисление литералов](https://craftinginterpreters.com/evaluating-expressions.html#evaluating-literals).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими числовые и строковые литералы.

Например, если `test.lox` содержит следующее:

```
"hello world!"
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh evaluate test.lox
hello world!
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

| Входные данные | Ожидаемый вывод |
| :---: | :-------------: |
| `"hello world!"` | `hello world!` |
| `10.40` | `10.4` |
| `10` | `10` |

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату.

### Примечания

- Для строковых литералов тестирующая система проверит, что программа выводит строку без кавычек.
- Для числовых литералов тестирующая система проверит, что программа выводит число с минимальным количеством знаков после десятичной точки без потери точности. (Например, 10.40 должно выводиться как 10.4.)
- Форматирование чисел немного отличается от этапов лексического и синтаксического анализа, но соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/expressions/evaluate.lox)
