На этом этапе вы добавите поддержку инструкций-выражений. Такая инструкция позволяет разместить выражение там, где ожидается инструкция. Они нужны для вычисления выражений с побочными эффектами.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 8.1: Инструкции](https://craftinginterpreters.com/statements-and-state.html#statements).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими выражения с побочными эффектами вместе с инструкцией `print`.

Например, если `test.lox` содержит следующее

```
"foo" + "bar";
print "baz";
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
baz
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
(37 + 42 - 21) > (76 - 37) * 2;
print !false;
"baz" + "hello" + "quz" + "bar" == "bazhelloquzbar";
print !false;
```

Ожидаемый вывод:

```
true
true
```

Тестовый случай 2:

Входные данные:

```
27 - 60 >= -99 * 2 / 99 + 76;
true == true;
("world" == "bar") == ("baz" != "hello");
print true;
```

Ожидаемый вывод:

```
true
```

Тестовый случай 3:

Входные данные:

```
print "the expression below is invalid";
49 + "baz";
print "this should not be printed";
```

Ожидаемый вывод:

```
the expression below is invalid
Operands must be two numbers or two strings.
[line 2]
```

Тестовый случай 4:

Входные данные:

```
print "79" + "baz";
print false * (18 + 84);
```

Ожидаемый вывод:

```
79baz
Operands must be numbers.
[line 2]
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 70.
