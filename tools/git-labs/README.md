# Локальные лаборатории Git

Курс состоит из 14 глав, начиная с `/git/book/01-model` и заканчивая `/git/book/14-final-project`. Все обязательные задания бесплатны и выполняются локально без GitHub, регистрации, настоящих секретов и сетевого сервера. Для Windows используйте Git Bash; для macOS/Linux — bash. Нужен Git 2.28 или новее.

`smoke.sh` проверяет воспроизводимость учебных механизмов, а не оценивает прохождение человеком. Он создаёт отдельную временную папку, изолирует глобальные и системные настройки Git, использует только фиктивный email example.invalid и удаляет свою папку при завершении. Ваш текущий репозиторий и личные настройки не изменяются. Нагрузка сети, push на внешние адреса и force push отсутствуют.

Из распакованной папки лабораторий:

```sh
git --version
bash smoke.sh
```

Проверяются снимок индекса, коммиты и diff, ветки, merge-конфликт и отмена, bare и два клона, fetch/pull/push с отказом при расхождении, локальное ревью, restore/revert/soft/mixed reset, личный rebase, cherry-pick/stash, bisect, границы ignore и финальная проверка согласованности. В конце ожидается `Git labs smoke: all scenarios passed`.

Если проверка падает, прочитайте первый FAIL и версию Git. Скрипт не меняет старые пользовательские папки и не требует очищать их. Повторяйте запуск после исправления среды. Пустой выход отдельных проверок `test` или `grep` означает успех по коду завершения, а не отсутствие действия.

При самостоятельных уроках используйте новые mktemp-папки из каждой главы. Сценарий smoke не заменяет лаборатории: нужно предсказать результат, выполнить действия самому и объяснить, какие области или ссылки изменились. В финальном проекте нет готового решения нового условия переноса исправления в старую поддерживаемую ветку.
