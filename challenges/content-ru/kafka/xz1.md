### API Produce

[API Produce](https://kafka.apache.org/42/design/protocol/#The_Messages_Produce) (ключ API `0`) используется для отправки сообщений в топик Kafka.

Мы создали интерактивный обозреватель структуры запросов и ответов `Produce`:

- 🔎 [Запрос Produce (v11)](https://binspec.org/kafka-produce-request-v11)
- 🔎 [Ответ Produce (v11)](https://binspec.org/kafka-produce-success-response)

На этом этапе достаточно добавить запись API `Produce` в ответ ApiVersions, реализованный ранее. Так клиенты узнают, что брокер поддерживает API `Produce`. Обработкой запросов `Produce` мы займёмся позже.

### Тесты

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh /tmp/server.properties
```

Затем подключится к серверу на порту 9092 и отправит корректный запрос `ApiVersions` (v4).

Она проверит, что:

- Первые 4 байта ответа («длина сообщения») корректны.
- Идентификатор корреляции в заголовке ответа совпадает с идентификатором в заголовке запроса.
- Код ошибки в теле ответа равен `0` (`NO_ERROR`).
- Тело ответа содержит хотя бы одну запись с ключом API `0` (`Produce`).
- Значение `MaxVersion` для API `Produce` не меньше 11.

### Примечания

- На этом этапе обрабатывать запросы `Produce` не требуется. Мы займёмся этим позже.
- Чтобы проходить предыдущие этапы, по-прежнему нужно включать в ответ запись `ApiVersions`.
- Значения `MaxVersion` для `Produce` и `ApiVersions` различаются: для `ApiVersions` это 4, для `Produce` — 11.
