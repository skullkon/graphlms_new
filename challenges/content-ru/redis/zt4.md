На этом этапе вы добавите ответ на команду `GEOADD`.

### Предварительные требования

Этот этап зависит от расширения [**«Упорядоченные множества»**](https://redis.io/docs/latest/data-types/sorted-sets/). Перед началом убедитесь, что оно пройдено.

### Команда `GEOADD`

Команда [`GEOADD`](https://redis.io/docs/latest/commands/geoadd/) добавляет в ключ местоположение с долготой, широтой и именем.

Пример:

```bash
> GEOADD places -0.0884948 51.506479 "London"
(integer) 1
```

Аргументы `GEOADD`:

1. `key`: ключ для хранения местоположения.
2. `longitude`: долгота.
3. `latitude`: широта.
4. `member`: имя местоположения.

Возвращается число добавленных элементов в формате целого числа RESP.

Здесь достаточно реализовать ответ `GEOADD`. Проверку аргументов и хранение местоположений добавим позже.

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем отправит команду `GEOADD`:

```bash
$ redis-cli GEOADD places 11.5030378 48.164271 Munich
```

Ожидаемый ответ — `:1\r\n`, то есть 1 (число добавленных местоположений) в формате целого числа RESP.

- На этом этапе нужен только ответ на `GEOADD`. Проверку аргументов и хранение местоположений реализуем позже.
