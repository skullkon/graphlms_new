На этом этапе вы добавите вычисление расстояния между двумя местоположениями командой `GEODIST`.

### Команда `GEODIST`

Команда `GEODIST` возвращает расстояние между двумя элементами ключа.

Пример:

```bash
> GEODIST places Munich Paris
"682477.7582"
```

Расстояние возвращается в метрах в формате [bulk string RESP](https://redis.io/docs/latest/develop/reference/protocol-spec/#bulk-strings).

Redis вычисляет расстояние между двумя точками по [формуле гаверсинусов](https://rosettacode.org/wiki/Haversine_formula). Реализацию в исходном коде Redis можно посмотреть [здесь](https://github.com/redis/redis/blob/4322cebc1764d433b3fce3b3a108252648bf59e7/src/geohash_helper.c#L228C1-L228C72).

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем добавит несколько местоположений командой `GEOADD`:

```bash
$ redis-cli
> GEOADD places 11.5030378 48.164271 "Munich"
> GEOADD places 2.2944692 48.8584625 "Paris"
```

Далее отправит несколько команд `GEODIST`, указывая два местоположения:

```bash
> GEODIST places Munich Paris
# Expecting "682477.7582"
```

Она проверит, что ответ — bulk string RESP с расстоянием между ними. Например:

```bash
$11\r\n682477.7582\r\n
```

### Примечания

- При вычислении расстояния используйте радиус Земли 6372797.560856 метра. Это точное значение, [используемое Redis](https://github.com/redis/redis/blob/35aacdf80a0871c933047fc46655b98a73a9374e/src/geohash_helper.c#L52).

- После округления расстояние должно совпадать с фактическим расстоянием между заданными местоположениями с точностью до четырёх знаков после запятой. Например, если ожидается 12345.6789, будут приняты такие значения:
  - `12345.67891`;
  - `12345.6789`;
  - `12345.67889`.
