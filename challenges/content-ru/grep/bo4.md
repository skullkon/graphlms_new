На этом этапе вы добавите обработку нескольких входных строк с выводом всех совпавших фрагментов.

### Вывод нескольких совпадений из нескольких строк

Если входные данные содержат несколько строк, флаг `-o` выводит все совпадения из всех строк, каждое на отдельной строке.

Например:

```bash
# The '\d' pattern matches 1 and 0 separately in multiple lines
$ echo -ne "Line1: 10\nLine2: 42" | grep -o -P '\d'
1
1
0
2
4
2

# The `\d\d` matches a pair of digits, so each pair (if found) is printed in its own line
$ echo -ne "Line01: 50\nLine02: 42" | grep -o -P '\d\d'
01
50
02
42
```

Порядок вывода соответствует порядку входных данных: сначала все совпадения из первой строки, затем из второй и так далее.

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -e "jekyll and hyde\nmickey mouse" | ./your_program.sh -o -E "(jekyll|hyde|mouse)"
jekyll
hyde
mouse
```

Она проверит, что:
- Выведены все совпадения из всех строк, каждое на отдельной строке.
- Совпадения идут по порядку: строка за строкой, совпадение за совпадением.
- Программа завершается с кодом `0`, когда найдено хотя бы одно совпадение.
- Программа ничего не выводит и завершается с кодом `1`, когда совпадений нет.
