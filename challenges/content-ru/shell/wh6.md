На этом этапе вы реализуете дополнение по Tab для нескольких исполняемых файлов с общим префиксом.

### Обработка нескольких совпадений

Когда пользователь вводит префикс команды и нажимает `<TAB>`, оболочка должна найти все исполняемые файлы в PATH с этим префиксом и выполнить следующее:

1. При первом нажатии `<TAB>` подать звуковой сигнал (с помощью `\x07`).
2. При втором нажатии `<TAB>`:
    - Вывести все совпавшие исполняемые файлы на новой строке. Перечислить их **в алфавитном порядке**, разделяя хотя бы одним пробелом (для удобства чтения рекомендуется два).
    - Снова показать приглашение на следующей строке, сохранив исходный префикс команды.
 
Например:

```bash
$ xyz_<TAB><TAB>
xyz_bar  xyz_baz  xyz_quz
$ xyz_
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система установит определённый `PATH` и поместит несколько исполняемых файлов, начинающихся с общего префикса, в разные каталоги из `PATH`.

Наконец, она введёт общий префикс и дважды нажмёт Tab.

```bash
$ xyz_<TAB><TAB>
xyz_bar  xyz_baz  xyz_quz
$ xyz_
```

Тестирующая система проверит, что:
1. Первое нажатие Tab вызывает звуковой сигнал.
2. Второе нажатие Tab показывает все совпавшие исполняемые файлы в алфавитном порядке.
    - Совпадения разделены хотя бы одним пробелом.
    - Совпадения отображаются на новой строке.
3. Приглашение появляется снова с сохранённым исходным вводом.
