# Источники и программа курса алгоритмов

Исследование 30 сентября 2026 года. Цель — практический базовый курс для начинающего Go-разработчика: договор → механизм → доказательство → оценка → независимая проверка. Это не заявление о превосходстве над всеми курсами рынка.

| Открытый материал | Сильная сторона для нашей методики | Адаптация |
|---|---|---|
| [MIT 6.006 syllabus](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/pages/syllabus/) | Связь программирования, модели задачи и анализа; явные предварительные знания | Добавлен мост для новичка: инвариант, база индукции, модель стоимости до сложных алгоритмов |
| [Berkeley CS61B](https://www2.eecs.berkeley.edu/Courses/CS61B/) | Абстрактные типы, структуры, поиск и сортировки | Операции структуры объясняются через пользовательскую задачу; Java не требуется |
| [Princeton Algorithms](https://algs4.cs.princeton.edu/home/) и [лекции](https://algs4.cs.princeton.edu/lectures/) | Темы сгруппированы по структурам и приложениям | Небольшие самостоятельные задачи, явные контрпримеры и стоимость операций |
| [Go sort.Search](https://pkg.go.dev/sort#Search), [container/heap](https://pkg.go.dev/container/heap) | Проверяемые договоры стандартных API | Отличаем интерфейс heap.Pop от метода контейнера; границу поиска от наличия элемента |
| [Go strings](https://go.dev/blog/strings), [maps](https://go.dev/blog/maps), [testing](https://pkg.go.dev/testing) | Семантика языка и исполняемые проверки | Rune/bytes, порядок map, benchmarks и независимые эталоны |

Некоторые прямые открытия Princeton и pkg.go.dev были недоступны через web; данные сопоставлены с официальными поисковыми выдержками и доступными авторскими страницами. Закрытые задания и платные материалы не заявлены изученными. Объяснения, задачи и реализации написаны самостоятельно; структуры курсов использованы как тематические ориентиры.

## Последовательность

16 глав: договоры → сложность → массивы/граница поиска → хеши/окно → стек/очередь → рекурсия → сортировки → дерево поиска → куча → BFS → DFS/топология → Dijkstra → динамика → жадный выбор → DSU → финальный планировщик.

Предварительные знания: базовые функции, циклы, срезы, map и тесты Go. Математические определения вводятся на малых примерах. Полный университетский объём теории сложности, продвинутые строки и реализация всех балансирующих деревьев в этот вводный курс не входят; границы прямо указаны.

## Практика и проверка

Каждая глава имеет самостоятельное задание, критерии готовности и разбор. Комплект tools/algorithm-labs включает открытые эталоны, 13 тестовых функций и три заготовки. Их исходный FAIL обозначен явно. Ключевые оптимизации сравниваются с другими алгоритмами: scan, сортировка, перебор строк/подмножеств, BFS, Bellman–Ford. Финал требует собственного CLI и объяснения смены условий, а не копирования готового приложения.
