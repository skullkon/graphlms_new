На этом этапе вы добавите поддержку явного закрытия соединения с помощью заголовка `Connection: close`.

### Тесты

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Тестирующая система отправит два запроса:
1. Обычный запрос, после которого соединение должно остаться открытым.
2. Запрос с заголовком `Connection: close`, после которого соединение должно закрыться.

```bash
$ curl --http1.1 -v http://localhost:4221/echo/orange --next http://localhost:4221/ -H "Connection: close"
```

Ваш сервер должен:
1. Оставить соединение открытым после первого запроса.
2. Закрыть соединение после второго запроса, содержащего `Connection: close`.
3. Включить заголовок `Connection: close` в ответ при закрытии соединения.

### Примечания
- Заголовок `Connection: close` указывает, что соединение нужно закрыть после ответа.
- Сервер должен включить такой же заголовок в ответ.
- После отправки ответа с `Connection: close` сервер должен закрыть TCP-соединение.
