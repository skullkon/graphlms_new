На этом этапе вы добавите чтение нескольких ключей из файла RDB.

Тестирующая программа создаст файл RDB с несколькими ключами и запустит вашу программу так:

```bash
$ ./your_program.sh --dir <dir> --dbfilename <filename>
```

Затем она отправит серверу команду `KEYS *`.

```bash
$ redis-cli KEYS "*"
```

Ответом на `KEYS *` должен быть массив RESP, элементы которого — ключи.

Например, если файл RDB содержит два ключа, `foo` и `bar`, ожидаемый ответ:

```
*2\r\n$3\r\nfoo\r\n$3\r\nbar\r\n
```

- `*2\r\n` означает, что массив содержит два элемента.
- `$3\r\nfoo\r\n` означает, что первый элемент — объёмная строка со значением `foo`.
- `$3\r\nbar\r\n` означает, что второй элемент — объёмная строка со значением `bar`.
