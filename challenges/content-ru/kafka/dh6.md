На этом этапе вы реализуете ответ Fetch на запрос Fetch без топиков.

🚧 **Мы ещё готовим инструкции для этого этапа**. Ниже приведено описание работы тестирующей системы.

### Тесты

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем подключится к серверу на порту 9092 и отправит запрос `Fetch` (v16) с пустым массивом топиков.

Она проверит, что:

- Первые 4 байта ответа («длина сообщения») корректны.
- Идентификатор корреляции в заголовке ответа совпадает с идентификатором в заголовке запроса.
- Код ошибки в теле ответа равен `0` (нет ошибки).
- Поле `throttle_time_ms` ответа равно `0`.
- Поле `responses` ответа содержит 0 элементов, поскольку в запросе был пустой массив топиков.
