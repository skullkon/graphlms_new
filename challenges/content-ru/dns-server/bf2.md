На этом этапе вы расширите DNS-сервер, чтобы он возвращал раздел вопросов — второй раздел DNS-сообщения.

### Структура раздела вопросов

Раздел вопросов содержит список вопросов (обычно всего 1), которые отправитель хочет задать получателю. Этот раздел присутствует как в запросах, так и в ответах.

Каждый вопрос имеет следующую структуру:

- **Name**: доменное имя в виде последовательности «меток» (подробнее ниже).
- **Type**: 2-байтовое целое число; тип записи (1 для записи A, 5 для CNAME и т. д.; полный список — [здесь](https://www.rfc-editor.org/rfc/rfc1035#section-3.2.2)).
- **Class**: 2-байтовое целое число; обычно имеет значение `1` (полный список — [здесь](https://www.rfc-editor.org/rfc/rfc1035#section-3.2.4)).

В [разделе 4.1.2](https://www.rfc-editor.org/rfc/rfc1035#section-4.1.2) RFC подробно описан формат раздела вопросов. В [разделе 3.2](https://www.rfc-editor.org/rfc/rfc1035#section-3.2) приведены дополнительные сведения о типе и классе.

### Кодирование доменных имён

В DNS-пакетах доменные имена кодируются последовательностью меток.

Метки кодируются как `<length><content>`, где `<length>` — один байт, задающий длину метки, а `<content>` — её содержимое. Последовательность меток завершается нулевым байтом (`\x00`).

Например:

- `google.com` кодируется как `\x06google\x03com\x00` (в шестнадцатеричном виде: `06 67 6f 6f 67 6c 65 03 63 6f 6d 00`).
  - `\x06google` — первая метка.
      - `\x06` — один байт с длиной метки.
      - `google` — содержимое метки.
  - `\x03com` — вторая метка.
      - `\x03` — один байт с длиной метки.
      - `com` — содержимое метки.
  - `\x00` — нулевой байт, завершающий доменное имя.

Как и на предыдущем этапе, тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем она отправит на порт 2053 UDP-пакет с DNS-запросом. Ваша программа должна отправить ответный DNS-пакет, содержащий описанный выше раздел вопросов (вместе с разделом заголовка из предыдущего этапа).

Ожидаемые значения раздела вопросов:

| Поле | Ожидаемое значение |
| ----- | ------------------------------------------------------------------------------------------------------- |
| Name | `\x0ccodecrafters\x02io`, за которым следует нулевой байт (это `codecrafters.io`, закодированное последовательностью меток) |
| Type | 1, закодированное как 2-байтовое целое число с порядком байтов big-endian (соответствует типу записи «A») |
| Class | 1, закодированное как 2-байтовое целое число с порядком байтов big-endian (соответствует классу записи «IN») |

Не забудьте соответствующим образом обновить поле `QDCOUNT` в заголовке и установить идентификатор в `1234`.
