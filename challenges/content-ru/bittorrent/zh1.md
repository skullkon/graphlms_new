На этом этапе вы получите метаданные торрента от пира.

### Сообщение метаданных `data`

Сообщение `data` — ответ на сообщение `request`, отправленное вашим пиром на предыдущем этапе.

Оно содержит сами метаданные, необходимые для скачивания файла.

Сообщение следует стандартному формату сообщений расширений BitTorrent:

- Префикс длины сообщения (4 байта).
- Идентификатор сообщения (1 байт).
  - Равен 20, поскольку сообщение реализовано расширением.
- Полезная нагрузка (переменный размер).
    - Идентификатор сообщения расширения (1 байт).
      - Это идентификатор расширения метаданных вашего пира, отправленный при рукопожатии расширений.
    - Словарь bencode (переменный размер).
      - Выглядит так: `{'msg_type': 1, 'piece': 0, 'total_size': XXXX}`.
      - `msg_type` равен 1, поскольку это сообщение `data`.
      - `piece` равен 0, поскольку в этом задании запрашивается только один фрагмент.
      - `total_size` — длина фрагмента метаданных.
    - Содержимое фрагмента метаданных (переменный размер).

Нас интересует именно содержимое фрагментов метаданных. После объединения они образуют словарь bencode примерно такого вида (для удобства показан в JSON):

```
{
  "piece length": 262144,
  "pieces": "<hash1><hash2>...",
  "name": "debian-12.3.0-amd64-netinst.iso",
  "length": 67108864
}
```

Это тот же [словарь info](https://www.bittorrent.org/beps/bep_0003.html#info-dictionary) из файла .torrent, который вы видели на предыдущих этапах.

Вы можете вычислить его хеш и сравнить с информационным хешем из magnet-ссылки.

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh magnet_info <magnet-link>
```
