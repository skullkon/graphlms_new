На этом этапе вы добавите чтение данных потока командой `XRANGE`.

### Команда `XRANGE`

Команда [`XRANGE`](https://redis.io/docs/latest/commands/xrange/) получает диапазон записей потока.

Она принимает два аргумента: начальный идентификатор `start` и конечный `end`, и возвращает все записи диапазона. Границы включены: записи с идентификаторами, равными `start` и `end`, тоже возвращаются.

Пример работы:

```bash
$ redis-cli XADD some_key 1526985054069-0 temperature 36 humidity 95
"1526985054069-0" # (ID of the first added entry)
$ redis-cli XADD some_key 1526985054079-0 temperature 37 humidity 94
"1526985054079-0"
$ redis-cli XRANGE some_key 1526985054069 1526985054079
1) 1) 1526985054069-0
   2) 1) temperature
      2) 36
      3) humidity
      4) 95
2) 1) 1526985054079-0
   2) 1) temperature
      2) 37
      3) humidity
      4) 94
```

Команда принимает идентификаторы вида `<millisecondsTime>-<sequenceNumber>`, но порядковый номер необязателен. Если он не указан:

- Для `start` порядковый номер по умолчанию равен `0`.
- Для `end` используется максимально возможный порядковый номер.

В действительности ответ отличается от показанного выше: пример уже отформатирован redis-cli.

Настоящий ответ — [массив RESP](https://redis.io/docs/latest/develop/reference/protocol-spec/#arrays), содержащий массивы.

Каждый вложенный массив представляет одну запись и содержит два элемента:

- Идентификатор записи как [объёмную строку](https://redis.io/docs/latest/develop/reference/protocol-spec/#bulk-strings).
- Массив пар «ключ — значение» в виде объёмных строк в порядке добавления.

В приведённом выше примере возвращаемое значение фактически такое:

```json
[
  [
    "1526985054069-0",
    [
      "temperature",
      "36",
      "humidity",
      "95"
    ]
  ],
  [
    "1526985054079-0",
    [
      "temperature",
      "37",
      "humidity",
      "94"
    ]
  ],
]
```

В формате массива RESP:

```text
*2\r\n
*2\r\n
$15\r\n1526985054069-0\r\n
*4\r\n
$11\r\ntemperature\r\n
$2\r\n36\r\n
$8\r\nhumidity\r\n
$2\r\n95\r\n
*2\r\n
$15\r\n1526985054079-0\r\n
*4\r\n
$11\r\ntemperature\r\n
$2\r\n37\r\n
$8\r\nhumidity\r\n
$2\r\n94\r\n
```

*(Ответ разбит на строки для удобства чтения. Реальное возвращаемое значение не содержит дополнительных переводов строк.)*

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем добавит несколько записей в поток.

```bash
$ redis-cli XADD stream_key 0-1 foo bar
"0-1"
$ redis-cli XADD stream_key 0-2 bar baz
"0-2"
$ redis-cli XADD stream_key 0-3 baz foo
"0-3"
```

После этого отправит серверу `XRANGE`.

```bash
$ redis-cli XRANGE stream_key 0-2 0-3
```

Сервер должен ответить массивом RESP с записями из указанного диапазона идентификаторов.

Для примера выше ответ должен выглядеть так (в формате массива RESP):

```json
[
  [
    "0-2",
    [
      "bar",
      "baz"
    ]
  ],
  [
    "0-3",
    [
      "baz",
      "foo"
    ]
  ]
]
```
