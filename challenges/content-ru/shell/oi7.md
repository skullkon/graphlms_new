На этом этапе вы добавите поддержку флага `-p` встроенной команды `complete`.

### Флаг `-p`

Флаг `-p` выводит спецификацию дополнения, зарегистрированную для указанной команды. 

```bash
$ complete -p git
complete -C '/path/to/git/completer' git
```

Если спецификация не зарегистрирована, он выводит сообщение об ошибке в таком формате:

```bash
$ complete -p git
complete: git: no completion specification
```

На этом этапе нужно возвращать только вывод ошибки. Пока не требуется отслеживать спецификации: достаточно распознать `-p` и вывести сообщение об ошибке для любого имени команды после него.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Система выполнит `complete -p` со случайным именем команды:

```bash
$ complete -p <command>
complete: <command>: no completion specification
```

Тестирующая система проверит, что:

- Вывод соответствует формату `complete: <command>: no completion specification`.
- Имя команды в выводе совпадает с переданным после `-p`.
