На этом этапе вы добавите поддержку разрешения и связывания идентификаторов во время компиляции.

Вам потребуется реализовать механизм разрешения имён, который обходит AST и сопоставляет идентификаторы с соответствующими привязками, а затем запускать его отдельным проходом по AST.

Мы говорим о разрешении идентификаторов, потому что на этом этапе вы будете разрешать объявления переменных, присваивания переменным, объявления функций и все остальные узлы AST.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 11.3: Класс разрешения имён](https://craftinginterpreters.com/resolving-and-binding.html#a-resolver-class).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими программы с разрешением и связыванием идентификаторов.

Например, если `test.lox` содержит следующее:

```
var variable = "global";

{
  fun f() {
    print variable;
  }

  f();

  var variable = "local";

  f();
}
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
global
global
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
fun global() {
  print "global";
}

{
  fun f() {
    global();
  }

  f();

  fun global() {
    print "local";
  }

  f();
}
```

Ожидаемый вывод:

```
global
global
```

Тестовый случай 2:

Входные данные:

```
var x = "global";

fun outer() {
  var x = "outer";

  fun middle() {
    fun inner() {
      print x;
    }

    inner();

    var x = "middle";

    inner();
  }

  middle();
}

outer();
```

Ожидаемый вывод:

```
outer
outer
```

Тестовый случай 3:

Входные данные:

```
var count = 0;

{
  fun makeCounter() {
    fun counter() {
      count = count + 1;
      print count;
    }
    return counter;
  }

  var counter1 = makeCounter();
  counter1();
  counter1();

  var count = 0;

  counter1();
}
```

Ожидаемый вывод:

```
1
2
3
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/4a840f70f69c6ddd17cfef4f6964f8e1bcd8c3d4/test/closure/open_closure_in_function.lox)
- Механизм разрешения имён должен обеспечивать сопоставление переменных с правильными областями видимости во время компиляции
