### Встроенная команда `declare`

Встроенная команда `declare` используется для создания и просмотра переменных оболочки. Например,

```bash
$ type declare
declare is a shell builtin
$ declare variable=value
$ declare -p variable
declare -- variable="value"
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем система проверит, что `declare` зарегистрирована как встроенная команда:

```bash
$ type declare
declare is a shell builtin
```

### Примечания

- На этом этапе достаточно зарегистрировать встроенную команду `declare`. Её поведение мы реализуем на следующих этапах.
