### Хранение местоположений в упорядоченном множестве

Местоположения, добавленные командой `GEOADD`, хранятся в упорядоченном множестве. Redis вычисляет для местоположения числовую оценку (score) по его широте и долготе.

Например, следующие две команды в Redis эквивалентны:

```bash
# Adding a location
$ redis-cli GEOADD places_key 2.2944692 48.8584625 location

# This command is equivalent to the command above
$ redis-cli ZADD places_key 3663832614298053 location
```

Реализуйте добавление местоположений в упорядоченное множество при выполнении `GEOADD`.

Пока можно жёстко задать оценку равной 0; её вычисление появится позже.

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем отправит команду `GEOADD`:

```bash
$ redis-cli GEOADD places 2.2944692 48.8584625 Paris
# Expect: (integer) 1
```

Далее командой `ZRANGE` проверит, что местоположение добавлено в упорядоченное множество:

```bash
$ redis-cli ZRANGE places 0 -1
# Expect RESP Array: ["Paris"]
```

### Примечания

- Пока оценку местоположения можно жёстко задать равной 0. Вычисление по широте и долготе реализуем позже.
- Реализация `ZRANGE` рассматривается в расширении упорядоченных множеств.
