На этом этапе вы реализуете добавление вывода команды в конец файла.

### Оператор `>>`

Оператор `>>` добавляет стандартный вывод команды в конец файла. В отличие от `>`, который перезаписывает файл, `>>` дописывает вывод в конец, сохраняя существующее содержимое.

Если файл не существует, он создаётся (как и при `>`). Если файл уже существует, новый вывод добавляется в его конец.

Например:
```bash
$ echo first >> output.txt
$ echo second >> output.txt
$ cat output.txt
first
second
```

Также можно явно написать `1>>`, чтобы добавить стандартный вывод команды в файл. `>>` и `1>>` работают совершенно одинаково.

### Проверки

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Затем система отправит оболочке последовательность команд и попытается добавить их вывод в файл:
```bash
$ ls /tmp/baz >> /tmp/bar/bar.md
$ cat /tmp/bar/bar.md
apple
banana
blueberry

$ echo Hello Emily 1>> /tmp/bar/baz.md
$ echo Hello Maria 1>> /tmp/bar/baz.md
$ cat /tmp/bar/baz.md
Hello Emily
Hello Maria

$ echo List of files: > /tmp/bar/qux.md
$ ls /tmp/baz >> /tmp/bar/qux.md
$ cat /tmp/bar/qux.md
List of files:
apple
banana
blueberry
```

Тестирующая система проверит, что:
- Команды с `>>` добавляют стандартный вывод в указанный файл.
- Команды с `1>>` работают так же, как с `>>`.
- Существующее содержимое файла сохраняется (не перезаписывается).
- Если файлов нет, они создаются.
