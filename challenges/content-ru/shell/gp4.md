На этом этапе вы расширите встроенную команду `cd` для обработки символа `~`.

### Встроенная команда `cd`: напоминание

Напомним, что `cd` может принимать аргументы нескольких типов:

- Абсолютные пути, например `/usr/local/bin`. (Обработаны на ранних этапах.)
- Относительные пути, например `./`, `../`, `./dir`. (Обработаны на предыдущих этапах.)
- Символ `~`.

### Символ `~`

Символ `~` (тильда) — сокращённое обозначение домашнего каталога пользователя. Это удобный способ быстро вернуться в домашний каталог из любой точки файловой системы.

Домашний каталог задаётся переменной окружения [`HOME`](https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/V1_chap08.html#tag_08_03). При получении `cd ~` оболочка должна:

1. Прочитать значение переменной окружения `HOME`.
2. Перейти в этот каталог.

Например:
```bash
$ pwd
/usr/local/bin
$ cd ~
$ pwd
/home/user
$ cd /var/log
$ pwd
/var/log
$ cd ~
$ pwd
/home/user
```   

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке последовательность команд `cd`:

```bash
$ cd /usr/local/bin
$ pwd
/usr/local/bin
$ cd ~
$ pwd
/home/user
$
```

Тестирующая система проверит, что:
- `cd ~` переходит в домашний каталог.
- Домашний каталог соответствует значению переменной окружения `HOME`.

### Примечания

- Большинство языков предоставляет функции чтения переменных окружения (например, `process.env.HOME` в Node.js, `os.getenv('HOME')` в Python или `getenv("HOME")` в C).
