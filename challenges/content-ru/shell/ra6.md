На этом этапе вы реализуете встроенную команду `cd` для обработки абсолютных путей. 

### Встроенная команда `cd`

Встроенная команда `cd` (change directory — сменить каталог) используется для изменения текущего рабочего каталога.

Команда `cd` может обрабатывать аргументы разных типов:

- Абсолютные пути, например `/usr/local/bin`.
- Относительные пути, например `./`, `../`, `./dir`.
- Символ `~`, обозначающий домашний каталог пользователя.

На этом этапе мы сосредоточимся на абсолютных путях.

### Обработка абсолютных путей

Абсолютный путь начинается с `/` и задаёт расположение от корня файловой системы.

Когда `cd` получает абсолютный путь:
- Если каталог существует, перейдите в него.
- Если каталог не существует, выведите `cd: <directory>: No such file or directory`.

Например:
```bash
$ pwd
/home/user
$ cd /usr/local/bin
$ pwd
/usr/local/bin
$ cd /does_not_exist
cd: /does_not_exist: No such file or directory
$ pwd
/usr/local/bin
```

Если смена каталога не удалась, текущий каталог должен остаться прежним.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке последовательность команд `cd`:

```bash
$ cd /usr/local/bin
$ pwd
/usr/local/bin
$ cd /does_not_exist
cd: /does_not_exist: No such file or directory
$
```

Тестирующая система проверит, что:
- Корректные пути меняют каталог.
- Для некорректных путей выводится сообщение `cd: <directory>: No such file or directory`.
- Некорректные пути не меняют текущий каталог.

### Примечания

- Проверяйте существование каталога перед попыткой перехода в него или обрабатывайте ошибку, если переход не удался.
