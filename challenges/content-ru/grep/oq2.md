На этом этапе вы добавите поддержку класса символов «цифры» (`\d`).

### Классы символов

[Классы символов](https://learn.microsoft.com/en-us/dotnet/standard/base-types/character-classes-in-regular-expressions) — специальные шаблоны регулярных выражений, соответствующие определённым наборам символов. Вместо одного заданного символа (например, `"a"` или `"3"`) класс соответствует любому символу из указанной группы.

Класс можно записать обратной косой чертой и следующей за ней буквой, например `\d` или `\w`, обозначающими определённую группу символов.

### Класс символов `\d`

Класс `\d` соответствует одной любой цифре (`0-9`).

Например:
- `\d` должно находить совпадение в `"3"`.
- `\d` должно находить совпадение в `"foo101"`.
- `\d` не должно находить совпадение в `"c"`.
- `\d` не должно находить совпадение в `"Art"`.

Если шаблон содержит `\d`, нужно проверить, есть ли во входной строке хотя бы одна цифра.

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -n "apple123" | ./your_program.sh -E "\d"
```

Программа должна:

- Завершиться с кодом `0`, если во входной строке найдена цифра.
- Завершиться с кодом `1`, если во входной строке нет цифр.

### Примечания

- Чтобы разобраться, как устроены регулярные выражения, реализуйте их самостоятельно с нуля, не используя встроенные средства Go для работы с ними.
