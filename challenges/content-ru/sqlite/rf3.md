На этом этапе вы добавите поддержку фильтрации записей с помощью условия `WHERE`.

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh sample.db "SELECT name, color FROM apples WHERE color = 'Yellow'"
```

Ожидаемый вывод:

```
Golden Delicious|Yellow
```

Пока можно считать, что содержимое таблицы достаточно мало и помещается на корневой странице. Таблицы, занимающие несколько страниц, мы рассмотрим на следующем этапе.
