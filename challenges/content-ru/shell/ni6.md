На этом этапе вы реализуете поддержку [заключения текста в кавычки](https://app.codecrafters.io/concepts/shell-quoting) с использованием одинарных кавычек. 

### Одинарные кавычки

[Одинарные кавычки](https://www.gnu.org/software/bash/manual/bash.html#Single-Quotes) (`'`) отключают любое специальное значение заключённых в них символов. Каждый символ между одинарными кавычками трактуется буквально.

При разборе командной строки оболочкой:

- Символы внутри одинарных кавычек (включая символы экранирования и потенциально специальные символы, такие как `$`, `*` или `~`) теряют специальное значение и трактуются как обычные символы.
- Последовательные пробельные символы (пробелы, табуляции) внутри одинарных кавычек сохраняются, не объединяются и не используются как разделители.
- Строки в кавычках, расположенные рядом, объединяются в один аргумент.

Несколько примеров поведения одинарных кавычек:

| Команда | Ожидаемый вывод | Объяснение |
| :---: | :-------------: | :---------: |
| <code style="white-space: pre;">echo 'hello    world'</code> | <code style="white-space: pre;">hello    world</code> | Пробелы внутри кавычек сохраняются. |
| <code style="white-space: pre;">echo hello    world</code> | `hello world` | Последовательные пробелы объединяются, если не заключены в кавычки. |
| `echo 'hello''world'` | `helloworld` | Соседние строки в кавычках `'hello'` и `'world'` объединяются.
| `echo hello''world` | `helloworld` | Пустые кавычки `''` игнорируются.


### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке последовательность команд `echo`:

```bash
$ echo 'shell hello'
shell hello
$ echo 'world     test'
world     test
$
```

Тестирующая система проверит, правильно ли команда `echo` выводит текст в кавычках.

Затем система также отправит команду `cat`, в которой имя файла заключено в одинарные кавычки:

```bash
$ cat '/tmp/file name' '/tmp/file name with spaces'
content1 content2
```

Тестирующая система проверит, правильно ли команда `cat` выводит содержимое файла.

### Примечания

- Команда `cat` — исполняемый файл, доступный в большинстве систем, поэтому реализовывать её самостоятельно не нужно.
