# Установка GraphLMS на ARM64

Сервер: `178.72.162.192`, Ubuntu 24.04, 4 ГБ памяти. Адрес приложения:
https://learn.178-72-162-192.sslip.io. Существующий THE ROOM обслуживается
отдельным блоком Caddy; перенаправление с IP оставлено за ним.

Исходники и сборка находятся в `/opt/graphlms/releases/20261102-a664090`.
`/opt/graphlms/current` указывает на активный релиз. Node.js установлен из
официального архива для ARM64; контрольная сумма архива проверена.

## Службы

- `graphlms-web`: Next.js standalone, `127.0.0.1:3100`, лимит памяти 768 МБ.
- `graphlms-api`: NestJS, `127.0.0.1:4100`, лимит памяти 512 МБ.
- `graphlms-grader`: существующий Go-грейдер с `RUNNER=piston`, порт 8090.
  Доступ ограничен localhost политикой systemd. Очередь выполняет одну
  задачу за раз; в ожидании может находиться до десяти задач.
- `graphlms-executor`: адаптер протокола Piston на `127.0.0.1:2000`.
  Он запускает одноразовые контейнеры Docker. Это отдельная небольшая
  реализация нужных грейдеру HTTP-методов, а не установка Piston.
- `graphlms-backup.timer`: ежедневная согласованная копия SQLite в 03:20 UTC,
  хранение последних четырнадцати копий на том же сервере.

Caddy направляет `/backend/*` в API, остальные запросы — в Next.js.
Секреты находятся в `/etc/graphlms/*.env` с правами `0600`.
База: `/var/lib/graphlms/app.db`. Она создана заново; пользователи с прежнего
сервера не переносились. Для AI-ментора и OAuth нужны отдельные ключи.
Приём отчётов локального Project Lab отключён: `PROJECT_LAB_LOCAL=0`.

## Исполнение Go

Образ `graphlms-go-sandbox:1.26.4` собирается из официального ARM64-образа
Go командой:

```sh
cd /opt/graphlms/current/site/deploy/vps
DOCKER_BUILDKIT=0 docker build --memory=768m --memory-swap=768m \
  --cpu-quota=100000 -f go-sandbox.Dockerfile \
  -t graphlms-go-sandbox:1.26.4 .
```

Образ содержит предварительно собранную стандартную библиотеку с `-race`.
Во время проверки корневая файловая система, кэш и исходники доступны только
для чтения. Временный каталог ограничен 128 МБ. Контейнер работает без сети,
без capabilities, от UID 65534, с `no-new-privileges`. Лимиты: одно ядро,
768 МБ памяти без swap, 128 процессов, 4 МБ вывода. Тесты запускаются с
`-race` и таймаутом 30 секунд; общий лимит запуска — 55 секунд.

Контейнер удаляется после выполнения. Если удаление не подтверждено,
исполнитель отказывает в новых запусках до перезапуска. При старте и остановке
служба очищает только контейнеры с меткой `graphlms.executor=1`.
Docker socket не передаётся в контейнеры. `RUNNER=local` не используется.

`executor.env` содержит `SANDBOX_IMAGE` с идентификатором подготовленного
образа. `grader.env` задаёт `PISTON_URL=http://127.0.0.1:2000`,
`CONCURRENCY=1`, `MAX_QUEUE=10` и `RATE_LIMIT_PER_MIN=10`.

## Обновление

Готовить следующий релиз в отдельном каталоге. Выполнить `npm ci`, сборки
API и web, `prisma migrate deploy`, перенести `.next/standalone`,
`.next/static`, `public` и `site/content` в runtime. Go-грейдер собирать
с `GOOS=linux GOARCH=arm64 CGO_ENABLED=0`. Имя бинарного файла в службе:
`site/grader/grader-linux-arm64`.

Перед переключением запустить `graphlms-backup.service`. Сохранить текущие
systemd-конфигурации и Caddyfile. Проверить фактические пути в службах web/API
и `GRAPHLMS_ROOT`: при первой установке они указывают на каталог релиза.
Переключить `current`, обновить эти пути и перезапустить службы. Предыдущий
релиз сохранять до завершения HTTP-проверок, регистрации и проверки Go-задачи.
Не заменять секреты и не удалять постоянную базу при обновлении.

Проверка адаптера без Docker:

```sh
python3 -m unittest discover -s site/deploy/vps -p test_container_executor.py
```

## Проверено 2 ноября 2026

Прошли 179 тестов web, тесты Go-грейдера, пять проверок адаптера,
`content:check` для десяти направлений и production-сборки Next.js/NestJS.
Через публичный HTTPS проверены 32 страницы и ресурса, включая интервью,
динамические этапы проектов и WASM. Хеши восьми архивов совпали с исходниками.

Регистрация, вход в независимой сессии, перенос большого черновика и защита
CSRF проверены; временный аккаунт удалён. В браузере запущено Go-интервью
с таймером и открыт тренажёр System Design.

Два запуска реального контейнера подтвердили UID 65534, отсутствие сети,
недоступность секретов и Docker socket, файловые ограничения и лимиты cgroup.
Проверены ошибка компиляции, таймаут и очистка контейнеров. Через публичный
`/api/run` эталон задачи `01` прошёл все пять тестов с `-race` за 14,7 секунды;
сервер выдал подписанное подтверждение PASS. Неверный код получил
`compileError=true`. Обычный запуск на этом сервере может занимать около
15–17 секунд: очередь последовательная, кэш не пополняется пользовательскими запусками.

Службы включены в автозапуск, первая резервная копия базы проверена.
Прямые обращения извне к портам 2000 и 8090 не проходят. Существующий
THE ROOM продолжает возвращать предусмотренный входом HTTP 401.
