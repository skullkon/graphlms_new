На этом этапе вы добавите создание [битовой карты](https://redis.io/docs/latest/develop/data-types/bitmaps/) командой `SETBIT`.

### Битовые карты Redis

Битовые карты хранят отдельные биты (`0` или `1`). В отличие от списков и упорядоченных множеств, это не отдельный тип данных Redis, а строки, доступные для чтения и изменения на уровне битов.

Каждое значение занимает всего один бит, поэтому битовые карты очень экономны по памяти. Они подходят для учёта подписок, подсчёта ежедневных активных пользователей и других задач, где нужен признак «да/нет» для большого числа объектов.

Например, битовая карта подписок на рассылку может выглядеть так:

```
newsletter_subscribers: 10001010
```

Здесь подписаны пользователи с номерами `0`, `4` и `6`. Redis нумерует биты слева направо, начиная со смещения `0`.

### Команда `SETBIT`

Команда [SETBIT](https://redis.io/docs/latest/commands/setbit/) устанавливает бит в `0` или `1` в строковом значении по ключу `key`.

Если `key` не существует, создаётся новая строка и устанавливается бит.

Пример:

```bash
> SETBIT bitmap_key 3 1
(integer) 0
```

Команда `SETBIT` принимает ключ, смещение и значение (`0` или `1`). Она возвращает прежний бит по этому смещению. Для нового ключа это всегда `0`.

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем отправит команду `SETBIT` с ключом, смещением и значением.

```bash
$ redis-cli SETBIT bitmap_key 3 1
```

Она проверит, что ответ равен `:0\r\n`: это 0 (прежний бит по указанному смещению), закодированный как [целое число RESP](https://redis.io/docs/latest/develop/reference/protocol-spec/#integers).

### Примечания

- Поскольку битовые карты — это строки, рекомендуем хранить их в той же структуре данных, что используется для `SET` и `GET`. Это пригодится позже.
- Redis считает смещение `0` старшим битом первого байта. Например, `SETBIT key 1 1` сохраняет байт `01000000`. Это важно для последующей реализации `GETBIT` и `BITCOUNT`.
