На этом этапе вы реализуете перенаправление вывода команды в файл.

### Оператор `>`

Оператор `>` перенаправляет стандартный вывод команды в файл. При использовании `>` вывод, который обычно появляется в терминале, записывается в указанный файл.

Если файл не существует, он создаётся. Если файл уже существует, он перезаписывается (его старое содержимое заменяется).

Например:

```bash
$ echo hello > output.txt
$ cat output.txt
hello
```

### Обозначения файловых дескрипторов

В Unix стандартный вывод обозначается числом `1`. Для его перенаправления можно явно написать `1>`:

```bash
$ echo hello 1> file.txt
```

Однако перенаправление стандартного вывода используется настолько часто, что оболочка позволяет опустить `1` и написать просто `>`:

```bash
$ echo hello > file.txt
```

Обе команды делают совершенно одно и то же.

### Вывод ошибок не перенаправляется

Оператор `>` перенаправляет только стандартный вывод, но не стандартный поток ошибок. Если команда создаёт сообщения об ошибках, они по-прежнему появляются в терминале:

```bash
$ cat nonexistent > output.txt
cat: nonexistent: No such file or directory
$ cat output.txt
$ 
```

Сообщение об ошибке появляется в терминале, а `output.txt` остаётся пустым (или содержит только обычный вывод, если он был).

### Проверки

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Затем система отправит оболочке последовательность команд и перенаправит их вывод в файл:

```bash
$ ls /tmp/baz > /tmp/foo/baz.md
$ cat /tmp/foo/baz.md
apple
blueberry

$ echo Hello James 1> /tmp/foo/foo.md
$ cat /tmp/foo/foo.md
Hello James

$ cat /tmp/baz/blueberry nonexistent 1> /tmp/foo/quz.md
cat: nonexistent: No such file or directory
$ cat /tmp/foo/quz.md
blueberry
```

Тестирующая система проверит, что:
- Команды с `>` перенаправляют стандартный вывод в указанный файл.
- Команды с `1>` работают так же, как с `>`.
- Если файлов нет, они создаются.
- Сообщения об ошибках по-прежнему появляются в терминале (не перенаправляются).
- В файл записывается только стандартный вывод.
