Теперь, когда вы освоили переходы между страницами базы данных, давайте разберёмся глубже и прочитаем данные из строк таблицы.

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh sample.db "SELECT name FROM apples"
```

Ожидаемый вывод:

```
Granny Smith
Fuji
Honeycrisp
Golden Delicious
```

Порядок возвращаемых строк не важен.

На диске строки хранятся в [формате записей](https://www.sqlite.org/fileformat.html#record_format), представляющем собой упорядоченную последовательность значений. Чтобы извлечь данные одного столбца, нужно знать его позицию в последовательности. Для этого потребуется разобрать оператор `CREATE TABLE` таблицы. Оператор `CREATE TABLE` хранится в столбце `sql` таблицы [`sqlite_schema`](https://www.sqlite.org/schematab.html).

Не хотите реализовывать SQL-парсер с нуля? При желании можно использовать доступную зависимость [`xwb1989/sqlparser`](https://github.com/xwb1989/sqlparser).
