На этом этапе вы добавите поддержку дополнения имён каталогов.

### Дополнение имён каталогов

Пока оболочка дополняет имена и пути файлов. Теперь вы расширите её для дополнения каталогов.

Дополнение каталогов помогает пользователям переходить в подкаталоги без ввода полного пути.

Когда пользователь нажимает `<TAB>`, а совпадение является каталогом:
1. Дополните токен совпавшим именем каталога.
2. Добавьте завершающую `/` без пробела.
   
Например:

```bash
$ cd proj<TAB>
$ cd project/
#           ^ note the trailing slash (no space)
```

Завершающая `/` позволяет сразу снова нажать Tab, чтобы дополнить следующий уровень пути.

Ещё несколько примеров:

```bash
# Example 1: Complete a directory
$ rmdir p<TAB>
$ rmdir pig/

# Example 2: Complete into a directory
$ rmdir pig/<TAB>
$ rmdir pig/dog/
```

Во втором примере пользователь уже ввёл `pig/`, затем нажимает Tab, чтобы дополнить до `pig/dog/`.

### Проверки

Тестирующая система создаст вложенные каталоги (например, `pig/dog/`) и запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем она имитирует пользовательский ввод:

```bash
$ ls <TAB>
$ ls pig/
$ ls pig/<TAB>
$ ls pig/dog/
```

Тестирующая система проверит, что:
- Первое нажатие Tab после команды (например, `ls `) дополняет ввод до первого каталога с косой чертой в конце.
- Второе нажатие Tab дополняет ввод до вложенного каталога с косой чертой в конце.
- После косых черт не добавляется пробел.

### Примечания

- Пока достаточно обработать случай с ровно одним совпавшим элементом. Несколько совпадений мы рассмотрим на следующих этапах.
- Должно работать дополнение и файлов, и каталогов. Файлы получают завершающий пробел, а каталоги — косую черту без пробела.
- Проверить, является ли элемент каталогом, можно средствами работы с файловой системой вашего языка (например, `os.path.isdir()` в Python, `fs.statSync().isDirectory()` в Node.js).
