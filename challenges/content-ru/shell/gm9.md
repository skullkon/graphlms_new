На этом этапе вы расширите автодополнение по Tab в оболочке для работы с командами с аргументами.

### Дополнение по Tab с аргументами

На предыдущих этапах вы реализовали базовое дополнение по Tab для встроенных команд. Теперь нужно обеспечить возможность продолжить ввод аргументов после дополнения команды и выполнить полную команду.

Например:

```bash
# 1. User types partial command
$ ech

# 2. User presses <TAB>. Shell autocompletes (note the trailing space)
$ echo 

# 3. User types argument 'hello'
$ echo hello

# 4. User presses <ENTER>. Shell executes the command
hello
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Проверки будут имитировать пользовательский ввод с нажатиями Tab и выполнять встроенные команды, как на предыдущих этапах, но с дополнительными аргументами:

```bash
$ ech<TAB>
$ echo 
$ echo hello<ENTER>
hello

$ ech<TAB>
$ echo
$ echo foo bar<ENTER>
foo bar
```

Тестирующая система проверит, что:
- Дополнение по Tab работает правильно.
- Аргументы, введённые после дополнения, сохраняются.
- Полная команда корректно выполняется со всеми аргументами.
