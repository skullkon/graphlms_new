На этом этапе вы добавите поддержку вычисления выражений в круглых скобках.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 7.2.2: Вычисление выражений в скобках](https://craftinginterpreters.com/evaluating-expressions.html#evaluating-parentheses).

### Проверки

Тестирующая система проверит вашу программу с помощью файла `test.lox`, содержащего выражение с круглыми скобками.

Например, если `test.lox` содержит следующее:

```
("hello world!")
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh evaluate test.lox
hello world!
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

| Входные данные | Ожидаемый вывод |
| :---: | :-------------: |
| `("hello world!")` | `hello world!` |
| `(true)` | `true` |
| `(10.40)` | `10.4` |
| `((false))` | `false` |

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/expressions/evaluate.lox)
- Строковые и числовые литералы должны форматироваться по тем же правилам, что и на предыдущем этапе.
