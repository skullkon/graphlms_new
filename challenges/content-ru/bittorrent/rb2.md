Информационный хеш (info hash) — уникальный идентификатор торрент-файла. Он используется при взаимодействии с трекерами и пирами.

На этом этапе вы вычислите информационный хеш торрент-файла и выведете его в шестнадцатеричном формате.

Для вычисления информационного хеша нужно:

- Извлечь словарь `info` после разбора торрент-файла.
- Закодировать содержимое словаря `info` в bencode.
- Вычислить хеш SHA-1 полученного словаря bencode.

Тестирующая система запустит вашу программу следующим образом:
```
$ ./your_program.sh info sample.torrent
```
Ожидаемый вывод:
```
Tracker URL: http://bittorrent-test-tracker.codecrafters.io/announce
Length: 92063
Info Hash: d69f91e6b2ae4c542468d1073a71d4ea13879a7f
```
