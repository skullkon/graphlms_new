На этом этапе вы добавите отключение подсветки в своей реализации grep с помощью значения цвета `never`.

### Параметр `--color=never`

Если пользователь передаёт параметр `--color=never`:
- Совпавшие строки по-прежнему выводятся.
- Управляющие последовательности ANSI не добавляются.
- Вывод содержит обычный текст без форматирования.

Это соответствует поведению ранних этапов, до добавления подсветки.

Например:

```
$ echo -n "Sally has 3 parrots" | grep --color=never -E "par+ots?"
Sally has 3 parrots
```

### Проверки

Тестирующая система запустит программу так:

```
$ echo -n "I have 5 vegetables" | grep --color=never -E '\d'
I have 5 vegetables
```

Она проверит, что:
- Совпавшие строки выводятся без управляющих последовательностей ANSI.
- Вывод содержит обычный текст.
- Программа завершается с кодом `0`, когда совпадение найдено.
- Программа ничего не выводит и завершается с кодом `1`, когда совпадения нет.
