На этом этапе вы реализуете автодополнение встроенных команд.

### Автодополнение по Tab

Дополнение по Tab — возможность оболочки, помогающая пользователям дополнять команды нажатием клавиши `<TAB>`.

На этом этапе вы реализуете автодополнение для двух встроенных команд: `echo` и `exit`.

Когда пользователь вводит часть команды и нажимает `<TAB>`, оболочка должна:

1. Проверить, совпадает ли введённый текст с началом встроенной команды (а именно `echo` или `exit`).
2. При наличии совпадения дополнить слово.
3. Добавить пробел в конце, чтобы пользователь мог сразу вводить аргументы.

Например, если пользователь вводит `ech` и нажимает Tab, оболочка должна дополнить его до `echo ` (с пробелом в конце).

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система имитирует пользовательский ввод и нажатия Tab:

```bash
$ ech<TAB>
$ echo 

$ exi<TAB>
$ exit 
```

Тестирующая система проверит, что:
- Нажатие Tab после `ech` дополняет ввод до `echo `.
- Нажатие Tab после `exi` дополняет ввод до `exit `.

### Примечания






- Для реализации рекомендуем библиотеку наподобие [readline](https://pkg.go.dev/github.com/chzyer/readline). Большинство современных оболочек и REPL (например, Python REPL) используют [GNU readline](https://www.wikiwand.com/en/articles/GNU_Readline) внутри. Хотя некоторые стандартные поведения, возможно, придётся переопределить, обычно это требует меньше работы, чем реализация с нуля.












- Разные оболочки обрабатывают автодополнение по-разному. Для единообразия рекомендуем использовать [Bash](https://www.gnu.org/software/bash/) при разработке и тестировании.
