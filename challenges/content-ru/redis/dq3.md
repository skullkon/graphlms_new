На этом этапе вы добавите чтение нескольких строковых значений из файла RDB.

Тестирующая программа создаст файл RDB с несколькими ключами и запустит вашу программу так:

```bash
$ ./your_program.sh --dir <dir> --dbfilename <filename>
```

Затем она отправит серверу несколько команд `GET <key>`.

```bash
$ redis-cli GET "foo"
$ redis-cli GET "bar"
```

Ответом на каждую команду `GET <key>` должна быть объёмная строка RESP со значением соответствующего ключа.
