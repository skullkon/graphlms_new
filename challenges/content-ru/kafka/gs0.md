### Тесты

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем подключится к серверу на порту 9092 и отправит корректный запрос `ApiVersions` (v4).

Она проверит, что:

- Первые 4 байта ответа («длина сообщения») корректны.
- Идентификатор корреляции в заголовке ответа совпадает с идентификатором в заголовке запроса.
- Код ошибки в теле ответа равен `0` (нет ошибки).
- Тело ответа содержит хотя бы одну запись с ключом API `1` (FETCH).
- Значение `MaxVersion` для API Fetch не меньше 16.

### Примечания

- На этом этапе обрабатывать запрос `Fetch` не требуется. Мы займёмся этим позже.
- Чтобы пройти предыдущий этап, по-прежнему нужно включать в ответ запись `ApiVersions`.
- Значения `MaxVersion` для `Fetch` и `ApiVersions` различаются: для `ApiVersions` это 4, для `Fetch` — 16.
