На этом этапе вы добавите количество таблиц в вывод команды `.dbinfo`.

### Таблица `sqlite_schema`

Чтобы получить количество таблиц в базе SQLite, нужно изучить её таблицу [`sqlite_schema`](https://www.sqlite.org/schematab.html). Таблица `sqlite_schema` хранит схему базы данных.

Каждой таблице, индексу, представлению и триггеру базы соответствует строка в `sqlite_schema`. Единственное исключение — сама таблица `sqlite_schema`, для которой строки нет.

Чтобы посмотреть содержимое `sqlite_schema`, выполните команду:
```
$ sqlite3 sample.db "SELECT * FROM sqlite_schema;"
```

В этом задании можно считать, что базы содержат только таблицы — без индексов, представлений и триггеров. Поэтому каждая строка в `sqlite_schema` представляет таблицу базы. Следовательно, общее количество таблиц можно получить, подсчитав строки в `sqlite_schema`.

### Страницы

Файл базы SQLite состоит из одной или нескольких [страниц](https://www.sqlite.org/fileformat.html#pages). Все таблицы, включая `sqlite_schema`, хранятся на одной или нескольких [страницах табличного B-дерева](https://www.sqlite.org/fileformat.html#b_tree_pages).

В этом задании можно считать, что таблица `sqlite_schema` достаточно мала и целиком помещается на одной странице. В действительности она иногда занимает несколько страниц. Чтобы получить количество строк в `sqlite_schema`, нужно прочитать страницу `sqlite_schema`.

#### Страница `sqlite_schema`

Подробнее о страницах B-дерева вы узнаете на следующих этапах. Пока достаточно следующего:
- Страница `sqlite_schema` всегда имеет номер 1 и начинается со смещения 0. Заголовок файла является частью страницы.
- Страница `sqlite_schema` хранит строки таблицы `sqlite_schema` в блоках данных, называемых «ячейками». Каждая ячейка хранит одну строку.

Таким образом, количество таблиц в базе равно количеству ячеек на странице `sqlite_schema`.

#### Количество ячеек

Чтобы получить количество ячеек на странице `sqlite_schema`, прочитайте заголовок страницы `sqlite_schema`. Заголовок страницы B-дерева содержит 2-байтовое значение в формате big-endian, задающее количество ячеек на странице. Подробнее — в [официальной документации](https://www.sqlite.org/fileformat.html#b_tree_pages).

Обратите внимание: заголовок страницы отделён от заголовка файла и расположен непосредственно после него.

### Тесты

Тестирующая система запустит вашу программу следующим образом:
```
$ ./your_program.sh sample.db .dbinfo
```

Программа должна вывести следующие значения:
- Размер страницы базы данных.
- Количество таблиц.

```
database page size: 4096
number of tables: 3
```

### Примечания

- Перед реализацией решения полезно изучить `sample.db` и убедиться, что вы понимаете формат файла. Для этого можно выполнить `hexdump -C sample.db` или использовать шестнадцатеричный редактор, например [HexEd.it](https://hexed.it/).
