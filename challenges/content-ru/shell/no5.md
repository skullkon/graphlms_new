На этом этапе вы обработаете дополнение по Tab при наличии нескольких совпадающих элементов.

### Обработка нескольких совпадений

Если текущему префиксу соответствуют несколько файлов или каталогов:
1. Первое нажатие `<TAB>`: вызовите звуковой сигнал (`\x07`), чтобы сообщить о нескольких совпадениях.
2. Последующие нажатия `<TAB>`: выведите все совпадения в алфавитном порядке на новой строке, затем снова покажите приглашение.

При выводе совпадений:
- Разделяйте элементы хотя бы одним пробелом (для удобства чтения рекомендуется два).
- Показывайте каталоги с завершающей `/`.
- Показывайте файлы без завершающего символа.

Например, для элементов `bar.txt` и `foo/`:
```bash
$ stat <TAB>
# Bell rings, no change to input
$ stat <TAB>
bar.txt  foo/
$ stat 
```

Поскольку исходный ввод сохраняется в приглашении, пользователь может продолжить ввод, чтобы сузить набор совпадений.

### Проверки

Тестирующая система создаст несколько элементов (например, `bar.txt` и `foo/`) и запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Затем она имитирует пользовательский ввод:
```bash
$ stat <TAB><TAB>
bar.txt  foo/
$ stat 
```

Тестирующая система проверит, что:
- Первое нажатие Tab вызывает звуковой сигнал.
- Последующие нажатия Tab отображают все совпавшие элементы:
    - Совпадения отсортированы по алфавиту.
    - Совпадения разделены хотя бы одним пробелом.
    - Каталоги показаны с завершающей `/`.
    - Совпадения отображаются на новой строке.
- Приглашение появляется снова с сохранённым исходным вводом.
