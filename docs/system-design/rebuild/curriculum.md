# Системный дизайн: программа пересборки

Дата: 2026-09-30. Версия материалов: 0.9.0. Все маршруты и лаборатории остаются бесплатными. Это собственный учебный курс, а не перевод или замена одной книги.

## Основной путь

Существующие 16 URL и 16 этапов рабочего проекта сохраняются. Их содержание пересмотрено по найденным пробелам, а полезные объяснения и проверки сохранены. Последовательность: приложение → HTTP и сеть → данные → расчёты → нагрузка → кэш → репликация → шардирование → события → realtime → медиа → безопасность → надёжность → эволюция → разбор решения → интервью.

После темы ученик обновляет «Клуб» и предоставляет артефакт. Вводные не требуют заранее знать SQL или распределённые алгоритмы; технические термины вводятся через конкретный путь операции. Для инженерных блоков предварительные знания указаны отдельно.

Порядок блоков не означает, что каждый вводит новый термин ровно один раз. Тема может сначала появиться на базовом уровне и затем раскрыться глубже. Ссылки предварительных знаний позволяют остановиться и восстановить недостающую основу. Числа в кейсах — учебные условия, не показатели компаний.

## Как оценивается понимание

Проверочные вопросы дают обратную связь на конкретный выбор. Лаборатории показывают наблюдаемое поведение ограниченных моделей. Проекты и финальные кейсы требуют самостоятельного объяснения, которое оценивают по рубрике: требования, инварианты, протоколы отказов, численные бюджеты, проверка и эксплуатация. Успешный квиз не называется подтверждением правильности произвольной архитектуры.

Три обязательных действия: воспроизвести нормальную историю; найти контрпример прежнему решению; изменить решение под новое существенное условие. Нельзя компенсировать нарушение вместимости, раскрытие доступа или потерю подтверждённой записи общим числом правильных ответов.
