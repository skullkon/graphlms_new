# Вайбкодинг: от первого запроса до своего харнесса

Курс для начинающего с минимумом кода. Добавлен в существующий каталог GraphLMS под `/vibecoding`. Публикация на рабочем сайте в эту задачу не выполнялась.

Сквозной проект — локальный менеджер задач на Python: добавление, просмотр и завершение. Студент поручает реализацию Claude Code или Codex, формулирует требования, запускает проверки и рассматривает изменения. Финальная работа добавляет одну небольшую функцию и проверяет продолжение работы в новой сессии.

## Программа

1. Вайбкодинг: возможности, ограничения и ответственность.
2. Файлы, терминал, Git и первый запуск.
3. Claude Code, Codex и состав рабочего окружения.
4. Как поставить задачу и определить готовность.
5. Подходы к разработке: прототип, план и маленькие шаги.
6. Контекст, инструкции проекта и продолжение работы.
7. Скиллы: как сделать повторяемую процедуру.
8. MCP: внешние инструменты, доступы и границы доверия.
9. Как проверять результат и разбирать ошибки.
10. Что такое харнесс и почему одного промпта мало.
11. Собираем свой рабочий процесс поверх готового агента.
12. Стоимость, контекст и несколько агентов.
13. От локального прототипа к передаче проекта.
14. Финальная работа: проект, харнесс и защита решения.

Каждая глава содержит ситуацию, объяснение, конкретный пример, самостоятельное задание, критерии и разбор. Ориентир: 2–3 часа чтения и 8–12 часов практики. Практика с живым агентом требует доступа к выбранному сервису; локальные проверки работают без внешних пакетов, сети и API-ключей.

## Материалы

Главы: `site/content/vibecoding/book/*.mdx`.
Практика: `tools/vibecoding-labs/`.
Архив: `site/web/public/downloads/vibecoding-labs.zip`.

В starter реализованы чтение и list, а add и done оставлены для студента. Reference — открытый эталон. Templates содержит документы процесса и пример скилла для установки внутри учебного проекта. Это настройка готового рантайма агента; check.py не реализует автономный цикл модели и не является песочницей.

Учебные ограничения: один пользователь, последовательные команды и локальный JSON. Нет гарантий при конкурентной записи или прерывании сохранения, сервера, синхронизации и авторизации.
