### Встроенная команда `exit`

Встроенная команда [`exit`](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html#exit) завершает оболочку. [Встроенные команды](https://app.codecrafters.io/concepts/what-are-builtin-commands) обрабатываются непосредственно оболочкой без запуска нового процесса.

При получении команды `exit` оболочка должна немедленно завершиться.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке недопустимую команду, а после неё — команду `exit`:

```bash
$ invalid_command_1
invalid_command_1: command not found
$ exit
```

Тестирующая система проверит, что оболочка завершается после получения команды `exit`.
