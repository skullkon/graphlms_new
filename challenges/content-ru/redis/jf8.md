На этом этапе вы добавите поддержку нескольких одновременных транзакций.

### Несколько транзакций

Одновременно могут быть открыты несколько транзакций: `MULTI` уже вызвана, а `EXEC` ещё нет. Каждая транзакция имеет собственную очередь команд.

Например, вы начали транзакцию 1 в одном соединении:

```bash
$ redis-cli
> MULTI
OK
> SET foo 41
QUEUED
> INCR foo
QUEUED
```

И транзакцию 2 в другом:

```bash
$ redis-cli
> MULTI
OK
> INCR foo
QUEUED
```

Если теперь выполнить `EXEC` в транзакции 1, результат будет таким:

```bash
> EXEC
1) OK
2) (integer) 42
```

`OK` — ответ на `SET foo 41`, а `42` — ответ на `INCR foo`.

Для транзакции 2 вызов `EXEC` должен вернуть:

```bash
> EXEC
1) (integer) 43
```

43 — ответ на `INCR foo`. Транзакция 1 установила `foo` в `42`, а `INCR foo` увеличивает его до `43`.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем подключится к серверу несколькими клиентами Redis и отправит несколько команд из каждого соединения:

```bash
$ redis-cli MULTI
> INCR foo
> EXEC
```
