На этом этапе вы добавите чтение значения ключа из файла RDB.

Как и на предыдущих этапах, пока ограничимся файлами RDB с одним ключом.

Тестирующая программа создаст файл RDB с одним ключом и запустит вашу программу так:

```
./your_program.sh --dir <dir> --dbfilename <filename>
```

Затем она отправит серверу команду `GET <key>`.

```bash
$ redis-cli GET "foo"
```

Ответом на `GET <key>` должна быть объёмная строка RESP со значением ключа.

Например, если файл RDB содержит ключ `foo` со значением `bar`, ожидаемый ответ — `$3\r\nbar\r\n`.

В формате RDB строки могут кодироваться тремя способами:

- Строки с префиксом длины.
- Целые числа в виде строк.
- Сжатые строки.

На этом этапе достаточно поддержать строки с префиксом длины. Два остальных типа в этом задании не рассматриваются.

Рекомендуем использовать [эту статью](https://rdb.fnordig.de/file_format.html) как справочник при работе над этапом.
