На этом этапе вы добавите поддержку дополнения имён файлов.

### Дополнение имён файлов

Дополнение имён файлов — возможность оболочки, помогающая пользователям дополнять аргументы имён файлов нажатием клавиши `<TAB>`.

Например:

```bash
$ cat re<TAB>
$ cat readme.txt 
#                ^ note the trailing space
```

Когда пользователь нажимает `<TAB>` при вводе аргумента:

1. Извлеките текст после последнего пробела во вводе (например, `"re"` в `"cat re"`).
2. Найдите в текущем каталоге файлы, начинающиеся с этого префикса.
3. Если файл совпал, дополните имя и добавьте пробел в конце.

Завершающий пробел позволяет пользователю сразу начать ввод следующего аргумента, не добавляя пробел вручную.

### Проверки

Тестирующая система создаст файл в текущем каталоге (например, `readme.txt`) и запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем она имитирует пользовательский ввод с неполным именем файла:

```bash
$ cat re<TAB>
$ cat readme.txt 

$ cat hello<TAB>
$ cat hello_world.py 
```

Тестирующая система проверит, что:

- Нажатие Tab дополняет неполное имя файла до полного.
- После имени файла добавляется пробел.

### Примечания

- На этом этапе достаточно сопоставлять префикс с файлами текущего рабочего каталога. Дополнение во вложенных каталогах мы реализуем на следующих этапах.
- На этом этапе достаточно обрабатывать случаи с одним совпавшим именем файла. Дополнение каталогов и несколько вариантов дополнения мы реализуем на следующих этапах.
- Дополнение работает для любой команды, а не только `cat`. Например, даже для несуществующей команды `xyz` нажатие Tab должно дополнить аргумент: `xyz read<TAB>` превращается в `xyz readme.txt `.
