На этом этапе вы добавите поддержку команды `ACL GETUSER`.

### Команда `ACL GETUSER`

Команда [`ACL GETUSER`](https://redis.io/docs/latest/commands/acl-getuser/) получает свойства указанного пользователя. В Redis пользователь `default` присутствует с самого начала, создавать его не требуется.

Например:

```bash
> ACL GETUSER default
1) "flags"
2) (empty array)
...
```

Возвращается вложенный массив RESP с парами «имя свойства — значение» пользователя:

```bash
[property_name_1, property_value_1, property_name_2, property_value_2, ...]
```

На этом этапе реализуйте только свойство `flags`.

### Свойство `flags`

Свойство `flags` — набор атрибутов, описывающих поведение пользователя или его особые разрешения. Каждый флаг — короткая метка, определяющая часть конфигурации пользователя.

Например, после создания или изменения пользователя массив флагов может выглядеть так:

```bash
> ACL GETUSER alice
1) "flags"
2) 1) "on"
   2) "allkeys"
   3) "allcommands"
```

На этом этапе у пользователя `default` ещё нет выводимых `flags`, поэтому жёстко задайте значение как пустой массив RESP (`[]`).

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем отправит `ACL GETUSER` для пользователя `default`:

```bash
# Expect RESP array: ["flags", []]
$ redis-cli
> ACL GETUSER default
1) "flags"
2) (empty array)
```

Она проверит, что ответ — массив RESP из двух элементов:

1. Первый элемент — bulk string `flags`.
2. Второй элемент — пустой массив RESP.
