На этом этапе вы добавите описание инструмента `Read` в запрос к модели.

### Инструменты

Инструменты — это функции, с помощью которых LLM может выполнять конкретные действия, например читать файлы или запускать команды.

По умолчанию LLM не имеет доступа к окружению пользователя: его файловой системе или терминалу. Поэтому Claude Code предоставляет ряд [инструментов](https://code.claude.com/docs/en/settings#tools-available-to-claude), таких как `Read`, `Write` и `Bash`, позволяющих модели читать и изменять код пользователя.

На этом этапе достаточно сообщить модели об инструменте `Read`; его реализация появится позже.

### Объявление инструментов

Объявляя инструменты, вы сообщаете модели, какие действия ей доступны и какие аргументы они принимают.

Чтобы объявить инструменты, добавьте массив `tools` в существующий запрос стартового кода:

```diff
 {
   "model": "...",
   "messages": [...],
+  "tools": [<tool1 spec>, <tool2 spec>, ...]
 }
```

На этом этапе массив `tools` должен содержать спецификацию инструмента `Read`:

```js
{
  "type": "function",
  "function": {
    "name": "Read",
    "description": "Read and return the contents of a file",
    "parameters": {
      "type": "object",
      "properties": {
        "file_path": {
          "type": "string",
          "description": "The path to the file to read"
        }
      },
      "required": ["file_path"]
    }
  }
}
```

Структура состоит из следующих полей:

- `type`: тип инструмента (для инструментов всегда `"function"`).
- `function`: определение функции.
    - `name`: имя функции (например, "Read").
    - `description`: назначение функции; помогает LLM понять, когда её использовать.
    - `parameters`: JSON-схема параметров функции.
        - `properties`: описание каждого параметра (в данном случае только `file_path`).
        - `required`: список обязательных параметров.

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh -p "How many tools are available to you in this request? Number only."
1
```

Она проверит, что:

- Программа выводит положительное число.
- Программа завершается с кодом `0`.

### Примечания

- Можно выбрать любое разумное имя инструмента `Read`. Тестирующая система выполняет только сквозные проверки по ответу LLM. Например, допустимы имена:
  - `Read`;
  - `read`;
  - `read_file`;
  - `ReadFile` и т. д.
- На этом этапе нужно лишь объявить доступность `Read` в запросе. Обработку вызовов инструментов добавим позже.
- Полную документацию о включении инструментов в запрос см. в [спецификации инструментов OpenRouter API](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion#body-tools).
