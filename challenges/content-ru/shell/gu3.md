На этом этапе вы реализуете поддержку обратных косых черт внутри двойных кавычек.

### Обратные косые черты в двойных кавычках

Внутри [двойных кавычек](https://www.gnu.org/software/bash/manual/bash.html#Double-Quotes) обратная косая черта экранирует только определённые специальные символы: `"`, `\`, `$`, `` ` `` и `newline`. Перед всеми остальными символами обратная косая черта трактуется буквально.

На этом этапе мы рассмотрим:

- `\"`: экранирует двойную кавычку, позволяя `"` присутствовать буквально внутри строки в кавычках.
- `\\`: экранирует обратную косую черту, давая буквальный символ `\`.

На этом этапе мы не рассматриваем следующие случаи:

- `\$`: экранирует знак доллара.
- `` \` ``: экранирует обратную кавычку.
- `\<newline>`: экранирует символ перевода строки.

Несколько примеров поведения обратных косых черт внутри двойных кавычек:

|              Команда               |      Ожидаемый вывод       |
| :--------------------------------: | :------------------------: |
|    `echo "A \\ escapes itself"`    |    `A \ escapes itself`    |
| `echo "A \" inside double quotes"` | `A " inside double quotes` |

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке последовательность команд `echo`:

```bash
$ echo "just'one'\\n'backslash"
just'one'\n'backslash
$ echo "inside\"literal_quote."outside\"
inside"literal_quote.outside"
```

Тестирующая система проверит, правильно ли команда `echo` выводит текст в кавычках.

Затем она также отправит команду `cat`, в которой аргументы имён файлов содержат обратные косые черты внутри двойных кавычек:

```bash
$ cat /tmp/"number 1" /tmp/"doublequote \" 2" /tmp/"backslash \\ 3"
content1 content2 content3
```

Тестирующая система проверит, правильно ли команда `cat` выводит содержимое файла.
