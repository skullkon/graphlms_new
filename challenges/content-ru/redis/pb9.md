На этом этапе вы создадите файл манифеста рядом с файлом AOF.

### Файл манифеста

Манифест сообщает Redis, какие файлы AOF существуют и в каком порядке их воспроизводить при восстановлении. Его имя имеет вид `<appendfilename>.manifest`, а находится он в том же каталоге, что и файл AOF.

Манифест содержит одну строку с описанием ранее созданного файла AOF:

```
file <appendfilename>.1.incr.aof seq 1 type i
```

Значение каждой части:

| Поле | Значение | Смысл |
|---|---|---|
| `file` | `<appendfilename>.1.incr.aof` | Имя файла AOF |
| `seq` | `1` | Порядковый номер файла |
| `type` | `i` | Инкрементальный файл, содержащий команды записи, добавленные по одной |

Например, при запуске с `--appendfilename appendonly.aof` манифест будет называться `appendonly.aof.manifest` и должен содержать:

```
file appendonly.aof.1.incr.aof seq 1 type i
```

На этом этапе порядковый номер и тип можно задать прямо в коде.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh --dir <dir> --appendonly yes --appenddirname <append_dir_name> --appendfilename <append_file_name>
```

Затем проверит, что:

- Каталог `<dir>/<append_dir_name>` существует.
- Пустой файл AOF `<dir>/<append_dir_name>/<append_file_name>.1.incr.aof` существует.
- Манифест `<dir>/<append_dir_name>/<append_file_name>.manifest` существует.
- Манифест содержит строку `file <append_file_name>.1.incr.aof seq 1 type i`.

### Примечания

- Манифест должен создаваться при запуске вместе с файлом AOF.
- Токены в строке манифеста разделяются ровно одним пробелом. Табуляции и лишние пробелы недопустимы.
- Строка манифеста должна завершаться символом перевода строки.
