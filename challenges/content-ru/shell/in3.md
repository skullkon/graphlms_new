На этом этапе вы добавите поддержку записи команд из памяти в файл истории с помощью команды `history -w <path_to_history_file>`.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке следующие команды:

```bash
$ echo hello
hello
$ echo world
world
$ history -w <path_to_history_file>
$
```

После этого тестирующая система ожидает следующее содержимое файла истории:

```txt
echo hello
echo world
history -w <path_to_history_file>
<|EMPTY LINE|>
```

### Примечания
- Если при запуске `history -w` файл не существует, оболочка должна создать его, а затем записать в него команды.
- Тестирующая система ожидает, что команда `history -w` также присутствует в файле истории.
- Файл истории должен завершаться символом перевода строки (отображаемым как пустая строка).
