На этом этапе вы расширите автодополнение по Tab в оболочке, включив в него внешние исполняемые файлы из пользовательского `PATH`.

### Дополнение по Tab для исполняемых файлов

На предыдущих этапах вы реализовали дополнение по Tab для встроенных команд (`echo` и `exit`). Теперь вы расширите его на внешние исполняемые файлы из переменной окружения PATH.

Когда пользователь вводит начало имени исполняемого файла и нажимает `<TAB>`, оболочка должна дополнить его до полного имени.

Например, если `custom_executable` существует в каталоге из PATH, ввод `custom` и нажатие Tab дополняют его до `custom_executable ` (с пробелом в конце).

### Проверки

Тестирующая система создаст исполняемый файл с именем `custom_executable` и добавит его каталог в `PATH`.

Затем она запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Далее система имитирует ввод начала внешней команды и нажатие `<TAB>`:

```bash
$ custom<TAB>
$ custom_executable 
```

Тестирующая система проверит, что оболочка корректно дополняет команду до имени внешнего исполняемого файла.

### Примечания

- PATH может включать каталоги, отсутствующие на диске, поэтому ваш код должен корректно обрабатывать такие случаи.
