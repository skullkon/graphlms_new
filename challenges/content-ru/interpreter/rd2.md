На этом этапе вы добавите поддержку инструкций возврата в функциях в свой интерпретатор Lox.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 10.5: Инструкции возврата](https://craftinginterpreters.com/functions.html#return-statements).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими программы с инструкциями возврата в функциях.

Например, если `test.lox` содержит следующее

```
fun foo() { return 10; }
print foo();
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
10
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
fun fib(n) {
  if (n < 2) return n;
  return fib(n - 2) + fib(n - 1);
}

var start = clock();
print fib(10) == 55;
print (clock() - start) < 5; // 5 seconds
```

Ожидаемый вывод:

```
true
true
```

Тестовый случай 2:

Входные данные:

```
fun f() {
  if (false) return "no"; else return "ok";
}

print f();
```

Ожидаемый вывод:

```
ok
```

Тестовый случай 3:

Входные данные:

```
fun f() {
  while (!true) return "ok";
}

print f();
```

Ожидаемый вывод:

```
nil
```

Тестовый случай 4:

Входные данные:

```
fun f() {
  return;
  print "bad";
}

print f();
```

Ожидаемый вывод:

```
nil
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/4a840f70f69c6ddd17cfef4f6964f8e1bcd8c3d4/test/function/local_recursion.lox)
