На этом этапе вы расширите поддержку конвейеров, включив встроенные команды оболочки.

Встроенные команды (например, `echo`, `type`) должны корректно обрабатываться в составе конвейера — в начале, середине или конце.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит команды с конвейерами, включающими встроенные команды:

```bash
$ echo apple-orange | wc
       1       1      13
$ ls | type exit
exit is a shell builtin
$
```

Тестирующая система проверит, соответствует ли итоговый вывод ожидаемому результату выполнения конвейера с корректной обработкой встроенных команд.
Для команды `type` система проверит корректную обработку встроенной команды и правильный вывод; вывод `ls` не должен отображаться.

### Примечания

- Встроенные команды обычно не требуют создания нового процесса через `fork`/`exec`. Вам потребуется выполнять их внутри процесса оболочки, при этом управляя перенаправлением ввода/вывода, необходимым для конвейера.
