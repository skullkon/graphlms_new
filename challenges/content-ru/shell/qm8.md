На этом этапе вы уточните поведение автодополнения по Tab в оболочке для случаев, когда пользователь вводит недопустимую команду.

### Обработка отсутствующих дополнений

Когда пользователь вводит команду, не совпадающую ни с одной известной встроенной командой, и нажимает `<TAB>`, оболочка должна:

1. Оставить ввод без изменений (не менять введённый пользователем текст).
2. Подать звуковой сигнал, сообщая об отсутствии допустимых дополнений.

Для звукового сигнала в терминал выводится [символ звонка](https://en.wikipedia.org/wiki/Bell_character) `\x07`. Обычно это вызывает звук или визуальную вспышку в зависимости от настроек терминала.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Проверки будут имитировать ввод недопустимой команды и нажатие клавиши `<TAB>`:

```bash
$ xyz<TAB>
$ xyz
```

Тестирующая система проверит, что:
- Если дополнение невозможно, ввод остаётся без изменений.
- Для обозначения отсутствия совпадений выводится символ звукового сигнала.
