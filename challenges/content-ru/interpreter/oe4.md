На этом этапе вы добавите поддержку обработки нескольких инструкций в одной `program`. С этого момента мы будем создавать тестовые программы, состоящие из нескольких инструкций.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 8.1: Инструкции](https://craftinginterpreters.com/statements-and-state.html#statements).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими несколько инструкций.

Например, если `test.lox` содержит следующее

```
print "Hello, World!";
print 42;
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
Hello, World!
42
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
print "world" + "baz" + "bar";
print 27 - 26;
print "bar" == "quz";
```

Ожидаемый вывод:

```
worldbazbar
1
false
```

Тестовый случай 2:

Входные данные:

```
print "hello"; print true;
print false;
print "bar"; print 43;
```

Ожидаемый вывод:

```
hello
true
false
bar
43
```

Тестовый случай 3:

Входные данные:

```
print 81;
    print 81 + 46;
        print 81 + 46 + 19;
```

Ожидаемый вывод:

```
81
127
146
```

Тестовый случай 4:

Входные данные:

```
print true != true;

print "36
10
78
";

print "There should be an empty line above this.";
```

Ожидаемый вывод:

```
false
36
10
78

There should be an empty line above this.
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0.
