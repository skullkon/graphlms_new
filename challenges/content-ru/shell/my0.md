На этом этапе вы добавите поддержку подстановки переменной, значение которой не задано.

### Подстановка незаданных имён

Если переменная не задана, вместо неё подставляется пустая строка — она ничего не добавляет к слову. Любой буквальный текст вокруг неё сохраняется.

```bash
$ declare greeting=hello
$ echo ${greeting}world
helloworld
$ echo ${missing}world
world
```

`${missing}` не задана, поэтому вместо неё ничего не подставляется и остаётся только `world`.
### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Система объявит `existing`, оставит `missing1` и `missing2` незаданными и выполнит:

```bash
$ declare existing=existingsvalue
$ ./custom_exe_1234 ${missing1}end ${existing} ${missing2}
Program was passed 3 args (including program name).
Arg #0 (program name): custom_exe_1234
Arg #1: end
Arg #2: existingsvalue
Program Signature: 5998595441
```

Обратите внимание: `${missing2}` раскрывается в пустую строку без окружающего текста, поэтому оболочка получает пустое слово и полностью удаляет его — третий аргумент не передаётся.

Тестирующая система проверит, что дочерний процесс получает именно эти аргументы после имени программы.
