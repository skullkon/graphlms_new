HTTP-серверы взаимодействуют по TCP — протоколу, на котором основана большая часть веб-трафика. На этом этапе вы реализуете TCP-сервер, прослушивающий порт 4221, как настоящий HTTP-сервер.

### Тесты

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh
```

Затем она попытается подключиться к серверу на порту 4221. Чтобы пройти этап, необходимо успешно установить соединение.

### Примечания

- Чтобы изучить устройство HTTP, вы реализуете сервер с нуля, используя примитивы TCP и не полагаясь на встроенные или сторонние HTTP-библиотеки.
