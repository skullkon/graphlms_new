На этом этапе вы добавите вывод одного совпавшего фрагмента текста.

### Флаг `-o`

Флаг `-o`, также называемый `only-matching`, позволяет выводить только совпавший текст на отдельной строке.

Например:

```bash
$ echo -ne "I have one cow" | grep -o -E 'cow'
cow
```

Если grep находит совпадение при включённом флаге `-o`, нужно:
1. Извлечь подстроку, соответствующую шаблону.
2. Вывести только эту подстроку, а не всю строку.
3. Завершиться с кодом `0`.

Если совпадение не найдено:
1. Ничего не выводить.
2. Завершиться с кодом `1`.

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -n "The king had 7 daughters" | ./your_program.sh -o -E "\d"
7
```

Она проверит, что:
- Программа выводит только совпавший текст, а не всю строку.
- Программа завершается с кодом `0`, когда совпадение найдено.
- Программа ничего не выводит и завершается с кодом `1`, когда совпадения нет.

### Примечания

- Достаточно обработать одну входную строку и одно вхождение шаблона. Вывод нескольких совпадений и обработка нескольких строк появятся на следующих этапах.
