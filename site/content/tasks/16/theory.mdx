## Запас и скорость

Token bucket хранит запас токенов и ограничивает его ёмкостью. Один допуск
стоит один токен; запас пополняется со скоростью rps в секунду. Полный
бакет допускает burst, поэтому не обещает не более rps вызовов в любом окне.

Вместо фонового таймера рассчитывайте пополнение при вызове Allow:

```go
elapsed := now.Sub(lastFill)
if elapsed > 0 {
    tokens += float64(rps) * elapsed.Seconds()
    if tokens > float64(rps) { tokens = float64(rps) }
    lastFill = now
}
if tokens >= 1 {
    tokens--
    return true
}
return false
```

## Дробный остаток

Храните tokens как float64 или явно переносите остаток времени. При 10 rps
за 150ms набирается 1.5 токена. Если округлить до одного и сдвинуть метку
на now, половина токена потеряется. Частое округление будет снижать темп.

## Синхронизация

Мьютекс должен защищать время и запас как единое состояние, включая проверку
и списание. Отдельные атомарные чтения и записи не делают весь алгоритм
атомарным. Allow сразу отказывает при недостатке токена, но краткое ожидание
лока допустимо. Производительность проверяется бенчмарком.

Задайте положительный rps и тестовый источник времени; проверьте burst,
пополнение, долгий простой и несколько частых вызовов с дробным остатком.
