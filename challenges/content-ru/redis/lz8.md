На этом этапе вы добавите обработку `INCR` для отсутствующего ключа.

### Напоминание

Реализация [`INCR`](https://redis.io/docs/latest/commands/incr/) разделена на три этапа:

- Ключ существует и содержит числовое значение (предыдущие этапы).
- Ключ отсутствует (**этот этап**).
- Ключ существует, но значение не является числом (следующие этапы).

Если ключа нет, `INCR` задаёт значение 1. Пример:

```bash
$ redis-cli INCR missing_key
(integer) 1
$ redis-cli GET missing_key
"1"
```

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем подключится к серверу как клиент Redis и выполнит команды:

```bash
$ redis-cli
> INCR foo (expecting ":1\r\n" as the response)
> INCR bar (expecting ":1\r\n" as the response)
```

### Примечания

- Реализация должна по-прежнему проходить тесты предыдущих этапов.
