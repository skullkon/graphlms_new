На этом этапе вы реализуете флаг `-p` встроенной команды declare для случая, когда запрошенная переменная не существует.

### Флаг `-p`

`declare -p NAME` выводит описание переменной `NAME`. Если в хранилище переменных оболочки такой переменной нет, оболочка выводит ошибку.

```bash
$ declare -p variable
declare: variable: not found
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
$ ./your_program.sh
```

Затем система выполнит `declare -p` с именем неопределённой переменной.

```bash
$ declare -p missing_variable
declare: missing_variable: not found
```

### Примечания

- На этом этапе можно жёстко задать вывод встроенной команды `declare`. Хранение переменных оболочки мы реализуем на следующих этапах.
