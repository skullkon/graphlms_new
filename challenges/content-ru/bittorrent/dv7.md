На этом этапе вы скачаете весь файл по magnet-ссылке и сохраните его на диск.

### Команда `magnet_download`

Для проверки программы на этом этапе вводится новая команда `magnet_download`. Она работает так:

```bash
$ ./your_program.sh magnet_download -o /tmp/sample <magnet-link>
```

Она похожа на команду `magnet_download_piece` из предыдущего этапа, но скачивает весь файл, а не один фрагмент. Нужно скачать все фрагменты и объединить их по порядку, чтобы получить полный файл.

### Тесты

Тестирующая система запустит вашу программу следующим образом:
```
$ ./your_program.sh magnet_download -o /tmp/sample <magnet-link>
```

Она проверит, что файл скачан правильно.

### Примечания

- Для локальной проверки можно использовать [эти magnet-ссылки](https://github.com/codecrafters-io/bittorrent-test-seeder/blob/main/torrent_files/magnet_links.txt).
- Для ускорения скачивания можно отправлять запросы конвейером. В [статье об экономике BitTorrent](http://bittorrent.org/bittorrentecon.pdf) рекомендуется держать одновременно до 5 незавершённых запросов, чтобы избежать задержек между отправками блоков.
