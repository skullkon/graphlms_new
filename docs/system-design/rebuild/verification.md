# Проверка курса System Design 0.9.0

30 сентября 2026 года. Пересобраны 16 основных глав и 16 инженерных блоков. Сохранены адреса прежних глав и идентификаторы прогресса. Предварительные знания образуют последовательный маршрут; углублённые блоки могут ссылаться на более ранние инженерные темы.

## Выполненные проверки

- `npm test`: 39 файлов, 176 тестов прошли. Включены реальный Markdown pipeline всех 32 уроков, синтаксис Mermaid, зависимости, ссылки, checkpoints и существующий учебный маршрут.
- `npm run content:check`: пять курсов, ссылки и manifest прошли. Финальный manifest версии 0.9.0 сформирован из опубликованной базы истории; промежуточный локальный hash не сохранялся как отдельный релиз.
- `npm run build`: код завершения 0, 213 статических страниц; проверка TypeScript и lint завершились. Существующие предупреждения Analytics img и twitter-image runtime остаются.
- Python: девять unittest для поиска и журнала операций прошли; stream_lab.py --test прошёл, включая конфликт payload в SQL inbox и rollback. Модели capacity.py и overload.py выполнены.
- ZIP: восемь файлов, целостность проверена, каждый файл совпадает с исходником. Из свежей временной распаковки выполнены четыре команды README. SHA256: `48c52fca132842b8deeb35de8d470e286bcf0202c07d1a046943b637e25ed081`.
- Production HTTP на 127.0.0.1:3000: все 32 урока возвращают 200, скачиваемый ZIP совпадает побайтно, неизвестный инженерный блок возвращает 404.
- В браузере проверены главная страница курса и ledger: видны маршрут 16+16, бесплатный архив, корректные ссылки prerequisites, рабочая тетрадь и переходы между блоками.
- `git diff --check`: прошёл.

## Независимые разборы

Сохранены network-review.md, data-review.md и architecture-review.md. Исправлены переполнение SQLite с переходом в REAL, нестабильный договор отказа insufficient, отсутствие сравнения payload в SQL inbox и небезопасный inline setup SQL. Также согласованы prerequisites и формула баланса с начальным состоянием.

## Границы результата

Дополнительная проверка при подготовке новых курсов: PostgreSQL 18.6 установлен, запущен отдельный временный кластер на Unix socket. Выполнены setup и повторный отказ, lost update, write skew, guard/fresh count и Serializable с SQLSTATE 40001. Прежнее ограничение SQL-исполнения закрыто. transactions.sql содержит setup и ручные двухсессионные сценарии; его запуск не объявлен автоматическим тестированием конкурентных историй.

Исследованы открытые структуры DDIA, Alex Xu/ByteByteGo, Grokking и университетских программ; технические утверждения сверены с первичными источниками. Закрытые книги и платные курсы не заявлены прочитанными целиком. Объяснения, задачи и модели курса написаны самостоятельно.

Результат не подтверждает первое место на рынке или понятность любому новичку: это проверяется человеческим пилотом по существующему /system-design/pilot. Агентская проверка и автоматические тесты не заменяют наблюдение за самостоятельным решением ученика.
