На этом этапе вы добавите поиск в файле, содержащем одну строку.

### Поиск в файле

Если передать `grep` имя файла в качестве аргумента, программа ищет совпадения в его строках:

```bash
# This prints any lines that match search_pattern
$ grep -E "search_pattern" any_file.txt
This is a line that matches search_pattern
```

При поиске в файле `grep`:
- Выводит каждую совпавшую строку в stdout (целиком, а не только совпавшую часть).
- Завершается с кодом `0`, если найдена хотя бы одна совпавшая строка.
- Завершается с кодом `1`, если совпавших строк нет.

На этом этапе обрабатываются только файлы из одной строки. Поддержка многострочных файлов появится позже.

### Проверки

Тестирующая система создаст файлы и выполнит поиск вашей программой:

```bash
# Create test file
$ echo "apple" > fruits.txt

# This must print the matched line to stdout and exit with code 0
$ ./your_program.sh -E "appl.*" fruits.txt
apple

# This must print nothing to stdout and exit with code 1
$ ./your_program.sh -E "carrot" fruits.txt
```

Затем она проверит, что:

- Все совпавшие строки выведены в stdout.
- Код завершения равен `0`, если совпавшие строки есть.
- Код завершения равен `1`, если совпавших строк нет.

### Примечания

- Гарантируется, что файл существует и содержит одну строку.
- Вывод должен содержать всю строку, соответствующую шаблону.
