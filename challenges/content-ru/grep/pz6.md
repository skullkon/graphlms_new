На этом этапе вы добавите вывод нескольких входных строк, соответствующих шаблону.

### Вывод нескольких совпавших строк

Получая несколько входных строк, grep проверяет каждую на соответствие шаблону и выводит все совпавшие строки.

Например:

```bash
$ echo -ne "line1\nline_two\nline3" | grep -E "\d"
line1
line3
```

Здесь grep получает три строки. Он выводит `"line1"` и `"line3"`, поскольку они содержат цифры. Строка `"line_two"` не содержит цифр и не выводится.

Код завершения grep указывает, найдены ли совпадения:

- Если хотя бы одна строка соответствует шаблону, программа завершается с кодом `0`.
- Если ни одна строка не соответствует шаблону, программа завершается с кодом `1`.

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -ne "first_line\n2nd_line\n3rd_line" | ./your_program.sh -E "\d"
```

Она проверит, что:

- Программа выводит все совпавшие строки в stdout, каждую на отдельной строке.
- Программа ничего не выводит, если совпавших строк нет.
- Программа завершается с кодом `0`, если совпала хотя бы одна строка.
- Программа завершается с кодом `1`, если не совпала ни одна строка.
