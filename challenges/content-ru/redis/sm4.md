На этом этапе вы добавите чтение значений с заданным сроком действия.

Тестирующая программа создаст файл RDB с несколькими ключами. У части ключей будет задан срок действия, у остальных — нет. Временные метки истечения срока также будут случайными: одни в прошлом, другие в будущем.

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh --dir <dir> --dbfilename <filename>
```

Затем отправит серверу несколько команд `GET <key>`.

```bash
$ redis-cli GET "foo"
$ redis-cli GET "bar"
```

Если срок действия ключа истёк, ожидается ответ `$-1\r\n` («нулевая объёмная строка»).

Если срок ещё не истёк, ожидается объёмная строка RESP со значением соответствующего ключа.
