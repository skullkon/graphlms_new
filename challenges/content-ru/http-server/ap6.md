На этом этапе вы реализуете эндпоинт `/files/{filename}`, который возвращает клиенту запрошенный файл.

### Тесты

Тестирующая система запустит вашу программу с флагом `--directory`. Программа должна прочитать этот флаг из аргументов командной строки и использовать указанный каталог как корневой для всех запросов файлов.

```
$ ./your_program.sh --directory /tmp/
```

Затем тестирующая система отправит два запроса `GET` к эндпоинту `/files/{filename}`. Каждый запрос соответствует пути `{directory}/{filename}`.

Ответ должен зависеть от того, существует ли файл по пути `{directory}/{filename}`.

#### Первый запрос
Первый запрос будет запрашивать файл, который существует в каталоге файлов:
```
$ echo -n 'Hello, World!' > /tmp/foo
$ curl -i http://localhost:4221/files/foo
```

Сервер должен вернуть ответ `200`, содержащий:
- Заголовок `Content-Type` со значением `application/octet-stream`.
- Заголовок `Content-Length` с размером файла в байтах.
- Тело ответа с содержимым файла.
```
HTTP/1.1 200 OK\r\nContent-Type: application/octet-stream\r\nContent-Length: 13\r\n\r\nHello, World!
```

#### Второй запрос
Второй запрос будет запрашивать файл, которого нет в каталоге файлов:
```
$ curl -i http://localhost:4221/files/non_existant_file
```

Сервер должен вернуть ответ `404`:
```
HTTP/1.1 404 Not Found\r\n\r\n
```
