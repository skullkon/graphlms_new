На этом этапе вы добавите поддержку обработки синтаксических ошибок в выражениях.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 6.3: Синтаксические ошибки](https://craftinginterpreters.com/parsing-expressions.html#syntax-errors).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими синтаксические ошибки.

Например, если `test.lox` содержит следующее:

```
(72 +)
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh parse test.lox
[line 1] Error at ')': Expect expression.
```

Тестирующая система проверит, что код завершения равен 65.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/expressions/parse.lox)
- Сообщения об ошибках следует выводить в `stderr`, а не в `stdout`.
- На этом этапе тестирующая система не проверяет точный текст ошибки, а только завершение программы с кодом 65.
