На этом этапе вы добавите поддержку синтаксиса блоков в свой интерпретатор. Блоки заключаются в фигурные скобки `{}` и используются для группировки инструкций. Они также создают локальные области видимости. Области видимости мы проверим на следующем этапе; пока нужно обработать только синтаксис блоков.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 8.5.2: Синтаксис и семантика блоков](https://craftinginterpreters.com/statements-and-state.html#block-syntax-and-semantics).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими операцию присваивания.

Например, если `test.lox` содержит следующее

```
{
    var foo = "before";
    print foo;
}
{
    var foo = "after";
    print foo;
}
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
before
after
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
{
    var hello = "baz";
    print hello;
}
```

Ожидаемый вывод:

```
baz
```

Тестовый случай 2:

Входные данные:

```
{
    var world = "before";
    print world;
}
{
    var world = "after";
    print world;
}
```

Ожидаемый вывод:

```
before
after
```

Тестовый случай 3:

Входные данные:

```
{
    var hello = 88;
    {
        var foo = 88;
        print foo;
    }
    print hello;
}
```

Ожидаемый вывод:

```
88
88
```

Тестовый случай 4:

Входные данные:

```
{
    var bar = 11;
    var world = 11;
    {
        print bar + world;
}
```

Ожидаемый вывод:

```
[line 6] Error at end: Expect '}' .
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0. Если есть открытые, но не закрытые блоки, должна возникнуть синтаксическая ошибка; в этом случае код завершения должен быть 65.
