На этом этапе вы добавите команду `INCR`.

### Команда INCR

Команда [INCR](https://redis.io/docs/latest/commands/incr/) увеличивает значение ключа на 1.

Пример использования:

```bash
$ redis-cli SET foo 5
"OK"
$ redis-cli INCR foo
(integer) 6
$ redis-cli INCR foo
(integer) 7
```

Если ключа нет, ему присваивается значение 1.

Мы разделим реализацию на три этапа:

- Ключ существует и содержит числовое значение (**этот этап**).
- Ключ отсутствует (следующие этапы).
- Ключ существует, но значение не является числом (следующие этапы).

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем подключится к серверу как клиент Redis и выполнит команды:

```bash
$ redis-cli
> SET foo 41 (expecting "+OK" as the response)
> INCR foo (expecting ":42\r\n" as the response)
```
