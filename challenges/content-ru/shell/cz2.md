На этом этапе вы реализуете вывод сообщений об ошибках для недопустимых команд.

Пример:

```
$ xyz
xyz: command not found
```

Ваша программа должна:

1. Показать приглашение `$ ` (сохраните код предыдущего этапа).
2. Прочитать ввод пользователя.
3. Вывести сообщение об ошибке в точности в таком формате: `{command}: command not found`.
   - Например, если пользователь вводит `xyz`, выведите `xyz: command not found`.

Пока мы будем считать все команды «недопустимыми». На следующих этапах мы добавим выполнение «допустимых» команд, таких как `echo`, `cd` и т. д.
