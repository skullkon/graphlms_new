На этом этапе вы реализуете поддержку конвейеров, включающих более двух команд.

Конвейеры могут связывать несколько команд, соединяя вывод каждой команды со вводом следующей.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит команды с конвейерами из трёх или более звеньев:

```bash
$ cat /tmp/foo/file | head -n 3 | wc
       3       3      10
$ ls -la /tmp/foo | tail -n 5 | head -n 3 | grep "file"
-rw-r--r-- 1 user user     5 Apr 29 10:06 file
$
```

Тестирующая система проверит, соответствует ли итоговый вывод ожидаемому результату выполнения многоступенчатого конвейера.

### Примечания

- Для этого потребуется управлять несколькими каналами и процессами.
- Обеспечьте правильную настройку stdin/stdout для каждой команды в цепочке (кроме stdin первой команды и stdout последней, которые обычно подключены к терминалу или файловым перенаправлениям).
- Правильная очистка процессов и ожидание их завершения крайне важны.
