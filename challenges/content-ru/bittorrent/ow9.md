На этом этапе вы разберёте торрент-файл и выведете сведения о торренте.

Торрент-файл (также называемый [файлом метаинформации](https://www.bittorrent.org/beps/bep_0003.html#metainfo-files)) содержит словарь bencode со следующими ключами и значениями:

- `announce`:
    - URL трекера — центрального сервера, отслеживающего пиров, участвующих в раздаче торрента.
- `info`:
    - Словарь с ключами:
        - `length`: размер файла в байтах для торрента с одним файлом.
        - `name`: предлагаемое имя для сохранения файла или каталога.
        - `piece length`: количество байт в каждом фрагменте.
        - `pieces`: объединённые хеши SHA-1 всех фрагментов.

**Примечание:** файлы .torrent содержат байты, не являющиеся допустимыми символами UTF-8. Если ваш язык представляет строки последовательностью символов Unicode (как [str](https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str) в Python), используйте последовательность байтов (например, [bytes](https://docs.python.org/3/library/stdtypes.html#bytes-objects) в Python).

**Примечание**: для торрентов с несколькими файлами словарь `info` выглядит немного иначе. В этом задании мы реализуем поддержку только однофайловых торрентов.

На этом этапе мы сосредоточимся на извлечении URL трекера и длины файла в байтах.

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh info sample.torrent
```

Ожидаемый вывод:

```
Tracker URL: http://bittorrent-test-tracker.codecrafters.io/announce
Length: 92063
```
