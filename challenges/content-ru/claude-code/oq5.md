На этом этапе вы добавите поддержку инструмента `Bash`.

### Инструмент `Bash`

Инструмент `Bash` позволяет LLM выполнять команды оболочки. Он даёт модели прямой доступ к командной строке для таких действий, как удаление файлов, создание каталогов и запуск скриптов.

Объявите инструмент `Bash` в запросе и выполняйте его по запросу модели.

Пример спецификации `Bash`:

```js
{
  "type": "function",
  "function": {
    "name": "Bash",
    "description": "Execute a shell command",
    "parameters": {
      "type": "object",
      "required": ["command"],
      "properties": {
        "command": {
          "type": "string",
          "description": "The command to execute"
        }
      }
    }
  }
}
```

### Выполнение инструмента `Bash`

Когда модель запрашивает вызов `Bash`:

1. Разберите аргументы и извлеките `command`.
2. Выполните команду средствами запуска оболочки вашего языка, например `subprocess.run()` в Python или `child_process.exec()` в Node.js.
3. Перехватите оба потока команды: stdout и stderr.
4. Верните вывод команды (или сообщение об ошибке при неудаче) модели как сообщение инструмента.

Например, получив команду `rm README_old.md`, выполните её и верните результат, который при успехе будет пустым.

### Проверки

Тестирующая система создаст три файла:
  - `app/main.js` — основной файл проекта;
  - `README.md` — актуальный файл readme;
  - `README_old.md` — старый файл readme.

Затем она запустит программу так:

```bash
$ ./your_program.sh -p "Delete the old readme file."
Deleted README_old.md
```

Она проверит, что:
  - `README_old.md` удалён и больше не существует.
  - `app/main.js` сохранён с исходным содержимым.
  - `README.md` сохранён с исходным содержимым.
  - Программа завершается с кодом `0`.

### Примечания

- Можно выбрать любое разумное имя инструмента оболочки, например `Bash`, `bash`, `RunBashCommand` или `run_bash_command`.
- Результат вызова `Bash` нужно отправить обратно модели в рамках цикла агента.
- Выполняйте команду в том же каталоге, что и вашу программу, а не во временном или другом рабочем каталоге.
