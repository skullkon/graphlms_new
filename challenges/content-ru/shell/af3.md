На этом этапе вы зарегистрируете встроенную команду `jobs`.

### Фоновые задания

Обычно при запуске команды в оболочке она ждёт её завершения, прежде чем снова показать приглашение. Это называется выполнением команды на переднем плане.

Однако команды можно запускать и в фоне, добавив `&` в конце. Фоновые команды не блокируют оболочку, поэтому во время их выполнения можно вводить другие команды.

Например:
```bash
$ sleep 10 &
[1] 12345
$ echo "I can run this immediately"
I can run this immediately
$
```

Оболочка назначает каждой фоновой команде номер задания (например, `[1]`) и идентификатор процесса (например, `12345`).

### Встроенная команда `jobs`

Встроенная команда [`jobs`](https://www.man7.org/linux/man-pages/man1/jobs.1p.html) выводит все фоновые задания, известные оболочке в данный момент. Она показывает их номера, состояние (например, `Running` или `Done`) и сами команды.

На этом этапе вы зарегистрируете `jobs` как встроенную команду, но оставите её реализацию пустой. Если фоновых заданий нет, команда `jobs` не должна ничего выводить: она просто возвращает управление к приглашению.

Например:
```bash
$ type jobs
jobs is a shell builtin
$ jobs
$ 
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Затем она проверит, что `jobs` зарегистрирована как встроенная команда:
```bash
$ type jobs
# Expected
jobs is a shell builtin

# Empty output expected
$ jobs
$ 
```

Тестирующая система проверит, что:
- `type jobs` сообщает, что это встроенная команда оболочки.
- Вызов команды `jobs` не создаёт вывода.


### Примечания

- Полная реализация `jobs` (вывод работающих фоновых заданий) будет рассмотрена на следующих этапах. Пока достаточно зарегистрировать её как встроенную команду с пустой реализацией.
