На этом этапе вы расширите `XADD`, добавив автоматическую генерацию порядкового номера идентификатора записи.

### Напоминание о форматах идентификатора в `XADD`

Команда `XADD` принимает идентификаторы в трёх форматах:

- Явный (`1526919030473-0`) — реализовано ранее.
- Автоматический порядковый номер (`1526919030474-*`).
- Автоматические время и порядковый номер (`*`).

На этом этапе вы реализуете второй вариант: автоматически генерируется только порядковый номер.

### Автоматическая генерация порядковых номеров

Redis назначает порядковый номер по следующим правилам:

- Если в потоке нет записей с заданной временной частью, номер начинается с `0`.
- Если записи с такой временной частью уже есть, новый номер равен последнему плюс `1`.
- Единственное исключение — временная часть `0`: для неё начальный номер равен `1`.

Пример добавления записи с `*` вместо порядкового номера:

```bash
$ redis-cli XADD some_key "1-*" foo bar
"1-0" # The sequence number is 0 if no prior entries exist

$ redis-cli XADD some_key "1-*" bar baz
"1-1" # Adding another entry will increment the sequence number
```

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем отправит `XADD` с `*` вместо порядкового номера.

```bash
$ redis-cli XADD stream_key 0-* foo bar
```

Сервер должен ответить `$3\r\n0-1\r\n`: значением `0-1` в формате [объёмной строки](https://redis.io/docs/latest/develop/reference/protocol-spec/#bulk-strings).

Далее тест отправит ещё одну `XADD` с `*` вместо порядкового номера, но со случайным числом во временной части.

```bash
$ redis-cli XADD stream_key 5-* foo bar
```

Сервер должен ответить `$3\r\n5-0\r\n`: значением `5-0` в формате объёмной строки.

После этого тест повторит ту же команду.

```bash
$ redis-cli XADD stream_key 5-* bar baz
```

Сервер должен ответить `$3\r\n5-1\r\n`: значением `5-1` в формате объёмной строки.

### Примечания

- Временная часть в тесте будет случайной; в примере использовано `5`.
