# Договор менеджера задач

Пользователь: один человек, локальный компьютер. Работа последовательная, без сервера.
Python 3.10+, стандартная библиотека. Путь к данным задаётся --file до подкоманды.

- list: отсутствующий файл означает пустой список; файл не создаётся. Все задачи показываются с id, названием и статусом.
- add: обрезать пробелы по краям; пустое название — ошибка без изменения файла. id = максимальный существующий id + 1, в пустом списке 1. done=false. Существующие задачи сохраняются.
- done: меняется только указанная задача. Отсутствующий id — ошибка без изменения файла. Повторное завершение успешно и не переписывает файл.
- Данные: JSON-список объектов с уникальным положительным целым id, непустым строковым title и булевым done. Булево значение не подходит в качестве id.
- Ошибочный JSON или структура — ошибка с ненулевым кодом и сохранением исходных байтов. Ошибки файловой системы сообщаются как ошибки.
- После нового запуска добавленные задачи и статусы видны.

Не входят в учебный договор: конкурентная запись, сбой питания при сохранении, сеть, аккаунты, удаление и синхронизация.

Дополнительная функция финала: запишите поведение и проверку до реализации.
