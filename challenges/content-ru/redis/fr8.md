На этом этапе вы добавите объединение битовых карт через `BITOP OR`.

### Команда `BITOP OR`

`BITOP OR` устанавливает бит результата, если он установлен хотя бы в одной исходной карте.

В примере две карты созданы командами `SETBIT`: `key1` равна `10001000`, а `key2` — `10000010`.

```bash
> BITOP OR dest key1 key2
(integer) 1
> GETBIT dest 0
(integer) 1
> GETBIT dest 4
(integer) 1
> GETBIT dest 6
(integer) 1
```

После операции `BITOP OR` над `key1` и `key2` получаем карту `dest` со значением `10001010`, поскольку биты `0`, `4` и `6` установлены хотя бы в одной исходной карте.

`BITOP` возвращает длину строки результата в байтах. Здесь это `1`.

Если исходные строки разной длины, Redis считает короткие дополненными нулями до длины самой длинной.

В следующем примере `key1` равна `01000000 00100000` (2 байта), а `key2` — `01000000` (1 байт).

```bash
> BITOP OR dest key1 key2
(integer) 2
> GETBIT dest 1
(integer) 1
> GETBIT dest 10
(integer) 1
```

Карта `key2` рассматривается как `01000000 00000000`. Бит `10` установлен в `key1`, а в `key2` дополнен до `0`, поэтому в результате он установлен. Значение `dest` равно `01000000 00100000`. Команда `BITOP` возвращает `2` — длину результата.

### Проверки

Тестирующая система запустит программу так:

```bash
$ ./your_program.sh
```

Затем создаст две карты одинаковой длины командами `SETBIT`.

```bash
$ redis-cli SETBIT key1 0 1
$ redis-cli SETBIT key1 4 1
$ redis-cli SETBIT key2 0 1
$ redis-cli SETBIT key2 6 1
```

Она отправит `BITOP OR`, сохраняющую результат в новый ключ.

```bash
$ redis-cli BITOP OR dest key1 key2
```

Ожидаемый ответ — `:1\r\n`.

Далее будет отправлена команда `GETBIT` для бита, установленного только в одном источнике.

```bash
$ redis-cli GETBIT dest 4
```

Ожидаемый ответ — `:1\r\n`.

Затем тестирующая система создаст две карты разной длины командами `SETBIT`.

```bash
$ redis-cli SETBIT key3 1 1
$ redis-cli SETBIT key3 10 1
$ redis-cli SETBIT key4 1 1
```

Она отправит `BITOP OR`, сохраняющую результат в новый ключ.

```bash
$ redis-cli BITOP OR dest2 key3 key4
```

Ожидаемый ответ — `:2\r\n`, то есть 2 в формате [целого числа RESP](https://redis.io/docs/latest/develop/reference/protocol-spec/#integers).

Далее будет отправлена команда `GETBIT` для бита за концом более короткого источника.

```bash
$ redis-cli GETBIT dest2 10
```

Ожидаемый ответ — `:1\r\n`.

### Примечания

- `BITOP` поддерживает и другие [операции](https://redis.io/docs/latest/commands/bitop/), например `XOR` и `NOT`, но в этой задаче они не рассматриваются.
