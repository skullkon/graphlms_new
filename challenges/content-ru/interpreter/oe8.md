На этом этапе вы добавите поддержку распознавания фигурных скобок.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 4.5: Распознавание лексем](https://craftinginterpreters.com/scanning.html#recognizing-lexemes).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими фигурные скобки вместе с круглыми.

Например, если `test.lox` содержит следующее:

```
{{}}
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh tokenize test.lox
LEFT_BRACE { null
LEFT_BRACE { null
RIGHT_BRACE } null
RIGHT_BRACE } null
EOF  null
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/tree/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/scanning)
- При выделении токенов допускаются непарные фигурные скобки. На следующих этапах, когда мы перейдём к синтаксическому анализу выражений, такие случаи будут отмечаться как ошибки.
