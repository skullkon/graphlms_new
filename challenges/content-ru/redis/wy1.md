На этом этапе вы добавите ответы на несколько команд [PING](https://redis.io/commands/ping), отправленных через одно соединение.

### Обработка нескольких команд

Завершив отправку ответа на предыдущую команду, сервер Redis сразу начинает ожидать следующую. Благодаря этому клиенты Redis могут отправлять несколько команд через одно соединение.

На этом этапе сервер должен выполнять цикл, непрерывно считывая команды и отправляя ответы через то же соединение. Пока мы работаем только с командой `PING`, программа может просто читать входные данные в цикле и отвечать `+PONG\r\n`.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем она отправит несколько команд `PING` через одно соединение.

Например:

```bash
$ echo -e "PING\nPING" | redis-cli
```

Для каждой отправленной команды ожидается ответ `+PONG\r\n`.

### Примечания

- Программа получит не просто байты `PING`, а что-то вроде `*1\r\n$4\r\nPING\r\n`: это представление команды `PING` в протоколе Redis.
- Как и на предыдущем этапе, можно задать ответ `+PONG\r\n` прямо в коде. К разбору клиентского ввода мы перейдём позже.
- Тестирующая программа отправит команды `PING` через одно соединение. Обработка нескольких соединений появится на следующих этапах.
