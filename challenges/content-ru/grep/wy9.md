На этом этапе вы добавите поддержку квантификатора `{n}`.

### Квантификатор `{n}`

Квантификатор `{n}` требует ровно `n` совпадений предшествующего элемента.

Например:
- `ca{3}t` находит совпадение в `"caaat"` (ровно три `"a"`).
- `ca{3}t` не находит совпадения в `"caat"` (только две `"a"`).
- `ca{3}t` не находит совпадения в `"caaaat"` (слишком много `"a"`).
- `d\d{2}g` находит совпадение в `"d42g"` (ровно две цифры).
- `d\d{2}g` не находит совпадения в `"d1g` (только одна цифра).
- `d\d{2}g` не находит совпадения в `"d123g"` (слишком много цифр).
- `c[xyz]{4}w` находит совпадение в `"czyxzw"` (ровно четыре символа из `[xyz]`).
- `c[xyz]{4}w` не находит совпадения в `"cxyzw"` (только три символа из `[xyz]`).

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -n "appleee" | ./your_program.sh -E "applee{2}"
```

Программа должна:
- Завершиться с кодом `0`, если входная строка соответствует шаблону.
- Завершиться с кодом `1` в противном случае.
