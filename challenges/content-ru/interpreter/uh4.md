На этом этапе вы добавите поддержку синтаксического анализа операторов сравнения: `>`, `<`, `>=` и `<=`.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 6.2: Синтаксический анализ методом рекурсивного спуска](https://craftinginterpreters.com/parsing-expressions.html#recursive-descent-parsing).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими операторы сравнения вместе с ранее введёнными токенами.

Например, если `test.lox` содержит следующее:

```
83 < 99 < 115
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh parse test.lox
(< (< 83.0 99.0) 115.0)
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату.
