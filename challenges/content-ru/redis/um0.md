На этом этапе вы добавите чтение потока командой `XREAD`.

### Команда `XREAD`

Команда [`XREAD`](https://redis.io/docs/latest/commands/xread/) читает данные одного или нескольких потоков, начиная с заданного идентификатора записи.

В отличие от `XRANGE`, которой нужны `start` и `end`, `XREAD` принимает только один идентификатор.

Другое отличие: `XREAD` не включает границу. Команда получает все записи с идентификатором строго больше указанного.

Базовый синтаксис:

```bash
XREAD STREAMS <key> <id>
```

`XREAD` поддерживает другие необязательные аргументы, но пока мы их не рассматриваем.

Пример поведения:

```bash
$ redis-cli XADD some_key 1526985054069-0 temperature 36 humidity 95
"1526985054069-0"

$ redis-cli XADD some_key 1526985054079-0 temperature 37 humidity 94
"1526985054079-0"

$ redis-cli XREAD STREAMS some_key 1526985054069-0
1) 1) "some_key"
   2) 1) 1) 1526985054079-0
         2) 1) temperature
            2) 37
            3) humidity
            4) 94
```

Возвращается массив потоков, каждый из которых содержит:

- Ключ потока как объёмную строку.
- Массив записей, где каждая запись — массив из двух частей:
  - Идентификатор записи как объёмная строка.
  - Массив пар «ключ — значение» как объёмных строк.

Ответ для примера выше:

```json
[
  [
    "some_key",
    [
      [
        "1526985054079-0",
        [
          "temperature",
          "37",
          "humidity",
          "94"
        ]
      ]
    ]
  ]
]
```

В формате массива RESP он выглядит так:

```text
*1\r\n
*2\r\n
$8\r\nsome_key\r\n
*1\r\n
*2\r\n
$15\r\n1526985054079-0\r\n
*4\r\n
$11\r\ntemperature\r\n
$2\r\n37\r\n
$8\r\nhumidity\r\n
$2\r\n94\r\n
```

(*Результат показан на отдельных строках для удобства чтения. Реальное возвращаемое значение — одна строка.*)

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем отправит `XADD`, чтобы добавить запись в поток.

```bash
$ redis-cli XADD stream_key 0-1 temperature 96
```

После этого тест отправит серверу `XREAD`.

```bash
$ redis-cli XREAD STREAMS stream_key 0-0
```

Сервер должен ответить массивом RESP с нужными записями потока.

Для примера выше ответ будет таким, в формате массива RESP:

```json
[
  [
    "stream_key",
    [
      [
        "0-1",
        [
          "temperature",
          "96"
        ]
      ]
    ]
  ]
]
```
