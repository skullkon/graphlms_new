На этом этапе вы реализуете третий шаг рукопожатия репликации.

### Напоминание о рукопожатии

Рукопожатие состоит из трёх шагов:

- Реплика отправляет ведущему `PING` (реализовано ранее).
- Реплика дважды отправляет ведущему `REPLCONF` (реализовано ранее).
- Реплика отправляет ведущему `PSYNC`.

### Команда `PSYNC`

Получив ответ на вторую `REPLCONF`, реплика отправляет ведущему команду [`PSYNC`](https://redis.io/commands/psync/).

Команда `PSYNC` синхронизирует состояние реплики с ведущим. Формат команды:

```bash
PSYNC <replication_id> <offset>
```

Она принимает два аргумента: текущий идентификатор репликации ведущего и текущее смещение реплики.

При первом подключении реплики:

- Идентификатор репликации равен `?`, поскольку идентификатор ведущего ещё неизвестен.
- Смещение равно `-1`, поскольку данных от ведущего ещё нет.

Итоговая команда — `PSYNC ? -1`, закодированная как массив RESP:

```
*3\r\n$5\r\nPSYNC\r\n$1\r\n?\r\n$2\r\n-1\r\n
```

Ведущий ответит [простой строкой](https://redis.io/docs/latest/develop/reference/protocol-spec/#simple-strings) примерно такого вида:

```
+FULLRESYNC <REPL_ID> 0\r\n
```

Пока этот ответ можно игнорировать. Его обработка появится позже.

### Тесты

Тестирующая программа запустит вашу программу так:

```
./your_program.sh --port <PORT> --replicaof "<MASTER_HOST> <MASTER_PORT>"
```

Затем проверит, что реплика подключилась к ведущему и отправила команды:

1. `PING`
2. `REPLCONF` с аргументами `listening-port` и `<PORT>`.
3. `REPLCONF` с аргументами `capa psync2`.
4. `PSYNC` с аргументами `? -1`.
