# Итоговая проверка новых курсов

30 сентября 2026 года. Git — 14 глав, Linux — 14, базы данных — 13, алгоритмы — 16. Всего 57 полноценных глав с практикой, критериями и открытыми разборами. Исследования программ и первичных материалов сохранены отдельно.

## Платформа

- `npm test`: 40 файлов, 179 тестов — PASS. Новый тест проверяет четыре каталога, граф последовательности, теги навыков, sitemap и рендер всех 57 глав реальным Markdown pipeline.
- `npm run content:check`: девять курсов, ссылки и manifest — PASS. Четыре новых курса имеют версию 0.10.0; System Design 0.9.0 сохранён как единый ещё не опубликованный снимок. Промежуточные локальные хеши не записывались отдельными релизами.
- `npm run build`: код завершения 0, 278 статических страниц; TypeScript и lint — PASS. Существующие предупреждения Analytics img и twitter-image runtime остаются. После сборки удалены два конечных пробела, manifest повторно проверен; видимое содержимое не изменилось.
- Production HTTP: 57 уроков и страницы четырёх курсов отвечают 200; book redirects приводят к содержанию; пять ZIP совпадают побайтно с архивами; неизвестные course/lesson возвращают 404. Sitemap включает новые главы.
- Браузер: каталог Git показывает 14 глав и бесплатные лаборатории; первая глава отображает код, самостоятельное задание, разбор, версию 0.10.0 и переход к следующей.
- `git diff --cached --check`: PASS после удаления двух конечных пробелов.

## Исполняемая практика

Git: автор выполнил smoke из десяти групп и отдельно все 23 shell-блока глав. Другой агент повторил smoke; интегратор выполнил его из распакованного ZIP. Все проверки — PASS.

Linux: переносимый smoke, ручной HTTP-сервер, ограниченное ожидание готовности и восстановление старой версии — PASS. Интегратор повторил smoke из ZIP. Установка Ubuntu, APT, systemd, ip/proc на Darwin не выполнялись; этот предел указан в README и исследовании.

Алгоритмы: 13 тестовых функций эталона Go — PASS. Оптимизации сравниваются с линейным просмотром, сортировкой, перебором строк и подмножеств, BFS, Bellman–Ford. Заготовки трёх exercises намеренно незаполнены: ожидаемый FAIL с implement обозначен в README и первой главе. Финальный CLI ученик пишет самостоятельно.

Базы данных: PostgreSQL 18.6 в отдельном временном кластере, доступном через Unix socket. Автор выполнил setup/tests/indexes/migration, отказ повторного setup без изменения seed, dump→новая база→restore→tests и пять двухсессионных сценариев: RC lost update, RR write skew, guard с новым снимком, Serializable 40001, unique conflict при обоих исходах первой транзакции. Также выполнены фрагменты normalization, jsonb и финального каталога.

Интегратор независимо повторил SQL-файлы, отказ setup, dump/restore/tests из распакованного ZIP. Go-клиент прочитал участников 1/2/3, включая NULL; недоступный localhost:1 дал ошибку без DSN. Требуется Go 1.23+, закреплён pgx v5.7.2; проверка выполнена на Go 1.25.6. Unit-тестов клиента нет: подтверждены компиляция и реальные запросы. Временный PostgreSQL остановлен, постоянная служба не включалась.

System Design: прежнее ограничение проверки SQL закрыто. На PostgreSQL 18.6 выполнены setup/collision и четыре двухсессионные истории. Девять Python unittest и stream --test/capacity/overload повторены из ZIP — PASS. SQL-файл сам по себе не автоматизирует конкурентные сценарии.

## Исправления и границы

Исправлены: настоящий carriage return вместо команды psql `\r`, подготовка Linux-папки до развилки systemd/manual, неверный путь notes, ожидание готовности HTTP и обязательное name в JSON финала алгоритмов. Отчёты независимых разборов сохранены.

GitHub PR, SSH и LFS-хостинг — необязательное продолжение; они не объявлены исполненными. Тесты не заменяют наблюдение за реальным новичком и не подтверждают первое место курса на рынке.
