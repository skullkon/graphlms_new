На этом этапе вы добавите подсветку одного совпадения.

### Флаг `--color`

Флаг `--color` указывает grep подсвечивать совпавший текст в выводе. Он принимает три значения:
- `always`: всегда использовать цвет;
- `auto`: использовать цвет только при выводе в терминал;
- `never`: никогда не использовать цвет.

На этом этапе реализуйте вариант `--color=always`.

### Подсветка совпавшего текста

Если пользователь передаёт `--color=always`, grep подсвечивает совпавший текст, окружая его специальными кодами форматирования.

Например:

<html>
<pre>
$ echo -n "I have 1 apple" | ./your_program.sh --color=always -E '\d'
I have <span style="color: red; font-weight: bold;">1</span> apple
</pre>
</html>

Совпадение ("1") отображается в терминале красным полужирным шрифтом.

### Управляющие последовательности ANSI

Grep использует [управляющие последовательности ANSI](https://en.wikipedia.org/wiki/ANSI_escape_code) для добавления цвета. Терминал интерпретирует эти специальные последовательности символов как команды форматирования, а не обычный текст.

По умолчанию grep выделяет совпавший текст красным полужирным шрифтом.

Чтобы подсветить совпавший текст:
1. Вставьте перед ним открывающую последовательность, задающую начертание и цвет.
2. Вставьте после него закрывающую последовательность, сбрасывающую форматирование.

Для красного полужирного текста используются следующие последовательности ANSI:

```bash
\033[01;31m
...
\033[m
```

Разберём открывающую последовательность (`\033[01;31m`):

| Компонент | Значение |
|-----------|---------|
| `\033` | Символ Escape, начинающий управляющую последовательность ANSI |
| `[` | Начало параметров [Select Graphic Rendition (SGR)](https://vt100.net/docs/vt510-rm/SGR.html) |
| `01;31` | Коды SGR: `01` — полужирный/яркий текст, `31` — красный цвет текста (разделены `;`) |
| `m` | Конец последовательности SGR |

Закрывающая последовательность (`\033[m`):

| Компонент | Значение |
|-----------|---------|
| `\033` | Символ Escape, начинающий управляющую последовательность ANSI |
| `[` | Начало параметров SGR |
| *(пусто)* | Отсутствие параметров сбрасывает все атрибуты к значениям по умолчанию |
| `m` | Конец последовательности SGR |

Например, чтобы получить такой вывод:

<html>
<pre>
hello<span style="color:red; font-weight:bold" >matched</span>world
</pre>
</html>

Можно использовать любую из последовательностей:

```
hello\033[01;31mmatched\033[mworld
# OR
hello\033[31;01mmatched\033[mworld
```

### Проверки

Тестирующая система запустит программу так:

<html>
<pre>
$ echo -n "I have 3 apples" | ./your_program.sh --color=always -E '\d'
I have <span style="font-weight:bold; color:red;">3</span> apples
</pre>
</html>

Если входные данные не соответствуют шаблону, программа должна:
- Завершиться с кодом `1`.
- Ничего не вывести.

Если входной текст соответствует шаблону, программа должна:
- Завершиться с кодом `0`.
- Вывести входной текст в стандартный вывод.
- Подсветить совпавший текст цветом grep по умолчанию.

### Примечания

* На этом этапе достаточно одного совпадения. Несколько совпадений будут рассмотрены позже.
* Порядок кодов SGR не важен: `\033[31;01m` и `\033[01;31m` дают одинаковое красное полужирное выделение.
* Нужно найти позицию совпадения во входной строке, вставить открывающую последовательность перед ним, а закрывающую — после.
