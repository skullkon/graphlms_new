На этом этапе вы реализуете поддержку обратных косых черт внутри одинарных кавычек.

### Обратные косые черты в одинарных кавычках

Внутри [одинарных кавычек](https://www.gnu.org/software/bash/manual/bash.html#Single-Quotes) обратная косая черта не выполняет экранирование. Каждый символ (включая обратные косые черты) внутри одинарных кавычек трактуется буквально. 

Например:

```bash
$ echo 'shell\\\nscript'
shell\\\nscript

$ echo 'example\"test'
example\"test
```

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке последовательность команд `echo`:

```bash
$ echo 'multiple\\slashes'
multiple\\slashes
$ echo 'every\"thing_is\"literal'
every\"thing_is\"literal
```

Тестирующая система проверит, правильно ли команда `echo` выводит текст в кавычках.


Далее тестирующая система отправит команду `cat`, в которой аргументы имён файлов содержат обратные косые черты внутри одинарных кавычек:
```bash
$ cat /tmp/'no slash 1' /tmp/'one slash \2' /tmp/'two slashes \3\'
content1 content2 content3
```

Тестирующая система проверит, правильно ли команда `cat` выводит содержимое файла.
