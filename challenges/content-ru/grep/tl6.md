На этом этапе вы добавите поддержку положительных групп символов.

### Положительные группы символов

[Положительные группы символов](https://docs.microsoft.com/en-us/dotnet/standard/base-types/character-classes-in-regular-expressions#positive-character-group--) соответствуют любому символу, указанному внутри квадратных скобок (`[]`).

В отличие от предопределённых классов, таких как `\d` и `\w`, положительная группа позволяет задать собственный набор искомых символов.

Синтаксис: `[characters]`.

Например:
- `[abc]` находит совпадение в `"apple"`, поскольку строка содержит `a`.
- `[abc]` находит совпадение в `"cab"`, поскольку строка содержит `a`, `b` и `c`.
- `[abc]` не находит совпадения в `"dog"`, поскольку строка не содержит ни `a`, ни `b`, ни `c`.
- `[123]` находит совпадение в `"a1b2c3"`, поскольку строка содержит `1`, `2` и `3`.

Если шаблон содержит группу символов (например, `[abc]`), программа должна проверить, встречается ли во входной строке хотя бы один из них.

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -n "apple" | ./your_program.sh -E "[abc]"
```

Программа должна:

- Завершиться с кодом `0`, если в строке найден хотя бы один символ группы.
- Завершиться с кодом `1`, если в строке нет ни одного символа группы.
