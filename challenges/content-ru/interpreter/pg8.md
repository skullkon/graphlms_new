На этом этапе вы добавите поддержку объявления, определения и интерпретации пользовательских функций без аргументов в свой интерпретатор Lox.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 10.3: Объявления функций](https://craftinginterpreters.com/functions.html#function-declarations).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими программы с пользовательскими функциями без аргументов.

Например, если `test.lox` содержит следующее

```
fun bar() { print 10; }
bar();
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh run test.lox
10
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

Тестовый случай 1:

Входные данные:

```
fun foo() {
  print 7;
}
foo();
```

Ожидаемый вывод:

```
7
```

Тестовый случай 2:

Входные данные:

```
fun f() {}
f();
```

Ожидаемый вывод:

```

```

Тестовый случай 3:

Входные данные:

```
fun foo() {}
print foo;
```

Ожидаемый вывод:

```
<fn foo>
```

Тестовый случай 4:

Входные данные:

```
fun cumulative_sum() {
    var n = 10;  // Fixed value
    var total = 0;
    var i = 1;
    while (i <= n) {
        total = total + i;
        i = i + 1;
    }
    print "The cumulative sum from 1 to 10 is: ";
    print total;
}

cumulative_sum();
```

Ожидаемый вывод:

```
The cumulative sum from 1 to 10 is:
55
```

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату, а код завершения равен 0.

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/4a840f70f69c6ddd17cfef4f6964f8e1bcd8c3d4/test/function/print.lox)
