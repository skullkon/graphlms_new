# GraphLMS — светлая учебная среда

## Задача
Полностью новая визуальная система, без опоры на старое оформление. Пользователь выбрал светлую среду: белые поверхности, графитовый текст, синий акцент, тёмный редактор. Сохраняются реальные учебные материалы, маршруты и поведение приложения.

## Структура
- Постоянная боковая навигация: обзор, курсы, практика, лаборатории, проекты; отдельно личный прогресс, отчёт, интервью и команды.
- На телефоне навигация открывается как доступный модальный диалог; фокус удерживается внутри, Escape закрывает его.
- Поиск разделов через кнопку или Cmd/Ctrl+K.
- Главная показывает следующий шаг, три курса, раскрывающиеся темы практики, прогресс и диагностику.
- Учебник: узкая колонка чтения, оглавление справа, мобильное раскрывающееся содержание.
- Практика: поиск, фильтры по теме/сложности/состоянию, адаптивные строки задач.
- Рабочее место: навигатор задач, условие слева, тёмный редактор справа; на телефоне условие перед редактором.
- Кабинет, отчёты, проекты, интервью, команды и админка используют общие семантические цвета.

## Интеграции
MCP-серверы shadcn, magicui и ui-layouts добавлены в глобальный конфиг Codex через `codex mcp add`. Подключения проверены реальным MCP handshake и tools/list. В текущем чате серверы использовались через локальный MCP SDK client; после перезапуска Codex инструменты будут доступны как обычные MCP.

- shadcn: просмотр button/sheet/progress; Radix-композиция Button, Progress и диалогов адаптирована к обычному CSS проекта.
- Magic UI: getRegistryItem(blur-fade), компонент установлен официальным shadcn CLI. Добавлена поддержка reduced motion.
- UI Layouts: search_components(accordion), get_source_code(single-layout-accordion). Раскрывающиеся строки практики реализованы нативным details/summary с этим паттерном; тяжёлая animation-зависимость для раскрытия не нужна.
- Реестры записаны в site/web/components.json.
- Lazyweb: health OK; запрос create вернул перенаправление. После реализации отправлена новая мобильная главная в generate_report(objective=improve), без старого дизайна.

## Проверки
- 85 unit tests проходят.
- TypeScript, lint и production build проходят; сгенерирована 151 страница.
- content:check подтверждает целостность всех трёх курсов.
- Мобильная проверка 375px: главная, меню, практика, чтение и задача. Найдено и исправлено переполнение grid каталога.
- Desktop 1440px: рабочее место и главная.
- Исправлен повторяющийся React key у групп ОС в отчёте.
- Скриншоты: evidence/design-2026-09-28/.

Известные backend-проблемы из первоначального аудита (миграции и доверие к отчётам) не исправлялись в задаче дизайна. Авторизация с внешними провайдерами и production-платежи не проверялись.

## Lazyweb
Бесплатный отчёт сформирован успешно (preview): https://www.lazyweb.com/report/lazyweb/f20fa1da-3948-4b0f-a6f9-c07e16cbadc8/?source=create
Главная рекомендация: следующее учебное действие должно быть видно на первом экране телефона. Остальные предложения — гипотезы для будущих продуктовых экспериментов, а не доказанные результаты.

Запуск стартового кода проверен через UI: очередь → выполнение → FAIL с выводом таймаута и записью в историю. Локальный grader после проверки остановлен.
