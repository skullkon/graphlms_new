На этом этапе вы добавите поддержку отрицательных групп символов.

### Отрицательные группы символов

[Отрицательные группы символов](https://docs.microsoft.com/en-us/dotnet/standard/base-types/character-classes-in-regular-expressions#negative-character-group-) противоположны положительным: они соответствуют любому символу, который не указан внутри квадратных скобок (`[]`).

Для создания отрицательной группы поставьте знак `^` сразу после открывающей скобки.

Синтаксис: `[^characters]`.

Например:
- `[^abc]` должно находить совпадение в `"cat"`, поскольку `t` не входит в набор `a`, `b` или `c`.
- `[^abc]` не должно находить совпадение в `"cab"`, поскольку все символы строки входят в набор.

Если шаблон содержит отрицательную группу (например, `[^abc]`), программа должна проверить, есть ли во входной строке хотя бы один символ, не указанный в скобках.

### Проверки

Тестирующая система запустит программу так:

```bash
$ echo -n "apple" | ./your_program.sh -E "[^abc]"
```

Программа должна:

- Завершиться с кодом `0`, если во входных данных есть хотя бы один символ, который **не** входит в группу.
- Завершиться с кодом `1`, если все входные символы входят в группу.
