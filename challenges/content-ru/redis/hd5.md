На этом этапе вы расширите реализацию ведущего для передачи команд нескольким репликам.

### Напоминание о распространении команд

После рукопожатия и загрузки RDB реплика готова получать текущие обновления ведущего.

Каждая команда записи, выполненная ведущим, должна пересылаться всем подключённым репликам. Так каждая реплика остаётся синхронизированной с ведущим.

### Тесты

Тестирующая программа запустит вашу программу так:

```
./your_program.sh --port <PORT>
```

Затем запустит **несколько** реплик: каждая подключится к серверу, выполнит рукопожатие и получит начальный файл RDB.

Далее отдельный клиент отправит ведущему команды `SET`.

```bash
$ redis-cli SET foo 1
$ redis-cli SET bar 2
$ redis-cli SET baz 3
```

Тест проверит, что каждая реплика получила команды в правильном порядке.
