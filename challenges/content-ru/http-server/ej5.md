На этом этапе вы добавите поддержку одновременных соединений.

### Тесты

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Затем она создаст несколько одновременных TCP-соединений с вашим сервером. Точное количество соединений выбирается случайно. После этого по каждому соединению будет отправлен один запрос `GET`.
```bash
$ (sleep 3 && printf "GET / HTTP/1.1\r\n\r\n") | nc localhost 4221 &
$ (sleep 3 && printf "GET / HTTP/1.1\r\n\r\n") | nc localhost 4221 &
$ (sleep 3 && printf "GET / HTTP/1.1\r\n\r\n") | nc localhost 4221 &
```

На каждый запрос сервер должен вернуть следующий ответ:
```javascript
HTTP/1.1 200 OK\r\n\r\n
```
