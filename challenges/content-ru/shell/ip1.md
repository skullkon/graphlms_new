На этом этапе вы добавите поддержку запуска внешних программ с аргументами.

### Запуск внешних программ

До этого вы реализовали встроенные команды, которые оболочка выполняет непосредственно. Теперь вы обработаете внешние программы, которые оболочке нужно найти и запустить.

Если команда не является встроенной, оболочка должна:

1. Определить, является ли указанная команда исполняемым файлом (можно повторно использовать логику `type`).
2. Если да, выполнить программу.
3. Передать программе аргументы из командной строки.

Например, если пользователь вводит `custom_exe arg1 arg2`, оболочка должна:

- Определить, является ли `custom_exe` исполняемым файлом в PATH.
- Выполнить его с тремя аргументами: `custom_exe` (имя программы), `arg1` и `arg2`.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит команду, которую нужно выполнить:

```bash
$ custom_exe_1234 alice
Program was passed 2 args (including program name).
Arg #0 (program name): custom_exe_1234
Arg #1: alice
Program Signature: 5998595441
```

Приведённый выше вывод создаёт сам исполняемый файл. Оболочке достаточно запустить его и позволить отобразить его вывод.

Тестирующая система проверит, что:

- Оболочка правильно находит и выполняет программу.
- Вывод программы появляется в оболочке.
- Аргументы передаются правильно.

Тестирующая система выполнит несколько команд, каждый раз используя случайное количество аргументов.

### Примечания

- Имя программы, аргументы и ожидаемый вывод будут случайными для каждого тестового случая.
- Вывод в примере ("Program was passed N args...") создаётся исполняемым файлом. Его не нужно реализовывать вручную.
- Для выполнения внешних программ потребуется API вашей операционной системы (например, семейство `exec` в Unix, `subprocess` в Python, `child_process` в Node.js и т. д.).
