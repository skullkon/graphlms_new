На этом этапе вы добавите поддержку вычисления унарных операторов `-` и `!`.

### Ссылка на книгу

Код для этого этапа реализован в [разделе 7.2.3: Вычисление унарных выражений](https://craftinginterpreters.com/evaluating-expressions.html#evaluating-unary-expressions).

### Проверки

Тестирующая система выполнит серию проверок с файлами `test.lox`, содержащими выражения с унарными операторами.

Например, если `test.lox` содержит следующее:

```
-(73)
```

Тестирующая система запустит вашу программу следующим образом:

```
$ ./your_program.sh evaluate test.lox
-73
```

Тестирующая система выполнит несколько таких проверок со случайными выражениями, например:

| Входные данные | Ожидаемый вывод |
| :---: | :-------------: |
| `-73` | `-73` |
| `!true` | `false` |
| `!10.40` | `false` |
| `!((false))` | `true` |

Тестирующая система проверит, что stdout вашей программы соответствует приведённому выше формату.

### Примечания

- Этот формат вывода соответствует спецификации в [репозитории книги](https://github.com/munificent/craftinginterpreters/blob/01e6f5b8f3e5dfa65674c2f9cf4700d73ab41cf8/test/expressions/evaluate.lox)
- Для истинных и ложных значений мы будем следовать соглашению из книги: `false` и `nil` считаются ложными, а всё остальное — истинным.
