На этом этапе вы реализуете выполнение по нажатию Enter команды, выбранной из истории стрелками вверх и вниз.

### Проверки

Тестирующая система запустит вашу программу следующим образом:

```bash
./your_program.sh
```

Затем система отправит оболочке несколько команд, после чего нажмёт стрелки вверх и вниз, чтобы выбрать команду из истории, а затем Enter для её выполнения:

```bash
$ echo hello
hello
$ echo world
world
<UP ARROW>
$ echo world
<UP ARROW>
$ echo hello
<DOWN ARROW>
$ echo world
<ENTER>
world
$
```

Тестирующая система ожидает, что при нажатии Enter команда будет выполнена.
