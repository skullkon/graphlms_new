На этом этапе вы добавите ответы на `PING` для клиента в режиме подписки.

### `PING` в режиме подписки

Если клиент отправляет ping после перехода в режим подписки, Redis возвращает не обычный ответ (`+PONG\r\n`), а массив RESP из двух элементов:

1. "pong" как объёмную строку.
2. "" — пустую объёмную строку.

### Тесты

Тестирующая программа запустит вашу программу так:

```bash
$ ./your_program.sh
```

Затем отправит серверу `SUBSCRIBE`, чтобы перейти в режим подписки:

```bash
$ redis-cli
> SUBSCRIBE foo
# Expecting ["subscribe", "foo", 1]
```

После этого отправит `PING`.

```
> PING 
```

Ожидается массив `["pong", ""]` в RESP, который выглядит так:

```
*2\r\n
$4\r\n
pong\r\n
$0\r\n
\r\n
```

Тест также отправит `PING` от отдельного клиента, не подписанного ни на один канал.

```
> PING
```

Ожидается ответ `+PONG\r\n`: "PONG" как простая строка RESP.
