# Менеджер задач: открытый эталон

Нужны Python 3.10+ и Git. Дополнительных Python-пакетов нет.
Откройте терминал в этой папке. На Windows замените `python3` на `py -3`, если так запускается ваш Python.

```sh
python3 --version
python3 app.py --help
python3 app.py --file demo.json list
python3 check.py
```

В эталоне все 12 тестов должны пройти. Изучайте его после самостоятельной попытки; сравнивайте поведение, а не только текст реализации.

Общая проверка: `python3 check.py`. Отдельные шаги:

```sh
python3 -m unittest discover -s tests -p test_app.py -k TestAdd
python3 -m unittest discover -s tests -p test_app.py -k TestDone
```

После реализации используйте новое имя файла для опыта:

```sh
python3 app.py --file example.json add "Пройти урок"
python3 app.py --file example.json list
python3 app.py --file example.json done 1
python3 app.py --file example.json list
```

Ожидается первая задача со статусом `[ ]`, затем `[x]`. Пустой список ничего не выводит.
Пробелы в названии обрезаются. Пустое название и неизвестный id возвращают ошибку, не меняя данные.
Повторное завершение успешно, без перезаписи. Повреждённые данные не перезаписываются.

Учебные ограничения: один пользователь, последовательный запуск, локальный JSON.
Нет блокировок для конкурентных процессов, гарантии сохранности при прерывании записи,
синхронизации, авторизации или сервера. Не используйте настоящие секреты и чужие данные.
`check.py` запускает Python-код и не является изолированной песочницей.

Проверки используют временные папки, не обращаются к сети и не читают ваш demo.json.
Скопируйте нужные документы из ../templates и адаптируйте к своему состоянию.
