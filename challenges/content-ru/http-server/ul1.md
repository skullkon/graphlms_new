На этом этапе вы расширите сервер, чтобы он обрабатывал несколько одновременных постоянных соединений.

### Тесты

Тестирующая система запустит вашу программу следующим образом:
```bash
$ ./your_program.sh
```

Она создаст два постоянных соединения и отправит несколько запросов по каждому из них:
```bash
$ curl --http1.1 -v http://localhost:4221/user-agent -H "User-Agent: orange/mango-grape" --next http://localhost:4221/echo/apple
```

Ваш сервер должен:
1. Обрабатывать несколько одновременных TCP-соединений.
2. Оставлять каждое соединение открытым для нескольких запросов.
3. Независимо обрабатывать запросы в каждом соединении.
4. Возвращать соответствующие ответы на все запросы.

### Примечания
- Каждое соединение нужно обрабатывать независимо.
- Сервер должен отдельно хранить состояние каждого соединения.
- Запросы по разным соединениям можно обрабатывать одновременно.
