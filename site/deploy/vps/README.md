## Службы и данные

- `graphlms-web`: Next.js standalone, `127.0.0.1:3100`.
- `graphlms-api`: аккаунты и прогресс, `127.0.0.1:4100`.
- Caddy завершает TLS и направляет `/backend/*` в API, остальные пути — в Next.js.
  Единый origin нужен в том числе для cookie с CSRF-токеном.
- Переменные и секреты: `/etc/graphlms/web.env` и `api.env`, права `0600`.
- SQLite: `/var/lib/graphlms/app.db`, вне каталога сборки.
- Ежедневная согласованная копия SQLite: `graphlms-backup.timer`, 03:20 UTC.
  Последние 14 копий хранятся в `/var/backups/graphlms` на этом же сервере.
  Это защита от ошибок обновления, но не от потери самого VPS.

Вход по почте и паролю работает без почтового провайдера. Для переноса прогресса
между компьютерами нужно входить в один аккаунт. Данные с прежнего localhost
сами на новый домен не переносятся; их перенос требует отдельного действия.
OAuth и AI-ментор требуют отдельных ключей и пока не настроены.

## Обновление

Загрузить изменённые исходники в `/opt/graphlms`, исключив `.git`, `.env*`,
`node_modules`, `.next`, `dist`, локальные базы и `.local`. Не использовать
`rsync --delete` для каталога приложения целиком.

На сервере:

```sh
systemctl start graphlms-backup.service
cd /opt/graphlms/site/api
npm ci --no-audit --no-fund
npx prisma generate
npm run build
DATABASE_URL=file:/var/lib/graphlms/app.db npx prisma migrate deploy
cd /opt/graphlms/site/web
npm ci --no-audit --no-fund
NEXT_PUBLIC_API_URL=https://learn.186.246.26.166.sslip.io/backend SITE_URL=https://learn.186.246.26.166.sslip.io npm run build
```

После успешной сборки скопировать `.next/standalone` в новый каталог runtime,
добавить `public` и `.next/static` из web, а `site/content` — в соседний `content`.
Сохранить предыдущий runtime для отката. Рабочий каталог службы —
`/opt/graphlms/runtime/web`; `GRAPHLMS_ROOT` указывает на `/opt/graphlms`, где лежат
`challenges` и `tools`. Запустить службы и проверить страницы и вход.

```sh
systemctl restart graphlms-api graphlms-web
systemctl status graphlms-api graphlms-web --no-pager
journalctl -u graphlms-web -u graphlms-api -n 80 --no-pager
```

`smoke.py` проверяет регистрацию, вход в независимой сессии, большой черновик
и CSRF через публичный HTTPS. Скрипт создаёт тестовый аккаунт `deploy-check-…`
и печатает его адрес; после проверки удалить именно этот аккаунт через Prisma.
Пароль и cookie не печатаются.

## Проверка кода

System Design, UML, сценарии, учебный проект, повторение и интервью не требуют
внешнего исполнителя. Project Lab рассчитан на локальный CLI; на публичном
сервере `PROJECT_LAB_LOCAL=0`.

Прежний Piston `201.51.24.60:2000` недоступен с этого VPS. Поэтому серверная
проверка Go-решений пока не подключена. Не включать `RUNNER=local` на публичном
сервере: он выполняет присланный код без изоляции. Для Go требуется доступный
изолированный Piston и grader из `site/deploy/docker-compose.yml`.
