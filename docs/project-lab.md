# Локальная инженерная лаборатория

GraphLMS содержит 11 публичных проектов CodeCrafters и 412 этапов: HTTP server, Redis, Shell, Git, SQLite, DNS, BitTorrent, Kafka, grep, Interpreter и Claude Code. Условия импортированы из официальных MIT-репозиториев; оригиналы, лицензии и точные версии находятся в `challenges/`. Русские переводы находятся в `challenges/content-ru/`, названия этапов — в `challenges/locales/ru/`. Английские оригиналы сохранены в `challenges/content/`; повторный импорт не перезаписывает переводы. Языковые примеры подготовлены для Go.

## Запуск

Нужны Node.js, Git, Go 1.24+ для сборки тестеров и инструменты выбранного языка решения.

```sh
cd site/web
npm install
npm run dev:projects
```

Откройте http://127.0.0.1:3000/projects. На странице проекта выберите язык и скопируйте команды создания проекта и проверки. Код пишется в вашей IDE. Например, из корня LMS:

```sh
node tools/project-lab/cli.mjs init http-server ../my-http-server --language go
```

После реализации этапа запустите указанную на его странице команду `submit` из папки решения. Она запускает официальный тестер локально и передаёт сайту отчёт; исходный код не загружается. Проверяются также предшествующие этапы соответствующей ветки. Первый запуск скачивает закреплённую версию тестера и собирает её; нужен интернет.

Отчёты и локальный токен находятся в `.local/project-lab/` и исключены из Git. Сайт принимает отчёты только в явно включённом локальном режиме. Это персональные результаты, не удалённая аттестация и не синхронизация аккаунта CodeCrafters. Git-push сервер не используется.

Claude Code требует `CODECRAFTERS_SECRET_OPENROUTER_API_KEY` в терминале и явный флаг `--allow-paid-api`: официальный тестер вызывает платный API. Эти проверки не запускались при разработке. Остальные десять проектов не требуют такого API.

Подробнее о CLI: [tools/project-lab/README.md](../tools/project-lab/README.md).

## Проверка реализации

Все 11 тестеров собраны на macOS arm64; начальные заготовки десяти бесплатных проектов проверены на ожидаемый FAIL. Рабочее HTTP-решение прошло первые два этапа, отправку отчёта и отображение результата в интерфейсе. Это smoke-проверка интеграции, а не прохождение всех 412 этапов.

## Проверка переводов

Из корня репозитория выполните `node scripts/check-challenge-translations.mjs`. Проверка требует перевод каждого этапа и названия раздела, а также сверяет блоки кода, встроенные команды и внешние ссылки с оригиналом. После обновления исходных курсов переводы нужно актуализировать отдельно.
